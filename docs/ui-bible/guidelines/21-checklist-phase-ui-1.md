# 21. CHECKLIST PHASE UI 1 POUR AGENT CODEUR IA

Avant d'implémenter une page MAATFEED, l'agent doit vérifier :

## ✅ Fond et Structure
- [ ] Le fond est dark premium, pas noir plat pauvre
- [ ] Les marges mobile respectent 16 px minimum
- [ ] Aucun élément critique n'est sous la bottom nav ou la safe area

## ✅ Actions et Navigation
- [ ] Le CTA principal est unique, doré et lisible
- [ ] Les boutons secondaires n'entrent pas en conflit avec le primaire
- [ ] La bottom navigation est stable et accessible

## ✅ Cartes et Contenus
- [ ] Les cartes ont radius, bordure et profondeur cohérents
- [ ] Les textes principaux sont en blanc chaud, pas gris faible
- [ ] L'or guide les actions et états actifs, pas toute la décoration

## ✅ États et Performance
- [ ] Les skeletons réservent les dimensions finales
- [ ] Les erreurs sont humaines, pas techniques
- [ ] Le mode offline/connexion faible ne détruit pas l'expérience

## ✅ Interactions et Gestures
- [ ] Les gestes mobiles sont naturels et doublés par boutons
- [ ] Le player audio reste prioritaire dans la structure
- [ ] Les débats restent lisibles même avec média

## ✅ Couches et Navigation
- [ ] Les modales et sheets n'entrent pas en conflit
- [ ] Les overlays sont contrôlés et ne masquent pas les actions critiques

## ✅ Animations et Micro-interactions
- [ ] Les animations sont courtes, fluides et utiles
- [ ] Les micro-interactions répondent sans surcharger

## ✅ Responsive et Accessibilité
- [ ] La version desktop enrichit l'expérience sans devenir SaaS
- [ ] L'accessibilité est intégrée dès le départ
- [ ] Les contrastes sont suffisants pour tous les états

## ✅ Identité Visuelle
- [ ] Aucun écran ne ressemble à une UI générique
- [ ] L'ADN noir/or est respecté
- [ ] Les éléments culturels sont subtils, pas décoratifs

*Checklist de validation pour l'implémentation UI Phase 1*
