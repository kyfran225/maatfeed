## 🔄 MÉTHODOLOGIE

### Parcours Chaque Phase
1. **Lecture documentation** : Consulter les fichiers UI BIBLE pertinents
2. **Implémentation** : Créer les composants selon les spécifications
3. **Validation** : Vérifier avec la checklist UI 1
4. **Tests** : Responsive, accessibilité, performance
5. **Documentation** : Mettre à jour les guides techniques

### Principes Clés
- **Mobile-first** : Commencer par mobile, ensuite desktop
- **Dark premium** : Respecter l'ADN noir/or
- **Audio-first** : Prioriser l'expérience audio
- **Performance** : Optimiser pour connexions modestes
- **Accessibilité** : Intégrer dès le départ

### Outils et Technologies
- **Design tokens** : Variables CSS/SCSS
- **Components** : React/Next.js avec TypeScript
- **Styling** : Tailwind CSS + custom design system
- **Performance** : Lazy loading, compression, cache
- **Testing** : Responsive design, accessibilité
