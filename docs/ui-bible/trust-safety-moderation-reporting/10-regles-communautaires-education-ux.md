# 10. RÈGLES COMMUNAUTAIRES ET ÉDUCATION UX

## 1. OBJECTIF UX

Présenter les règles communautaires MAATFEED de manière courte, compréhensible et actionnable, sans transformer l'expérience en règlement administratif.

## 2. ÉMOTION RECHERCHÉE

Responsabilité partagée.
L'utilisateur doit comprendre que les règles protègent la qualité du débat.

## 3. STRUCTURE VISUELLE GLOBALE

Règles principales :

- attaque les idées, pas les personnes ;
- source les affirmations fortes ;
- respecte les croyances et traditions ;
- évite le harcèlement ;
- pas de désinformation volontaire ;
- pas de spam ;
- protège la vie privée ;
- accepte la nuance ;
- signale sans abuser.

## 4. LAYOUT EXACT

### Mobile :

- écran règles en cartes ;
- version courte d'abord ;
- détails repliables ;
- recherche dans règles si nécessaire.

### Desktop :

- page règles avec navigation latérale.

## 5. HIERARCHIE VISUELLE

- règle courte ;
- exemple ;
- action attendue ;
- détail.

Les exemples doivent être pédagogiques, pas humiliants.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Règles accessibles depuis :

- onboarding débat ;
- composer ;
- signalement ;
- paramètres ;
- modération.

## 7. DIMENSIONS & ESPACEMENTS

Carte règle :

- 88 à 140 px ;
- padding 16 px ;
- icône 22 px ;
- radius 22 px.

## 8. COULEURS

Règles :

- fond graphite ;
- icône ambre ;
- alerte ocre pour règles sensibles ;
- texte beige.

## 9. TYPOGRAPHIE

- titre règle : 15 à 17 px ;
- exemple : 12 à 14 px ;
- détail : 12 à 13 px.

## 10. BOUTONS

Actions :

- Voir exemples ;
- J'ai compris ;
- Retour au débat ;
- Signaler ;
- Modifier ma réponse.

## 11. CARTES

Carte règle :

- icône ;
- règle courte ;
- exemple ;
- action recommandée.

## 12. ICONOGRAPHIE

- balance ;
- plume ;
- source ;
- bouclier ;
- communauté ;
- verrou ;
- main.

## 13. COMPORTEMENT SCROLL

Règles courtes visibles d'abord.
Détails seulement si demandé.

## 14. ANIMATIONS

- ouverture accordéon ;
- focus sur règle liée depuis alerte ;
- transition douce.

## 15. MICRO INTERACTIONS

- tap règle ;
- tap exemple ;
- revenir au composer ;
- copier règle si besoin.

## 16. GESTURES MOBILE

- tap ;
- swipe down fermer sheet ;
- scroll vertical.

## 17. ÉTATS LOADING

Règles locales, pas de loading nécessaire.

## 18. ÉTATS ERREUR

Si version complète indisponible :

- afficher règles courtes locales.

## 19. ÉTATS OFFLINE

Règles disponibles offline.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile :

- cartes verticales.

Desktop :

- navigation + contenu.

## 21. ACCESSIBILITÉ

- règles lisibles ;
- exemples clairs ;
- navigation clavier ;
- contraste.

## 22. PERFORMANCE UX

- contenu local ;
- pas d'images ;
- rendu immédiat.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- règles embarquées ;
- pas de dépendance réseau ;
- langage simple.

## 24. RÈGLES NON NÉGOCIABLES

- Règles courtes.
- Exemples utiles.
- Pas de jargon.
- Disponibles partout.
- Offline.
- Liées aux actions concrètes.
