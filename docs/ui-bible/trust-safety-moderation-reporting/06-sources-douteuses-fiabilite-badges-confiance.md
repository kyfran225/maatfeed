# 6. SOURCES DOUTEUSES, FIABILITÉ ET BADGES DE CONFIANCE

## 1. OBJECTIF UX

Aider l'utilisateur à distinguer les contenus sourcés, les opinions, les hypothèses, les interprétations et les sources douteuses.
MAATFEED doit encourager la culture de la source sans transformer chaque débat en examen universitaire.

## 2. ÉMOTION RECHERCHÉE

Clarté intellectuelle.
L'utilisateur doit sentir qu'il peut explorer sans se perdre dans de fausses certitudes.

## 3. STRUCTURE VISUELLE GLOBALE

Système de fiabilité :

- badge source ;
- badge source vérifiée ;
- badge source discutée ;
- badge source manquante ;
- badge opinion/interprétation ;
- panneau détails ;
- appel à ajouter une source ;
- comparaison de sources.

## 4. LAYOUT EXACT

Dans une réponse :

- badge près de l'affirmation ou sous la réponse ;
- sources listées en bas de carte ;
- bouton "voir sources".

Dans un débat :

- section "Sources citées" ;
- badge fiabilité dans header si débat très documentaire.

Dans un document :

- carte source avec métadonnées.

## 5. HIERARCHIE VISUELLE

- affirmation ;
- source disponible ou non ;
- type de source ;
- fiabilité/contextualisation ;
- action.

Le badge ne doit pas remplacer la lecture critique.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Badge source :

- sous titre ;
- près des métadonnées ;
- ou au niveau de la citation.

Ne pas mettre le badge loin en bas si l'affirmation est sensible.

## 7. DIMENSIONS & ESPACEMENTS

Badge :

- 22 à 28 px ;
- texte 11 à 12 px ;
- icône 14 à 16 px.

Carte source :

- 88 à 140 px ;
- padding 14 à 16 px.

## 8. COULEURS

Source fiable :

- or/beige.

Source discutée :

- ocre.

Source manquante :

- gris chaud + bordure ocre faible.

Opinion :

- graphite + texte beige.

## 9. TYPOGRAPHIE

Labels :

- "Source ajoutée"
- "Source vérifiée"
- "Source discutée"
- "Source manquante"
- "Opinion"
- "Interprétation"

Détails :

- 12 à 13 px.

## 10. BOUTONS

Actions :

- Voir source ;
- Ajouter une source ;
- Comparer ;
- Signaler source ;
- Voir contexte ;
- Marquer comme interprétation.

## 11. CARTES

Carte source :

- titre ;
- auteur ou origine si disponible ;
- date ;
- type ;
- fiabilité ;
- bouton ouvrir ;
- avertissement si douteux.

## 12. ICONOGRAPHIE

- papyrus ;
- sceau ;
- loupe ;
- lien ;
- alerte source ;
- balance ;
- document.

## 13. COMPORTEMENT SCROLL

Sources peuvent être repliées sous une réponse.
Dans un débat long, section sources sticky ou accessible depuis header.

## 14. ANIMATIONS

- badge apparaît après ajout source ;
- source douteuse affiche halo ocre léger ;
- liste sources se déplie.

## 15. MICRO INTERACTIONS

- tap badge ;
- tap source ;
- long press source pour signaler ;
- ajouter source depuis composer ;
- copier référence.

## 16. GESTURES MOBILE

- tap ;
- swipe sources horizontales si plusieurs ;
- long press source ;
- sheet détail.

## 17. ÉTATS LOADING

Vérification source :

- skeleton badge ;
- source affichée mais statut "vérification…" ;
- ne pas bloquer publication.

## 18. ÉTATS ERREUR

Si source impossible à charger :

- afficher métadonnées disponibles ;
- indiquer "source non accessible pour le moment" ;
- proposer signaler.

## 19. ÉTATS OFFLINE

Offline :

- sources déjà consultées disponibles ;
- ouverture externe indisponible ;
- statut fiabilité cache ;
- ajout source en attente.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile :

- badges compacts + sheets.

Tablet :

- panneau source.

Desktop :

- panneau détail latéral + comparaison.

## 21. ACCESSIBILITÉ

- badge textuel ;
- pas de couleur seule ;
- source lisible ;
- lien identifiable ;
- statut annoncé.

## 22. PERFORMANCE UX

- métadonnées d'abord ;
- vérification différée ;
- pas de preview lourde automatique ;
- cache sources.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- sources en texte ;
- pas d'aperçu lourd ;
- statut cache ;
- ajout différé.

## 24. RÈGLES NON NÉGOCIABLES

- Ne pas confondre opinion et fait.
- Encourager les sources.
- Source douteuse contextualisée.
- Ne pas censurer uniquement parce qu'une source manque.
- Donner option d'ajout.
- Toujours rester lisible.
