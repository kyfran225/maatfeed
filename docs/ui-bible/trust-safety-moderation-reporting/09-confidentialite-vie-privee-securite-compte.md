# 9. CONFIDENTIALITÉ, VIE PRIVÉE ET SÉCURITÉ DE COMPTE

## 1. OBJECTIF UX

Permettre à l'utilisateur de comprendre et contrôler ce qui est visible, ce qui est privé, ce qui est sauvegardé et ce qui est utilisé pour personnaliser son expérience.

## 2. ÉMOTION RECHERCHÉE

Contrôle tranquille.
L'utilisateur doit sentir que MAATFEED respecte son espace personnel.

## 3. STRUCTURE VISUELLE GLOBALE

Zones :

- visibilité profil ;
- historique de recherche ;
- activité publique ;
- contenus sauvegardés ;
- préférences IA ;
- personnalisation ;
- blocages ;
- sécurité compte ;
- données personnelles ;
- suppression compte.

## 4. LAYOUT EXACT

### Mobile :

- paramètres sécurité/confidentialité ;
- sections en cartes ;
- toggles ;
- détails repliables ;
- actions sensibles confirmées.

### Desktop :

- navigation latérale paramètres ;
- panneau central ;
- détails à droite.

## 5. HIERARCHIE VISUELLE

- visibilité ;
- interactions ;
- données ;
- sécurité ;
- suppression.

Actions destructives en bas, séparées.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Confidentialité accessible depuis :

- paramètres ;
- profil ;
- onboarding si choix sensible ;
- menu sécurité.

## 7. DIMENSIONS & ESPACEMENTS

Lignes paramètres :

- 56 à 72 px ;
- toggle 44 px zone tactile ;
- cartes : 90 à 140 px ;
- section gap : 24 px.

## 8. COULEURS

Confidentialité :

- graphite ;
- or doux pour actif ;
- ocre pour actions sensibles ;
- rouge sombre rare pour suppression.

## 9. TYPOGRAPHIE

- section : 16 à 20 px ;
- label : 14 à 16 px ;
- description : 12 à 13 px ;
- avertissement : 13 px.

## 10. BOUTONS

Actions :

- Modifier visibilité ;
- Effacer historique ;
- Télécharger données si prévu ;
- Gérer personnalisation ;
- Gérer IA ;
- Changer mot de passe ;
- Supprimer compte ;
- Annuler.

## 11. CARTES

Carte confidentialité :

- titre ;
- statut ;
- description ;
- action.

Carte donnée :

- type de donnée ;
- usage ;
- bouton gérer.

## 12. ICONOGRAPHIE

- verrou ;
- œil ;
- historique ;
- IA ;
- données ;
- bouclier ;
- corbeille ;
- clé.

## 13. COMPORTEMENT SCROLL

Paramètres longs, mais groupés.
Actions sensibles tout en bas, séparées par espace.

## 14. ANIMATIONS

- toggle doux ;
- confirmation ;
- suppression avec étape claire ;
- pas d'animation ludique sur actions graves.

## 15. MICRO INTERACTIONS

- tap toggle ;
- voir détail ;
- effacer historique ;
- confirmation ;
- undo pour actions réversibles seulement.

## 16. GESTURES MOBILE

- tap ;
- pas de swipe pour suppression compte ;
- swipe possible pour historique individuel.

## 17. ÉTATS LOADING

- chargement paramètres ;
- sauvegarde préférence ;
- suppression en cours ;
- export si prévu.

## 18. ÉTATS ERREUR

Si sauvegarde échoue :

- conserver état précédent ;
- message clair ;
- retry.

## 19. ÉTATS OFFLINE

Offline :

- changements locaux en attente si sûrs ;
- actions critiques comme suppression nécessitent réseau ;
- état clair.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile :

- sections verticales.

Tablet/Desktop :

- navigation latérale.

## 21. ACCESSIBILITÉ

- toggles annoncés ;
- états visibles ;
- confirmations lisibles ;
- focus ;
- actions destructives explicites.

## 22. PERFORMANCE UX

- paramètres cache ;
- sauvegarde légère ;
- pas de médias ;
- confirmation robuste.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- paramètres lisibles offline ;
- sync différée ;
- actions critiques en ligne seulement ;
- messages simples.

## 24. RÈGLES NON NÉGOCIABLES

- Confidentialité claire.
- Données contrôlables.
- Historique effaçable.
- IA contrôlable.
- Suppression compte non accidentelle.
- Actions critiques expliquées.
- Pas de jargon juridique inutile dans l'UI principale.
