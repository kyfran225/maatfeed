# 13. CHECKLIST AGENT CODEUR - TRUST, SAFETY, MODERATION & REPORTING SYSTEM

## 1. OBJECTIF UX

Donner à l'agent codeur une checklist complète pour implémenter le système de confiance MAATFEED sans le rendre froid, opaque, agressif ou générique.

## 2. ÉMOTION RECHERCHÉE

Exécution juste.
Le résultat doit protéger sans étouffer, expliquer sans noyer, guider sans infantiliser.

## 3. STRUCTURE VISUELLE GLOBALE

À livrer :

- signalement ;
- modération débat ;
- modération IA ;
- contenus sensibles ;
- sources douteuses ;
- badges fiabilité ;
- avertissements contextuels ;
- blocage ;
- masquage ;
- mute ;
- confidentialité ;
- règles communautaires ;
- appels à nuance ;
- anti-toxicité ;
- états offline ;
- accessibilité ;
- recours.

## 4. LAYOUT EXACT

Vérifier :

- mobile bottom sheets ;
- desktop panneaux ;
- alertes inline ;
- badges près du contenu ;
- menu contextuel ;
- paramètres sécurité ;
- pas de modales inutiles.

## 5. HIERARCHIE VISUELLE

Vérifier :

- sécurité avant bruit ;
- personnes protégées ;
- débat préservé ;
- sources contextualisées ;
- décisions expliquées ;
- recours visible.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Vérifier :

- signaler accessible ;
- masquer accessible ;
- bloquer accessible ;
- badges visibles ;
- alertes sous composer ;
- règles depuis composer/débat/signalement ;
- confidentialité dans paramètres.

## 7. DIMENSIONS & ESPACEMENTS

Vérifier :

- touch target 44 px ;
- badges 22 à 28 px ;
- cartes alertes 56 à 160 px ;
- sheets 65 à 90 % ;
- padding 16 à 20 px ;
- radius 18 à 24 px.

## 8. COULEURS

Vérifier :

- noir charbon ;
- graphite chaud ;
- ambre/or ;
- ocre/cuivre pour prudence ;
- rouge sombre uniquement grave ;
- pas de rouge partout ;
- pas de bleu SaaS.

## 9. TYPOGRAPHIE

Vérifier :

- messages courts ;
- non accusateurs ;
- règles claires ;
- raisons lisibles ;
- pas de jargon juridique lourd ;
- détails repliables.

## 10. BOUTONS

Créer et vérifier :

- Signaler ;
- Masquer ;
- Bloquer ;
- Muter ;
- Reformuler ;
- Ajouter source ;
- Voir pourquoi ;
- Voir règle ;
- Demander révision ;
- Annuler ;
- Réessayer ;
- Synchroniser plus tard.

## 11. CARTES

Créer cartes pour :

- motif signalement ;
- avertissement sensible ;
- source fiable ;
- source douteuse ;
- source manquante ;
- contenu masqué ;
- appel nuance ;
- décision modération ;
- blocage ;
- règle communautaire ;
- signalement en attente.

## 12. ICONOGRAPHIE

Vérifier :

- bouclier ;
- balance ;
- papyrus ;
- source ;
- alerte ;
- œil masqué ;
- blocage ;
- plume ;
- info ;
- révision.

## 13. COMPORTEMENT SCROLL

Vérifier :

- aucun saut brutal ;
- contenu masqué garde placeholder ;
- alertes proches du contexte ;
- sheets scroll internes ;
- CTA sticky si nécessaire.

## 14. ANIMATIONS

Vérifier :

- apparition douce ;
- repli contenu ;
- confirmation sobre ;
- réduction motion ;
- pas d'animation punitive ;
- pas de choc visuel.

## 15. MICRO INTERACTIONS

Vérifier :

- tap badge ;
- long press contenu ;
- tap motif ;
- undo masquer ;
- reformuler ;
- ajouter source ;
- voir règle ;
- feedback signalement.

## 16. GESTURES MOBILE

Vérifier :

- long press actions ;
- swipe masquer si prévu ;
- swipe down sheet ;
- pas de blocage par geste accidentel ;
- alternatives visibles.

## 17. ÉTATS LOADING

Vérifier :

- signalement en cours ;
- blocage en cours ;
- vérification source ;
- analyse modération ;
- skeletons locaux ;
- pas de blocage global.

## 18. ÉTATS ERREUR

Vérifier :

- signalement échoué ;
- source inaccessible ;
- contenu supprimé ;
- modération indisponible ;
- blocage échoué ;
- recours échoué ;
- retry clair ;
- choix conservés.

## 19. ÉTATS OFFLINE

Vérifier :

- signalements en attente ;
- blocages en attente ;
- masquage local ;
- règles offline ;
- sources cache ;
- sync différée ;
- aucune donnée perdue.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Tester :

- petit mobile ;
- grand mobile ;
- tablet portrait ;
- tablet paysage ;
- desktop ;
- desktop large ;
- zoom navigateur ;
- clavier ouvert ;
- mini-player actif ;
- faible réseau.

## 21. ACCESSIBILITÉ

Vérifier :

- badges textuels ;
- alertes annoncées ;
- focus visible ;
- navigation clavier ;
- lecteur d'écran ;
- contraste ;
- pas de couleur seule ;
- confirmations ;
- recours accessible.

## 22. PERFORMANCE UX

Vérifier :

- règles locales ;
- pas d'analyse IA permanente ;
- cache ;
- actions optimistes prudentes ;
- sync différée ;
- pas de médias lourds ;
- interface utilisable sans IA.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Vérifier :

- actions locales ;
- signalements en file ;
- messages simples ;
- sources texte ;
- règles offline ;
- pas de reload complet ;
- pas de dépendance réseau pour masquer/bloquer localement.

## 24. RÈGLES NON NÉGOCIABLES

- Protéger sans étouffer.
- Ne pas confondre désaccord et toxicité.
- Expliquer la modération.
- Toujours permettre signalement.
- Toujours permettre masquage.
- Blocage non accidentel.
- Pas de censure invisible.
- Pas de source douteuse sans contexte.
- Pas d'humiliation publique.
- Pas de dark pattern sécurité.
- Pas d'IA juge opaque.
- Offline supporté.
- Respect culturel.
- Respect religieux.
- Respect de la nuance.
- Respect total de l'identité MAATFEED.
