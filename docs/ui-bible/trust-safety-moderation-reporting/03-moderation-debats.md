# 3. MODÉRATION DES DÉBATS

## 1. OBJECTIF UX

Préserver des débats vivants, contradictoires et profonds sans laisser les attaques personnelles, la désinformation agressive, le harcèlement ou la toxicité détruire la conversation.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit ressentir :

- liberté ;
- cadre ;
- respect ;
- intensité saine ;
- possibilité de désaccord.

Le débat doit garder son feu, mais avec un foyer.

## 3. STRUCTURE VISUELLE GLOBALE

La modération débat comprend :

- règles courtes visibles ;
- alertes pré-publication ;
- badges de contexte ;
- ralentissement des fils tendus ;
- appels à la nuance ;
- masquage de réponses problématiques ;
- signalement ;
- intervention IA ou modérateur ;
- résumé des décisions si nécessaire.

## 4. LAYOUT EXACT

Dans une page débat :

- header débat ;
- badge sensibilité si sujet sensible ;
- thread ;
- composer ;
- alertes inline ;
- menu modération sur chaque réponse ;
- panneau de règles accessible.

Les alertes doivent apparaître dans le flux, jamais comme murs.

## 5. HIERARCHIE VISUELLE

Priorité :

- sujet ;
- réponses de qualité ;
- contexte ;
- modération discrète ;
- actions de sécurité.

La modération ne doit pas devenir le contenu principal sauf crise.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Dans le composer :

- alerte sous le champ ;
- bouton reformuler proche ;
- bouton publier reste visible.

Dans le thread :

- contenu masqué reste à sa place avec explication courte ;
- badge "contenu modéré" près de la réponse concernée.

## 7. DIMENSIONS & ESPACEMENTS

Alerte composer :

- 56 à 96 px ;
- padding : 12 à 16 px ;
- radius : 18 à 22 px.

Carte masquée :

- 64 à 100 px ;
- bouton "voir pourquoi" ;
- option "afficher" si autorisé.

## 8. COULEURS

Débat tendu :

- ocre subtil ;
- pas de rouge dramatique.

Réponse masquée :

- graphite mat ;
- texte beige grisé ;
- bordure cuivre faible.

Réponse validée/qualité :

- badge or doux.

## 9. TYPOGRAPHIE

Messages courts :

- "Réponds à l'idée, pas à la personne."
- "Cette réponse semble manquer de source."
- "Le ton peut être perçu comme agressif."

Taille :

- 13 à 15 px.

## 10. BOUTONS

Actions :

- Reformuler ;
- Ajouter source ;
- Publier ;
- Modifier ;
- Signaler ;
- Masquer ;
- Voir règle ;
- Demander révision ;
- Continuer le débat.

## 11. CARTES

Cartes modération débat :

- appel à la nuance ;
- source recommandée ;
- réponse masquée ;
- débat ralenti ;
- règle communautaire ;
- intervention IA.

## 12. ICONOGRAPHIE

- balance ;
- bouclier ;
- source ;
- plume ;
- alerte ocre ;
- cercle débat ;
- ralentisseur symbolique.

## 13. COMPORTEMENT SCROLL

Les fils longs doivent rester lisibles.
Si une réponse est masquée, ne pas supprimer brutalement l'espace.
Si plusieurs réponses sont modérées, regrouper l'explication.

## 14. ANIMATIONS

- alerte apparaît sous le composer ;
- réponse masquée se replie ;
- reformulation s'insère avec highlight ;
- badge de qualité apparaît doucement.

## 15. MICRO INTERACTIONS

- tap "voir pourquoi" ;
- tap "reformuler" ;
- tap "ajouter source" ;
- long press réponse ;
- signaler depuis menu.

## 16. GESTURES MOBILE

- long press sur réponse ;
- swipe pour masquer si activé ;
- swipe down sheet règles ;
- tap badge.

## 17. ÉTATS LOADING

Analyse pré-publication :

- ne doit pas durer longtemps ;
- peut être différée ;
- bouton publier ne doit pas être bloqué sauf cas critique.

## 18. ÉTATS ERREUR

Si modération indisponible :

- appliquer règles locales minimales ;
- permettre publication selon niveau de risque ;
- message discret.

## 19. ÉTATS OFFLINE

Offline :

- brouillon conservé ;
- règles locales ;
- publication en attente ;
- analyse complète au retour réseau.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile :

- alertes inline ;
- bottom sheets.

Tablet :

- panneau règles.

Desktop :

- panneau latéral contexte/modération.

## 21. ACCESSIBILITÉ

- alertes annoncées ;
- contenu masqué expliqué ;
- boutons accessibles ;
- focus vers alerte ;
- pas de couleur seule.

## 22. PERFORMANCE UX

- analyse légère ;
- pas de recalcul constant ;
- groupement des alertes ;
- cache règles.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- règles locales ;
- publication différée ;
- modération complète plus tard ;
- pas de blocage réseau permanent ;
- messages courts.

## 24. RÈGLES NON NÉGOCIABLES

- Désaccord autorisé.
- Attaque personnelle limitée.
- Harcèlement stoppé.
- Sources encouragées.
- Modération expliquée.
- Pas d'humiliation.
- Pas de censure invisible.
- L'utilisateur garde un recours.
