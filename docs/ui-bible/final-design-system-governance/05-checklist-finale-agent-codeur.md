# 5. CHECKLIST FINALE AGENT CODEUR

## 1. OBJECTIF UX

Cette checklist finale permet à l'agent codeur de valider l'ensemble de MAATFEED avant livraison. Elle doit être utilisée comme contrôle qualité global après implémentation des pages, composants et flows.

## 2. ÉMOTION RECHERCHÉE

La livraison finale doit donner l'impression d'un produit :

- fini ;
- solide ;
- fluide ;
- cohérent ;
- premium ;
- adapté au public réel ;
- prêt à grandir.

Pas une maquette codée. Pas un prototype fragile. Une application qui tient debout.

## 3. STRUCTURE VISUELLE GLOBALE

L'agent doit vérifier :

- fond global ;
- surfaces ;
- cartes ;
- headers ;
- bottom nav ;
- player ;
- sheets ;
- modales ;
- prompts ;
- états vides ;
- états offline ;
- notifications ;
- paramètres.

Chaque élément doit appartenir à la même famille visuelle.

## 4. LAYOUT EXACT

Checklist layout :

- marges mobiles cohérentes ;
- safe areas respectées ;
- bottom nav non intrusive ;
- mini-player non bloquant ;
- sheets correctement positionnées ;
- modales lisibles ;
- desktop non surchargé ;
- aucun overflow horizontal.

## 5. HIERARCHIE VISUELLE

Checklist hiérarchie :

- contenu principal immédiatement identifiable ;
- action principale claire ;
- actions secondaires discrètes ;
- sponsor natif non agressif ;
- premium élégant ;
- IA transparente ;
- offline lisible.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Checklist position :

- boutons principaux accessibles au pouce ;
- retour toujours accessible ;
- menus secondaires cohérents ;
- badges proches du contenu ;
- statuts réseau visibles mais non envahissants ;
- suppression isolée.

## 7. DIMENSIONS & ESPACEMENTS

Checklist dimensions :

- zones tactiles minimum 44 px ;
- boutons 48 px environ ;
- lignes réglages confortables ;
- cartes respirantes ;
- chips lisibles ;
- typographie jamais microscopique ;
- spacing constant.

## 8. COULEURS

Checklist couleurs :

- noir charbon dominant ;
- or/ambre comme accent ;
- texte ivoire lisible ;
- gris chaud secondaire ;
- rouge argile pour danger ;
- vert discret pour succès ;
- aucun bleu générique dominant ;
- aucun blanc brutal.

## 9. TYPOGRAPHIE

Checklist typo :

- titres cohérents ;
- corps lisible ;
- métadonnées secondaires ;
- textes courts ;
- erreurs humaines ;
- aucun jargon technique utilisateur ;
- microtextes non critiques.

## 10. BOUTONS

Checklist boutons :

- primary clair ;
- secondary cohérent ;
- disabled expliqué ;
- loading intégré ;
- danger isolé ;
- icône + texte pour critique ;
- pas de compétition entre CTA.

## 11. CARTES

Checklist cartes :

- vidéo ;
- audio ;
- débat ;
- série ;
- document ;
- créateur ;
- notification ;
- premium ;
- offline ;
- brouillon ;
- IA.

Chaque carte doit avoir loading, erreur, offline, empty si pertinent.

## 12. ICONOGRAPHIE

Checklist icônes :

- style homogène ;
- taille cohérente ;
- stroke cohérent ;
- signification claire ;
- texte pour actions critiques ;
- avatars IA non humains ;
- symbolique MAATFEED respectée.

## 13. COMPORTEMENT SCROLL

Checklist scroll :

- feed fluide ;
- position conservée ;
- débat lisible ;
- thread non perdu ;
- player stable ;
- filtres horizontaux maîtrisés ;
- aucun saut de layout ;
- fin de liste claire.

## 14. ANIMATIONS

Checklist motion :

- transitions douces ;
- pas de surcharge ;
- réduction motion ;
- sheets naturelles ;
- modales sobres ;
- shimmer discret ;
- feedback rapide.

## 15. MICRO INTERACTIONS

Checklist feedback :

- action sociale ;
- sauvegarde ;
- téléchargement ;
- publication ;
- paiement ;
- notification ;
- sync ;
- offline ;
- erreur ;
- réglage modifié.

Chaque action doit répondre.

## 16. GESTURES MOBILE

Checklist gestures :

- swipe back ;
- swipe down ;
- tap ;
- long press optionnel ;
- pull refresh ;
- gestures non destructives ;
- player manipulable ;
- sheets fermables.

## 17. ÉTATS LOADING

Checklist loading :

- app shell rapide ;
- skeletons contextuels ;
- aucun spinner abusif ;
- média progressif ;
- bouton loading ;
- paiement loading sécurisé ;
- IA thinking state clair.

## 18. ÉTATS ERREUR

Checklist erreur :

- message humain ;
- action proposée ;
- alternative légère ;
- contenu utilisateur préservé ;
- erreur proche du contexte ;
- aucun code brut ;
- pas d'écran mort.

## 19. ÉTATS OFFLINE

Checklist offline :

- page offline utile ;
- contenu local ;
- audio offline ;
- brouillons ;
- actions en attente ;
- retour réseau ;
- recherche locale ;
- cache visible ;
- Low Data actif.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Checklist responsive :

- mobile parfait ;
- petits écrans utilisables ;
- tablette enrichie ;
- desktop multi-panel maîtrisé ;
- pas de dashboard froid ;
- pas d'overflow ;
- bottom nav adaptée.

## 21. ACCESSIBILITÉ

Checklist accessibilité :

- contraste ;
- labels ;
- focus ;
- clavier ;
- lecteur d'écran ;
- captions ;
- transcriptions ;
- tailles tactiles ;
- réduction motion ;
- erreurs annoncées.

## 22. PERFORMANCE UX

Checklist performance :

- première ouverture rapide ;
- feed stable ;
- audio prioritaire ;
- médias lazy ;
- images optimisées ;
- vidéos manuelles en low data ;
- cache intelligent ;
- pas de blocage inutile ;
- skeletons limités.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Checklist Afrique :

- mode économie visible ;
- data respectée ;
- offline réel ;
- audio léger ;
- téléchargements Wi-Fi ;
- publication différée ;
- brouillons protégés ;
- messages simples ;
- téléphone modeste respecté.

## 24. RÈGLES NON NÉGOCIABLES

Avant livraison, l'agent codeur doit confirmer mentalement :

- aucune page générique ;
- aucun composant sans état ;
- aucun média sans fallback ;
- aucune action sans feedback ;
- aucun flow critique sans erreur/offline ;
- aucun écran non mobile-first ;
- aucun style hors identité MAATFEED.
