# 10. RÉSULTATS SPONSORISÉS, PREMIUM ET DÉCOUVERTE MONÉTISÉE

## 1. OBJECTIF UX

Intégrer les contenus sponsorisés ou premium sans casser la confiance. La monétisation dans Discovery doit être transparente, élégante et non intrusive.

## 2. ÉMOTION RECHERCHÉE

Confiance.
L'utilisateur doit comprendre ce qui est sponsorisé, ce qui est premium et pourquoi c'est affiché.

## 3. STRUCTURE VISUELLE GLOBALE

Types possibles :

- contenu sponsorisé natif
- série premium
- audio sponsorisé
- créateur mis en avant
- chemin premium
- document premium si pertinent
- offre de soutien créateur

## 4. LAYOUT EXACT

Les résultats sponsorisés peuvent apparaître :

- après 3 à 5 résultats organiques
- dans une section dédiée
- jamais en premier résultat absolu sauf recherche commerciale claire
- jamais comme contenu déguisé

## 5. HIERARCHIE VISUELLE

### Carte sponsorisée :

- label sponsorisé
- titre
- valeur réelle
- créateur/marque
- action

### Premium :

- label premium
- aperçu gratuit
- bénéfice
- prix ou condition si nécessaire
- action

## 6. POSITIONNEMENT DES ÉLÉMENTS

Label toujours visible en haut de carte.

Sur mobile, label dans coin supérieur gauche.

Sur desktop, label près du type de résultat.

## 7. DIMENSIONS & ESPACEMENTS

Même dimensions que les cartes natives pour éviter rupture, mais avec label clair.

Label :

- hauteur : 22 à 26 px
- radius : 999
- padding horizontal : 8 à 10 px

## 8. COULEURS

### Sponsorisé :

- label beige/cuivre discret
- pas de vert agressif
- pas de rouge
- pas de badge trompeur

### Premium :

- or plus net
- fond noir profond
- halo très subtil

## 9. TYPOGRAPHIE

### Label :

- 11 à 12 px
- lisible
- pas caché

### Titre :

- identique aux autres cartes

### Texte transparence :

- 12 à 13 px

## 10. BOUTONS

Actions :

- voir aperçu
- écouter extrait
- soutenir
- débloquer
- en savoir plus
- masquer cette annonce

Boutons commerciaux jamais plus visuellement forts que l'action de recherche principale.

## 11. CARTES

La carte sponsorisée doit respecter la même qualité éditoriale que les cartes organiques.

- Pas de bannière criarde
- Pas de publicité hors univers visuel
- Pas d'interruption brutale

## 12. ICONOGRAPHIE

- label discret
- sceau premium
- étoile or
- casque audio premium
- série verrouillée
- soutien créateur

## 13. COMPORTEMENT SCROLL

Sponsorisé intégré dans le flux, mais espacé.

Ne jamais répéter trop fréquemment.

Sur faible connexion, sponsorisé lourd doit être évité.

## 14. ANIMATIONS

Aucune animation publicitaire agressive.

Premium peut avoir un halo doux.

## 15. MICRO INTERACTIONS

- tap label : explication
- masquer annonce : disparition douce
- aperçu premium : ouverture non intrusive
- retour facile

## 16. GESTURES MOBILE

- long press pour options
- swipe masquer si disponible
- tap aperçu

## 17. ÉTATS LOADING

Ne jamais bloquer résultats organiques pour charger sponsorisé.

Si sponsorisé indisponible, ne rien afficher.

## 18. ÉTATS ERREUR

Erreur sponsorisée invisible pour l'utilisateur.

Erreur premium :

- message clair si paiement ou accès indisponible
- ne jamais perdre l'aperçu

## 19. ÉTATS OFFLINE

Sponsorisé non prioritaire offline.

Premium offline possible uniquement si déjà débloqué ou téléchargé.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- intégration rare et douce

### Tablet :

- panneau soutien discret

### Desktop :

- possibilité de bloc latéral sponsorisé discret
- jamais de bannière agressive

## 21. ACCESSIBILITÉ

- label sponsorisé annoncé
- paywall expliqué
- pas de dark pattern
- boutons clairs

## 22. PERFORMANCE UX

- sponsorisé lazy-load
- pas de scripts lourds visibles
- pas de média autoplay
- premium preview optimisé

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- éviter publicités lourdes
- prioriser texte
- premium avec aperçu léger
- paiement abordé dans phase monétisation

## 24. RÈGLES NON NÉGOCIABLES

- Sponsorisé doit être toujours identifié
- Premium ne doit pas humilier l'utilisateur gratuit
- Aucun dark pattern
- Aucun contenu publicitaire qui casse l'identité MAATFEED
- La recherche organique reste prioritaire
