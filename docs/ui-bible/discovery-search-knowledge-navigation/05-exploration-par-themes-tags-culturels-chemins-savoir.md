# 5. EXPLORATION PAR THÈMES, TAGS CULTURELS ET CHEMINS DE SAVOIR

## 1. OBJECTIF UX

Permettre à l'utilisateur d'explorer MAATFEED sans savoir quoi chercher exactement. Les thèmes et tags doivent devenir des portes d'entrée vers des chemins de savoir.

## 2. ÉMOTION RECHERCHÉE

Curiosité guidée.
L'utilisateur doit sentir que l'application lui propose des pistes riches sans l'obliger à réfléchir trop longtemps.

## 3. STRUCTURE VISUELLE GLOBALE

Blocs principaux :

- thèmes majeurs
- tags culturels
- chemins d'apprentissage
- sujets liés
- débats associés
- séries recommandées
- voix expertes
- sources fondatrices

## 4. LAYOUT EXACT

### Mobile :

- carousel de thèmes
- chips tags
- cartes chemin verticales
- section "Commencer ici"

### Desktop :

- grille de thèmes
- carte active avec détails
- panneau latéral de tags associés
- résultats liés au centre

## 5. HIERARCHIE VISUELLE

Les thèmes sont plus importants que les tags.

Hiérarchie :

1. thème
2. description courte
3. chemin recommandé
4. contenus associés
5. tags secondaires

## 6. POSITIONNEMENT DES ÉLÉMENTS

Les thèmes apparaissent haut dans Discovery, après search bar et filtres rapides.

Les tags apparaissent sous les thèmes ou dans une section "Explorer par mots-clés".

Les chemins de savoir apparaissent comme cartes plus éditoriales.

## 7. DIMENSIONS & ESPACEMENTS

### Thème mobile :

- carte : 160 à 220 px de large
- hauteur : 120 à 160 px
- radius : 24 à 28 px
- padding : 16 px

### Tag :

- hauteur : 34 à 38 px
- radius : pilule
- padding horizontal : 14 à 18 px

### Chemin :

- hauteur : 160 à 240 px selon richesse
- espace entre cartes : 14 à 18 px

## 8. COULEURS

Les thèmes utilisent :

- fond noir/brun texturé
- gradient ambre très subtil
- motifs culturels à faible opacité
- icône symbolique or
- texte blanc chaud

Les tags actifs :

- fond ambre sombre
- bordure or douce
- texte ambre clair

## 9. TYPOGRAPHIE

### Thème :

- titre : 17 à 21 px
- description : 13 à 14 px
- compteur : 12 px

### Tag :

- 13 à 14 px

### Chemin :

- titre : 18 px
- étape : 13 px
- durée estimée : 12 px

## 10. BOUTONS

Boutons :

- Explorer
- Commencer
- Voir débats
- Écouter audios
- Voir sources
- Suivre ce thème
- Masquer ce thème

Le bouton "Suivre ce thème" doit être discret mais accessible.

## 11. CARTES

### Carte thème :

- icône symbolique
- titre
- phrase courte
- nombre de contenus
- indicateur de tendance

### Carte chemin :

- titre
- progression éventuelle
- étapes
- formats inclus
- durée estimée
- bouton commencer

## 12. ICONOGRAPHIE

Thèmes possibles :

- Kemet
- spiritualité africaine
- religions comparées
- histoire
- langues
- diaspora
- philosophie
- sciences anciennes
- débats contemporains
- art et symboles

Icônes non humaines, abstraites, symboliques.

## 13. COMPORTEMENT SCROLL

Les tags peuvent être horizontaux sur mobile.

Les thèmes peuvent être en carousel horizontal ou grille compacte.

Les chemins doivent rester verticaux pour favoriser la lecture.

## 14. ANIMATIONS

- thème actif s'illumine doucement
- tag sélectionné se remplit
- chemin se déploie pour montrer étapes
- transitions de contenus liés fluides

## 15. MICRO INTERACTIONS

- tap thème : feedback visuel immédiat
- long press thème : aperçu rapide
- suivre thème : petite confirmation
- tag actif : bordure lumineuse
- progression chemin : ligne douce animée

## 16. GESTURES MOBILE

- swipe thèmes
- swipe tags
- tap pour filtrer
- long press pour aperçu
- swipe down pour quitter détail thème

## 17. ÉTATS LOADING

Skeleton :

- cartes thèmes
- chips
- chemins
- compteurs

Les thèmes populaires peuvent être affichés depuis cache avant actualisation.

## 18. ÉTATS ERREUR

Si thèmes indisponibles :

- afficher tags populaires locaux
- proposer historique
- message doux :
  "Les thèmes complets ne sont pas disponibles. Voici ce qui est déjà accessible."

## 19. ÉTATS OFFLINE

Offline :

- thèmes consultés
- tags récents
- chemins commencés
- contenus sauvegardés par thème

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- carousel

### Tablet :

- grille 2 colonnes

### Desktop :

- grille 3 à 4 colonnes
- panneau détail

## 21. ACCESSIBILITÉ

- thème lisible sans motif
- tags accessibles au clavier
- état actif annoncé
- description textuelle pour icônes
- taille tactile suffisante

## 22. PERFORMANCE UX

- motifs légers
- icônes vectorielles simples
- pas d'images lourdes dans tous les thèmes
- précharger thèmes principaux
- différer contenus associés

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- thèmes en cache
- tags textuels
- pas d'obligation image
- chemins chargés par étapes
- contenus lourds optionnels

## 24. RÈGLES NON NÉGOCIABLES

- Les tags ne doivent pas être des hashtags froids
- Les thèmes doivent raconter une direction
- Les chemins doivent guider l'apprentissage
- L'esthétique doit rester culturelle et premium
- Aucun thème ne doit devenir une catégorie générique vide
