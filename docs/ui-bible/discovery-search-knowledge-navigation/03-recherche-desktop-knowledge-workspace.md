# 3. RECHERCHE DESKTOP & KNOWLEDGE WORKSPACE

## 1. OBJECTIF UX

Créer une expérience desktop plus puissante, pensée pour les utilisateurs qui explorent profondément : chercheurs, passionnés, créateurs, débatteurs, curieux avancés.

Le desktop Discovery doit être un workspace de navigation du savoir, sans devenir un outil froid.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit ressentir :

- puissance calme
- profondeur
- lisibilité
- orientation
- maîtrise documentaire
- prestige intellectuel

## 3. STRUCTURE VISUELLE GLOBALE

Desktop en trois zones :

- colonne gauche : catégories, thèmes, filtres
- colonne centrale : recherche et résultats
- colonne droite : tendances, IA, historique, recommandations

Le centre reste roi. Les panneaux latéraux guident sans écraser.

## 4. LAYOUT EXACT

### Colonne gauche :

- largeur 220 à 260 px
- sticky
- fond légèrement différent
- catégories verticales

### Centre :

- largeur fluide
- search bar large
- résultats
- sections éditoriales

### Droite :

- largeur 300 à 340 px
- suggestions IA
- tendances
- recherches récentes
- créateurs recommandés

## 5. HIERARCHIE VISUELLE

Priorité :

1. recherche centrale
2. résultats
3. filtres gauche
4. intelligence contextuelle droite
5. historique secondaire

Le panneau droit ne doit jamais distraire plus que les résultats.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Search bar en haut du centre.

Filtres principaux à gauche.

Suggestions IA à droite en haut.

Tendances sous suggestions IA.

Historique en bas du panneau droit ou repliable.

## 7. DIMENSIONS & ESPACEMENTS

- container global : 1180 à 1440 px selon écran
- search bar : 60 px
- rayon : 28 px
- gutter : 24 px
- section gap : 32 px
- cartes résultats : 112 à 180 px
- cartes featured : 220 à 320 px
- padding panneaux : 16 à 24 px

## 8. COULEURS

Même palette dark premium.

Différencier les panneaux par nuances :

- gauche : noir graphite
- centre : noir charbon
- droite : brun noir plus chaud
- lignes séparatrices : or/brun très transparent

Ne jamais utiliser des fonds gris clairs de dashboard.

## 9. TYPOGRAPHIE

Desktop permet plus de respiration :

- titre page : 32 px
- search input : 17 à 18 px
- catégories : 14 à 15 px
- résultats : 16 à 19 px
- extraits : 14 à 15 px
- métadonnées : 12 à 13 px

## 10. BOUTONS

Boutons desktop :

- filtres
- sauvegarder recherche
- ouvrir résultat
- écouter
- suivre
- comparer sources
- ouvrir en mode lecture
- ouvrir débat
- voir chemin associé

Les boutons secondaires peuvent apparaître au hover.

## 11. CARTES

Les cartes desktop peuvent être plus riches :

- miniature plus grande
- extrait plus long
- badges
- actions au hover
- aperçu audio
- aperçu débat
- score de pertinence culturel discret
- indication source ou créateur

## 12. ICONOGRAPHIE

La colonne gauche peut utiliser des icônes très simples :

- Tout
- Débats
- Audios
- Séries
- Créateurs
- Sources
- Thèmes
- Premium
- Sauvegardés

L'icône active reçoit un halo ambre discret.

## 13. COMPORTEMENT SCROLL

- centre scroll principal
- gauche sticky
- droite sticky jusqu'à hauteur disponible
- search bar sticky au scroll
- pas de scroll horizontal
- retour haut visible après longue descente

## 14. ANIMATIONS

Desktop supporte :

- hover cards
- expansion aperçu
- panneau filtre glissant
- transitions onglets
- focus search bar lumineux
- apparition progressive des résultats

Animation jamais décorative au point de ralentir.

## 15. MICRO INTERACTIONS

- hover résultat : révélation actions
- hover source : aperçu fiabilité
- hover créateur : mini profil
- clic filtre : état actif clair
- sauvegarde : feedback toast
- drag non nécessaire

## 16. GESTURES MOBILE

Non prioritaire sur desktop, mais sur tablet hybride :

- swipe entre panneaux
- tap hors panneau pour fermer
- pinch ou zoom système respecté

## 17. ÉTATS LOADING

Desktop loading :

- search bar prête immédiatement
- skeletons dans centre
- panneaux latéraux déjà visibles
- tendances chargées progressivement
- pas d'écran bloqué complet

## 18. ÉTATS ERREUR

Erreur dans centre uniquement si les résultats échouent.

Les panneaux latéraux peuvent rester utilisables.

Message :

- "Résultats indisponibles pour le moment."
- "Les tendances et recherches récentes restent accessibles."

## 19. ÉTATS OFFLINE

Desktop offline :

- colonne gauche disponible
- centre affiche résultats locaux
- droite affiche historique
- bouton mode léger
- bouton synchroniser quand réseau revient

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Tablet paysage :

- deux colonnes
- filtres repliables
- panneau IA optionnel

### Desktop large :

- trois colonnes

### Desktop petit :

- colonne droite passe sous le centre ou devient drawer

## 21. ACCESSIBILITÉ

- navigation clavier complète
- raccourci focus recherche possible
- panneaux nommés clairement
- focus visible
- hover doublé par focus
- contrastes vérifiés
- pas de dépendance à la souris

## 22. PERFORMANCE UX

- virtualisation éventuelle des longs résultats
- lazy-load des panneaux secondaires
- cache par requête
- préchargement des catégories populaires
- maintien état entre navigation et retour

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Même sur desktop, considérer cybercafés, partage de connexion, réseau instable :

- résultats texte d'abord
- médias différés
- mode léger
- cache agressif
- pas d'autoplay
- preview audio courte

## 24. RÈGLES NON NÉGOCIABLES

- Ne pas transformer Discovery desktop en dashboard administratif
- Garder une atmosphère culturelle
- Garder le centre lisible
- Les panneaux latéraux doivent guider, pas remplir
- Aucun tableau lourd
- Aucun excès de widgets
- L'expérience doit rester MAATFEED, pas moteur de recherche générique
