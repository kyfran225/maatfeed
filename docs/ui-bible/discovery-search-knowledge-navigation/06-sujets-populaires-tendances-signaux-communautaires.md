# 6. SUJETS POPULAIRES, TENDANCES ET SIGNAUX COMMUNAUTAIRES

## 1. OBJECTIF UX

Montrer ce qui bouge dans la communauté sans pousser au buzz vide. Les tendances MAATFEED doivent privilégier l'intérêt culturel, la qualité du débat, l'écoute audio et la profondeur.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit ressentir qu'il entre dans une conversation vivante et intelligente, pas dans une foire au bruit.

## 3. STRUCTURE VISUELLE GLOBALE

Sections :

- sujets populaires
- débats actifs
- audios montants
- créateurs en progression
- séries suivies
- sources consultées
- tendances par thème
- tendances près de ton archétype

## 4. LAYOUT EXACT

### Mobile :

- section "En ce moment"
- cards compactes verticales
- carousel horizontal pour tendances rapides

### Desktop :

- panneau droit avec top tendances
- section centrale complète si page dédiée

## 5. HIERARCHIE VISUELLE

Une tendance doit montrer :

- sujet
- raison de la tendance
- type dominant
- niveau d'activité
- action

Exemple de raison :

- "Débat très actif"
- "Audio beaucoup écouté"
- "Série reprise cette semaine"
- "Source souvent citée"

## 6. POSITIONNEMENT DES ÉLÉMENTS

La section tendances doit être visible assez tôt, mais après la recherche.

Sur desktop, tendances dans la colonne droite.

Sur mobile, tendances après filtres rapides et avant sections profondes.

## 7. DIMENSIONS & ESPACEMENTS

- carte tendance : hauteur 92 à 130 px
- padding : 14 à 16 px
- radius : 20 à 24 px
- icône : 18 à 22 px
- badge : 24 à 30 px de haut

## 8. COULEURS

- tendance : accent flamme ambre
- fond : brun noir
- bordure : or subtil
- indicateur d'activité : cuivre

Éviter rouge agressif sauf alerte modération, pas tendance.

## 9. TYPOGRAPHIE

- titre sujet : 15 à 17 px
- raison : 12 à 13 px
- compteur : 12 px
- badge tendance : 11 à 12 px

## 10. BOUTONS

Actions :

- ouvrir
- écouter
- rejoindre débat
- suivre sujet
- masquer tendance

"Masquer" doit être disponible mais secondaire.

## 11. CARTES

Carte tendance doit être concise :

- sujet
- badge
- activité
- format dominant
- action

Pas de longues descriptions.

## 12. ICONOGRAPHIE

Icônes :

- flamme douce
- onde audio
- cercle de débat
- étoile montante
- sceau source
- série
- communauté

## 13. COMPORTEMENT SCROLL

Sur mobile, tendances peuvent être horizontales au-dessus d'une liste détaillée.

Sur desktop, panneau tendance reste visible pendant scroll.

## 14. ANIMATIONS

- légère pulsation sur tendance active
- pas d'animation agressive
- changement classement doux
- apparition progressive

## 15. MICRO INTERACTIONS

- tap tendance : carte s'ouvre avec contexte
- hover : affiche pourquoi c'est populaire
- suivre sujet : feedback court
- masquer : carte glisse et disparaît

## 16. GESTURES MOBILE

- swipe horizontal
- long press pour options
- swipe pour masquer si explicite
- tap principal pour ouvrir

## 17. ÉTATS LOADING

Skeleton tendances :

- 3 cartes
- badges fantômes
- lignes courtes

## 18. ÉTATS ERREUR

Si tendances indisponibles :

- afficher sujets populaires en cache
- message :
  "Les tendances en direct ne sont pas disponibles. Voici les sujets souvent consultés."

## 19. ÉTATS OFFLINE

Offline :

- tendances mises en cache
- clairement indiquées comme non actualisées
- possibilité de consulter contenus sauvegardés liés

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- carousel + liste courte

### Tablet :

- grille 2 colonnes

### Desktop :

- panneau droit + page dédiée

## 21. ACCESSIBILITÉ

- ne pas indiquer tendance uniquement par couleur
- texte expliquant le signal
- focus visible
- éviter animations excessives

## 22. PERFORMANCE UX

- tendances en cache
- rafraîchissement discret
- pas de recalcul lourd côté interface
- limiter badges dynamiques

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- tendances cache-first
- mise à jour différée
- texte avant miniatures
- audio non préchargé automatiquement

## 24. RÈGLES NON NÉGOCIABLES

- Les tendances ne doivent pas encourager le vide
- La qualité doit primer sur le bruit
- Les débats toxiques ne doivent pas être promus sans contexte
- Les tendances doivent expliquer pourquoi elles apparaissent
- Les signaux communautaires doivent rester lisibles
