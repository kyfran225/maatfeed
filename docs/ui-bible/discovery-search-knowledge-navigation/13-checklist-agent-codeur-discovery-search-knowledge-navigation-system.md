# 13. CHECKLIST AGENT CODEUR — DISCOVERY, SEARCH & KNOWLEDGE NAVIGATION SYSTEM

## 1. OBJECTIF UX

Donner à l'agent codeur une liste claire de validation pour implémenter la Discovery sans improviser l'interface.

## 2. ÉMOTION RECHERCHÉE

Rigueur.
L'implémentation doit respecter la vision sans transformer MAATFEED en app générique.

## 3. STRUCTURE VISUELLE GLOBALE

L'agent doit livrer :

- page Discovery mobile
- recherche mobile focus
- recherche desktop
- filtres rapides
- filtres avancés
- résultats par type
- thèmes
- tags
- tendances
- recommandations
- historique
- suggestions IA
- états loading
- états erreur
- états offline
- mode faible connexion

## 4. LAYOUT EXACT

Valider :

- mobile une colonne
- desktop trois zones
- tablet adaptatif
- search bar sticky
- bottom nav respectée
- mini-player respecté
- pas de scroll horizontal global

## 5. HIERARCHIE VISUELLE

Vérifier :

- search bar prioritaire
- filtres visibles
- résultats lisibles
- recommandations non intrusives
- tendances contextualisées
- sources identifiables

## 6. POSITIONNEMENT DES ÉLÉMENTS

Vérifier :

- search bar en haut
- chips sous search
- résultats sous chips
- mode léger accessible
- historique en focus
- suggestions IA après historique
- desktop panneaux équilibrés

## 7. DIMENSIONS & ESPACEMENTS

Vérifier :

- zones tactiles 44 px minimum
- search bar environ 52 px mobile
- chips 34 à 40 px
- cartes respirantes
- safe area
- marge basse avec mini-player

## 8. COULEURS

Vérifier :

- noir charbon
- ambre/or
- surfaces graphite
- aucun bleu SaaS générique
- aucun fond blanc massif
- sponsorisé/premium transparent

## 9. TYPOGRAPHIE

Vérifier :

- lisible mobile
- titres courts
- extraits limités
- métadonnées discrètes
- hiérarchie stable

## 10. BOUTONS

Vérifier :

- actions claires
- filtres accessibles
- reset visible
- mode léger visible
- boutons non agressifs
- paywall transparent si présent

## 11. CARTES

Vérifier cartes :

- contenu
- débat
- audio
- créateur
- série
- document
- source
- thème
- tendance
- premium
- sponsorisé

Chaque carte doit avoir identité propre.

## 12. ICONOGRAPHIE

Vérifier :

- icônes fines
- symboles culturels
- pas d'emoji décoratif excessif
- pas d'icônes enfantines
- labels pour actions critiques

## 13. COMPORTEMENT SCROLL

Vérifier :

- scroll fluide
- sticky search
- sections horizontales contrôlées
- retour position
- aucun saut au chargement

## 14. ANIMATIONS

Vérifier :

- transitions sobres
- skeleton doux
- hover desktop
- focus search
- réduction motion possible

## 15. MICRO INTERACTIONS

Vérifier :

- feedback tap
- sélection filtre
- sauvegarde
- suppression historique
- audio actif
- erreur image
- mode offline

## 16. GESTURES MOBILE

Vérifier :

- swipe chips
- swipe tags
- pull refresh
- long press actions
- sheet filtres swipe down
- alternatives visibles

## 17. ÉTATS LOADING

Vérifier :

- skeleton search
- skeleton chips
- skeleton cards
- skeleton audio
- skeleton tendances
- jamais spinner solitaire global

## 18. ÉTATS ERREUR

Vérifier :

- messages humains
- actions utiles
- conservation contenu déjà chargé
- erreur par section si possible

## 19. ÉTATS OFFLINE

Vérifier :

- recherche locale
- historique
- sauvegardés
- audios téléchargés
- séries commencées
- mode léger
- synchronisation future

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Vérifier :

- mobile
- tablet
- desktop
- desktop large
- clavier ouvert
- orientation
- mini-player actif

## 21. ACCESSIBILITÉ

Vérifier :

- contraste
- focus
- lecteur écran
- labels
- tailles tactiles
- réduction motion
- navigation clavier
- pas d'info uniquement couleur

## 22. PERFORMANCE UX

Vérifier :

- search bar immédiate
- cache
- lazy-load
- images compressées
- pas d'autoplay
- requêtes maîtrisées
- données textuelles prioritaires

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Vérifier :

- mode léger
- fallback texte
- historiques cache
- médias différés
- pas de dépendance réseau continue
- interface utilisable avec connexion instable

## 24. RÈGLES NON NÉGOCIABLES

- Ne pas coder une recherche générique
- Ne pas copier TikTok, YouTube ou Google
- Ne pas transformer en dashboard
- Ne pas ignorer audio
- Ne pas ignorer débats
- Ne pas cacher sources
- Ne pas bloquer offline
- Ne pas casser l'identité noir/or
- Ne pas surcharger mobile
- Ne pas improviser les composants

*Checklist de validation pour l'implémentation Discovery, Search & Knowledge Navigation System*
