# 16. MODÉRATION, SIGNALEMENT & SÉCURITÉ DU DÉBAT

## 1. OBJECTIF UX

Maintenir des débats respectueux, sûrs et constructifs sans créer une ambiance policière.

## 2. ÉMOTION RECHERCHÉE

Protection, confiance, maturité. L'utilisateur doit sentir que MAATFEED protège le débat sans censurer au hasard.

## 3. STRUCTURE VISUELLE GLOBALE

Options de modération dans menu réponse ou débat : signaler, masquer, bloquer, voir règles, contacter support. Les rappels de règles sont sobres.

## 4. LAYOUT EXACT

Menu options : sheet compacte 35 à 55 % hauteur.
Signalement : page/sheet avec liste motifs 48 à 56 px par ligne.
Champ détails optionnel : 96 à 140 px.
CTA envoyer : bas.

## 5. HIERARCHIE VISUELLE

Masquer et signaler visibles mais pas agressifs. Les actions destructives en rouge discret. Règles visibles dans débat.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Menu depuis trois points de réponse. Signalement en flow séparé. Confirmation après envoi.

## 7. DIMENSIONS & ESPACEMENTS

Options : padding 16 px.
Lignes : 52 px.
CTA : 48 px.
Écart sections : 20 px.

## 8. COULEURS

Fond sombre. Signalement rouge doux. Règles or/gris. Confirmation succès vert doux.

## 9. TYPOGRAPHIE

Motifs : 14 px. Description : 13 px. Titre : 17 à 18 px.

## 10. BOUTONS

Signaler, Masquer, Bloquer, Annuler, Envoyer signalement, Voir règles. Bloquer/supprimer toujours confirmés.

## 11. CARTES

Règles du débat peuvent être une carte compacte sous le sujet ou dans sheet.

## 12. ICONOGRAPHIE

Drapeau, bouclier, œil barré, blocage, info, règles.

## 13. COMPORTEMENT SCROLL

Signalement long peut scroller. Le débat derrière reste gelé si sheet ouverte.

## 14. ANIMATIONS

Menu slide up. Confirmation signalement : check discret. Masquer réponse : fade collapse.

## 15. MICRO INTERACTIONS

Tap motif sélectionne avec check. Masquer retire localement. Signaler confirme réception.

## 16. GESTURES MOBILE

Swipe down ferme signalement avec confirmation si détails saisis. Pas de swipe pour supprimer directement.

## 17. ÉTATS LOADING

Envoi signalement : CTA loading. Masquer : action locale immédiate.

## 18. ÉTATS ERREUR

Erreur signalement : conserver sélection/détails, réessayer. Ne pas perdre texte.

## 19. ÉTATS OFFLINE

Signalement peut être mis en attente si produit le permet, avec message. Masquage local possible.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Desktop : menu contextuel ou modal. Mobile : bottom sheet. Admin/modérateur aura vue dédiée hors feed.

## 21. ACCESSIBILITÉ

Motifs radio/checkbox accessibles. Danger annoncé. Confirmation claire.

## 22. PERFORMANCE UX

Actions locales rapides. Envoi réseau non bloquant si possible.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Masquer local fonctionne. Signalement en attente possible. Aucun blocage plein écran.

## 24. RÈGLES NON NÉGOCIABLES

Pas de suppression accidentelle. Pas de signalement caché. Pas de langage humiliant. Pas d'action modération sans feedback.
