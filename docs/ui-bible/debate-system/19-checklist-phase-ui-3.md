# 19. CHECKLIST PHASE UI 3 POUR AGENT CODEUR IA

Avant d'implémenter le Debate System MAATFEED, l'agent doit vérifier :

## ✅ Structure Débat
- [ ] Le débat n'est jamais traité comme une simple section commentaire
- [ ] La question principale est toujours forte, lisible et prioritaire
- [ ] Les réponses sont hiérarchisées avec profondeur visible limitée
- [ ] Les sous-réponses ne dépassent pas deux niveaux visibles par défaut

## ✅ Composer & Réponses
- [ ] Le composer ne masque pas le contenu et ne perd jamais les brouillons
- [ ] Les formats texte, audio, vidéo, image, document et lien sont clairement différenciés
- [ ] L'audio a waveform, durée, play clair et fallback transcription si disponible
- [ ] La vidéo ne démarre jamais avec son automatiquement
- [ ] Les documents ne se chargent pas lourdement dans le thread

## ✅ Citations & Sources
- [ ] Les citations affichent toujours source et extrait court
- [ ] Les citations ne font pas sauter le scroll ou dominer la réponse

## ✅ Réactions & Qualité
- [ ] Les réactions restent nuancées et ne réduisent pas le débat à un like
- [ ] Les filtres restent lisibles et ne surchargent pas mobile
- [ ] Les badges qualité sont rares et pertinents

## ✅ IA Contextuelle
- [ ] Les réponses IA sont clairement identifiées comme IA
- [ ] L'IA aide sans dominer les humains
- [ ] L'IA ne publie jamais automatiquement

## ✅ Navigation & Performance
- [ ] Les états loading, erreur et offline préservent le sujet et les contenus déjà chargés
- [ ] Le signalement est accessible sans être agressif
- [ ] Les gestes mobiles sont doublés par boutons visibles
- [ ] Le retour depuis détail restaure position et contexte

## ✅ Desktop Workspace
- [ ] Le desktop devient un workspace premium, pas un dashboard
- [ ] Les panels sont indépendants mais cohérents
- [ ] Le design reste noir/or, culturel, intelligent, audio-first, débat-first et mobile-first

## ✅ Accessibilité & UX
- [ ] Tous les éléments sont focusables et labellisés
- [ ] Les contrastes sont suffisants
- [ ] Les gestes sont doublés par boutons
- [ ] Le débat reste lisible même dense

## ✅ Performance & Réseau
- [ ] Le texte et structure chargent avant médias lourds
- [ ] Les brouillons sont sauvegardés localement
- [ ] Les actions optimistes fonctionnent offline avec synchronisation
- [ ] Le mode faible connexion est supporté

*Checklist de validation pour l'implémentation Debate System*
