# 8. RÉPONSE IMAGE, PHOTO & DOCUMENT

## 1. OBJECTIF UX

Permettre d'appuyer un argument avec une image, une photo, une capture, un document ou une pièce de référence.

## 2. ÉMOTION RECHERCHÉE

Preuve, clarté, crédibilité. Les médias doivent soutenir le débat, pas devenir une galerie confuse.

## 3. STRUCTURE VISUELLE GLOBALE

Carte réponse avec auteur, texte d'accompagnement, aperçu média ou document, type, taille/durée si applicable, actions.

## 4. LAYOUT EXACT

Image unique : largeur 100 %, ratio respecté, hauteur max contrôlée.
Galerie : grille 2 colonnes ou carrousel horizontal.
Document : carte fichier avec icône, nom, type, taille, aperçu optionnel.
Texte d'accompagnement : au-dessus ou sous média.

## 5. HIERARCHIE VISUELLE

Argument/texte puis preuve média. Pour document, nom et type d'abord, preview ensuite.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Média sous le texte. Document dans sous-carte sombre séparé. Bouton ouvrir/télécharger à droite ou bas.

## 7. DIMENSIONS & ESPACEMENTS

Image radius : 14 à 18 px.
Image hauteur max mobile : 320 à 420 px.
Document bloc : 64 à 88 px.
Galerie écart : 6 à 8 px.

## 8. COULEURS

Aperçu sur fond noir. Bordure graphite. Document icône ambre/rouge doux. Badge type gris/or.

## 9. TYPOGRAPHIE

Nom fichier : 13 à 14 px.
Taille/type : 11 à 12 px.
Texte accompagnement : 14 à 15 px.

## 10. BOUTONS

Ouvrir, télécharger, citer, voir en plein écran, sauvegarder. Bouton supprimer seulement pour auteur/modération.

## 11. CARTES

Document dans sous-carte. Image dans média-card avec radius. Ne pas créer d'énorme bloc si média est secondaire.

## 12. ICONOGRAPHIE

Image, document, PDF, téléchargement, plein écran, citation, vérification.

## 13. COMPORTEMENT SCROLL

Images lazy-load. Documents n'affichent pas de preview lourde automatiquement. Ouvrir en viewer dédié.

## 14. ANIMATIONS

Image viewer : fade/zoom doux. Document download : progress. Galerie : scroll horizontal fluide.

## 15. MICRO INTERACTIONS

Tap image : plein écran. Tap document : viewer. Tap citer : ajoute référence au composer.

## 16. GESTURES MOBILE

Pinch zoom dans viewer image/document. Swipe entre images galerie. Swipe down ferme viewer.

## 17. ÉTATS LOADING

Image placeholder ratio réservé. Document preview skeleton. Download progress visible.

## 18. ÉTATS ERREUR

Image échouée : bloc fallback avec réessayer. Document indisponible : garder nom/type et message.

## 19. ÉTATS OFFLINE

Documents téléchargés lisibles. Images cache visibles. Upload de document en attente si réponse brouillon.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Desktop : viewer dans panneau ou modal large. Grilles plus larges possibles, mais rester lisibles.

## 21. ACCESSIBILITÉ

Alt text ou description si disponible. Nom document lisible. Type/taille annoncés.

## 22. PERFORMANCE UX

Compression images. Preview document légère. Pas de PDF complet dans le fil.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Images basse résolution d'abord. Documents à la demande. Upload résumable ou brouillon.

## 24. RÈGLES NON NÉGOCIABLES

Pas de document lourd chargé dans le thread. Pas d'image sans contexte. Pas de galerie qui casse la largeur mobile.
