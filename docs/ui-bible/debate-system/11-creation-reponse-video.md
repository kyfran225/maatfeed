# 11. CRÉATION D'UNE RÉPONSE VIDÉO

## 1. OBJECTIF UX

Permettre une réponse vidéo claire avec import, capture, preview, découpe simple, couverture et publication contrôlée.

## 2. ÉMOTION RECHERCHÉE

Maîtrise, expression, sécurité. L'utilisateur doit savoir exactement ce qu'il publie.

## 3. STRUCTURE VISUELLE GLOBALE

Flow en étapes : choisir vidéo ou caméra, preview, couper/cover, description, publier. Interface sombre avec CTA bas.

## 4. LAYOUT EXACT

Sélecteur média : liste de choix 56 à 72 px par option.
Preview vidéo : ratio 16:9 ou vertical selon source, max 60 % hauteur.
Timeline simple : hauteur 48 à 72 px.
CTA : bas sticky.

## 5. HIERARCHIE VISUELLE

Preview dominante. Actions édition simples. Description courte. Publier visible.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Preview en haut. Outils sous preview. Description sous outils. CTA bas. Retour haut gauche.

## 7. DIMENSIONS & ESPACEMENTS

Preview radius : 16 à 20 px.
Timeline marge : 16 px.
Outils : hitbox 44 px.
CTA : 48 à 52 px.

## 8. COULEURS

Fond noir. Outils surfaces sombres. Progress/trim or. Danger rouge pour supprimer.

## 9. TYPOGRAPHIE

Labels outils : 11 à 12 px. Description : 14 à 15 px. Durée : 12 px.

## 10. BOUTONS

Importer, caméra, couper, couverture, mute, supprimer, publier, enregistrer brouillon.

## 11. CARTES

Vidéo ajoutée dans composer devient carte preview avec poster, durée, statut upload.

## 12. ICONOGRAPHIE

Caméra, galerie, coupe, image couverture, volume, upload, check.

## 13. COMPORTEMENT SCROLL

Flow de création contrôlé. Clavier pour description ne masque pas CTA. Preview reste visible si possible.

## 14. ANIMATIONS

Import : progress. Trim : poignée fluide. Publication : progress clair.

## 15. MICRO INTERACTIONS

Tap couverture : choisir frame. Tap play : preview. Tap supprimer : confirmation.

## 16. GESTURES MOBILE

Scrub timeline. Swipe down ferme avec sauvegarde brouillon si média présent.

## 17. ÉTATS LOADING

Traitement vidéo : afficher étape. Upload : pourcentage. Compression : message "Optimisation de la vidéo".

## 18. ÉTATS ERREUR

Fichier trop lourd : proposer compression ou audio/texte. Upload échoué : garder vidéo locale.

## 19. ÉTATS OFFLINE

Vidéo peut être préparée en brouillon, publication attend connexion. Indiquer taille et recommandation Wi-Fi.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Desktop : drag and drop possible, preview plus grande. Mobile : import/caméra prioritaire.

## 21. ACCESSIBILITÉ

Boutons labellisés, durée visible, description possible, sous-titres si ajoutés.

## 22. PERFORMANCE UX

Compression avant upload. Pas de preview lourde multiple. Limiter durée selon règles produit.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Avertir sur data. Proposer réponse audio comme alternative légère. Upload différé.

## 24. RÈGLES NON NÉGOCIABLES

Pas de vidéo publiée sans aperçu. Pas d'upload qui bloque toute l'app. Pas de perte du fichier choisi.
