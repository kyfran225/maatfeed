# 2. CARTE VIDÉO FEED

## 1. OBJECTIF UX

Intégrer les vidéos dans le feed de manière premium, performante et non intrusive.

## 2. ÉMOTION RECHERCHÉE

Immersion contrôlée, découverte visuelle, respect de la data. La vidéo doit enrichir sans dominer.

## 3. STRUCTURE VISUELLE GLOBALE

Carte sombre avec poster, titre, créateur, durée, actions sociales. Pas d'autoplay agressif.

## 4. LAYOUT EXACT

Poster : ratio 16:9, pleine largeur utile.
Titre : 2-3 lignes max.
Créateur + métadonnées : 1 ligne.
Actions sociales : barre horizontale.
Hauteur totale : 280-340 px selon contenu.

## 5. HIERARCHIE VISUELLE

Poster d'abord, titre ensuite, créateur puis actions. La vidéo attire mais ne cache pas le contexte.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Poster haut. Titre sous poster (16 px écart). Créateur sous titre (6 px écart). Actions en bas (12 px écart).

## 7. DIMENSIONS & ESPACEMENTS

Radius poster : 16-20 px.
Padding carte : 16 px.
Écart éléments : voir layout.
Hitbox actions : 36-44 px.

## 8. COULEURS

Surface noire élevée.
Bordure graphite.
Poster avec overlay très léger si besoin.
Actions or/ gris selon état.

## 9. TYPOGRAPHIE

Titre : 16-18 px semibold.
Créateur : 13-14 px medium.
Métadonnées : 12 px.
Actions chiffres : 12 px.

## 10. BOUTONS

Play central sur poster (56-72 px). Actions sociales : like, commenter, partager, sauvegarder.

## 11. CARTES

Carte vidéo premium mais pas criarde. Respect du design system noir/or.

## 12. ICONOGRAPHIE

Play, like, commentaire, partage, bookmark. Icônes fines 20-22 px.

## 13. COMPORTEMENT SCROLL

Vidéo hors viewport se met en pause. Poster visible pendant scroll.

## 14. ANIMATIONS

Tap play : transition vers lecteur. Like/save : remplissage 120-180 ms. Pas d'animations lourdes dans feed.

## 15. MICRO INTERACTIONS

Hover poster : play légèrement plus visible. Press : feedback immédiat.

## 16. GESTURES MOBILE

Tap poster : lecture. Tap actions : fonction correspondante. Long press : menu options.

## 17. ÉTATS LOADING

Skeleton poster + lignes titre/créateur. Poster chargé avant autoplay éventuel.

## 18. ÉTATS ERREUR

Poster + message erreur + réessayer. Carte reste fonctionnelle.

## 19. ÉTATS OFFLINE

Poster visible. Indicateur "Connexion requise" pour lecture. Actions offline possibles.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile : layout décrit.
Tablet : cartes plus larges possible.
Desktop : peut ouvrir dans panneau droit.

## 21. ACCESSIBILITÉ

Titre accessible. Contrôles focusables. Durée annoncée.

## 22. PERFORMANCE UX

Poster compressé. Lazy-load vidéo. Pas d'autoplay en data limitée.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Poster prioritaire. Lecture manuelle. Option qualité basse. Audio-only possible.

## 24. RÈGLES NON NÉGOCIABLES

Pas d'autoplay sonore. Pas de vidéo qui bloque le feed. Pas de poster basse résolution flou.
