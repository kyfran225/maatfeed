# 6. CARTE CRÉATEUR/PROFIL FEED

## 1. OBJECTIF UX

Intégrer les profils créateurs dans le feed de manière élégante et incitative.

## 2. ÉMOTION RECHERCHÉE

Découverte, authenticité, connexion. L'utilisateur doit vouloir suivre et explorer.

## 3. STRUCTURE VISUELLE GLOBALE

Carte profil avec avatar, nom, bio courte, stats, badge vérifié, CTA suivre.

## 4. LAYOUT EXACT

Avatar : 64-88 px circulaire.
Nom : 1 ligne.
Bio : 2-3 lignes max.
Stats : abonnés, contenus, tendance.
Badge : petit cercle ou icône.
CTA : "Suivre" ou "Suivi".
Hauteur totale : 120-160 px.

## 5. HIERARCHIE VISUELLE

Avatar et nom d'abord, bio ensuite, stats puis CTA. Le créateur doit sembler accessible.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Avatar gauche, nom et bio à droite. Badge près du nom. Stats sous bio. CTA à droite ou en bas selon layout.

## 7. DIMENSIONS & ESPACEMENTS

Avatar radius : cercle parfait.
Padding carte : 16 px.
Écart avatar/nom : 12 px.
Écart nom/bio : 6 px.
Écart bio/stats : 8 px.
Écart stats/CTA : 12 px.

## 8. COULEURS

Surface noire élevée.
Bordure graphite.
Badge vérifié : or.
CTA : or (suivre) ou secondaire (suivi).
Texte : blanc chaud.

## 9. TYPOGRAPHIE

Nom : 16-18 px semibold.
Bio : 13-14 px regular.
Stats : 12-13 px medium.
CTA : 14-15 px medium.

## 10. BOUTONS

"Suivre" (or) ou "Suivi" (secondaire sombre). Menu options si déjà suivi.

## 11. CARTES

Carte profil premium mais accessible. Pas d'effets de célébrité excessifs.

## 12. ICONOGRAPHIE

Badge vérifié, stats icônes (personnes, contenu), menu options. Icônes fines 16-20 px.

## 13. COMPORTEMENT SCROLL

Cartes profil gardent leur état (suivi/non suivi). Stats peuvent s'incrémenter discrètement.

## 14. ANIMATIONS

CTA changement : transition douce. Badge : apparition subtile. Pas d'animations lourdes.

## 15. MICRO INTERACTIONS

Tap avatar : profil complet. Tap nom : profil. Tap CTA : follow/unfollow avec feedback immédiat.

## 16. GESTURES MOBILE

Long press : options créateur. Swipe : sauvegarder profil si pertinent.

## 17. ÉTATS LOADING

Skeleton avatar + lignes nom/bio + stats placeholder.

## 18. ÉTATS ERREUR

Avatar placeholder + info disponible + réessayer. Carte reste fonctionnelle.

## 19. ÉTATS OFFLINE

Profils consultés récemment accessibles. Stats locales. Follow mis en file d'attente.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile : layout décrit.
Tablet : avatar plus grand possible.
Desktop : peut inclure plus de détails et actions.

## 21. ACCESSIBILITÉ

Nom annoncé comme titre. Stats lisibles. Badge vérifié annoncé. CTA explicite.

## 22. PERFORMANCE UX

Avatar compressé. Bio limitée. Stats légères. Pas de médias lourds.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Avatar et texte prioritaires. Stats secondaires. Follow possible offline.

## 24. RÈGLES NON NÉGOCIABLES

Pas de profil sans avatar de secours. Pas de bio trop longue. Pas de stats illisibles. Pas de follow sans feedback.
