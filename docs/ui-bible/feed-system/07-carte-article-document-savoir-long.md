# 7. CARTE ARTICLE, DOCUMENT & SAVOIR LONG

## 1. OBJECTIF UX

Intégrer les articles, documents, fiches de savoir et contenus longs dans le feed sans casser le rythme média/audio.

## 2. ÉMOTION RECHERCHÉE

Sérieux, valeur, bibliothèque vivante. L'utilisateur doit sentir qu'il peut approfondir après avoir découvert.

## 3. STRUCTURE VISUELLE GLOBALE

Carte sombre avec icône document ou couverture, titre, extrait, durée de lecture, catégorie, actions sauvegarder/lire/télécharger.

## 4. LAYOUT EXACT

Couverture ou vignette : 72-120 px selon carte.
Titre : 2 lignes max.
Extrait : 2-3 lignes.
Footer : durée, type, sauvegarde.
CTA : "Lire" ou "Télécharger" si pertinent.

## 5. HIERARCHIE VISUELLE

Titre + catégorie d'abord. Extrait ensuite. Type/durée rassurent. CTA final.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Vignette gauche pour carte compacte, vignette haut pour carte immersive. Icône document visible près du titre ou sur vignette.

## 7. DIMENSIONS & ESPACEMENTS

Carte compacte : hauteur 112-150 px.
Carte large : 180-240 px.
Padding : 14-16 px.
Écart vignette/texte : 12 px.

## 8. COULEURS

Surface noire, bordure graphite. Icône document ambre/rouge doux selon type. Catégorie or.

## 9. TYPOGRAPHIE

Titre : 16-18 px semibold.
Extrait : 14 px.
Durée/type : 12 px.

## 10. BOUTONS

"Lire", "Sauvegarder", "Télécharger", "Partager", "Citer dans un débat". Le CTA principal peut être secondaire sombre si la carte n'est pas prioritaire.

## 11. CARTES

Les documents PDF doivent avoir une identité claire : mini-preview, nom fichier, taille, type. Les articles ressemblent plus à des cartes éditoriales.

## 12. ICONOGRAPHIE

Document, article, livre, lecture, téléchargement, citation. Icônes fines dans conteneurs arrondis.

## 13. COMPORTEMENT SCROLL

Les cartes longues ne doivent pas ralentir le feed. Extraits limités. Lire la suite ouvre détail.

## 14. ANIMATIONS

Ouverture article : transition page. Téléchargement : progress discret. Save : icône or.

## 15. MICRO INTERACTIONS

Tap extrait : ouvrir. Tap "Citer" : composer réponse avec référence. Tap téléchargement : file d'attente.

## 16. GESTURES MOBILE

Long press document : options. Swipe sauvegarder possible. Pas de preview lourde automatique.

## 17. ÉTATS LOADING

Skeleton titre/extrait/vignette. Preview document chargée après texte.

## 18. ÉTATS ERREUR

Document indisponible : carte reste, message et réessayer. Si preview échoue, afficher icône document.

## 19. ÉTATS OFFLINE

Documents téléchargés disponibles. Articles sauvegardés lisibles. Non téléchargés affichent état connexion requise.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Desktop : article peut s'ouvrir en panneau lecture à droite. Feed garde carte compacte. Tablet : split view possible.

## 21. ACCESSIBILITÉ

Titre, type, durée, taille fichier accessibles. Documents doivent avoir alternative ou résumé quand disponible.

## 22. PERFORMANCE UX

Ne pas rendre PDF lourd dans feed. Mini-preview légère ou icône. Chargement à la demande.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Le texte et résumé doivent primer sur preview. Téléchargement différé. Lecture hors ligne valorisée.

## 24. RÈGLES NON NÉGOCIABLES

Pas de PDF lourd injecté directement dans feed. Pas de carte document sans type/taille. Pas d'article illisible en police minuscule.
