# 1. FEED STRUCTURE & HEADER

## 1. OBJECTIF UX

Créer une structure de feed premium qui combine découverte, navigation et action sans surcharge visuelle.

## 2. ÉMOTION RECHERCHÉE

Clarté, immersion, contrôle. L'utilisateur doit sentir qu'il entre dans un espace culturel organisé.

## 3. STRUCTURE VISUELLE GLOBALE

Header compact + tabs + feed vertical + bottom nav. Le header reste discret mais utile.

## 4. LAYOUT EXACT

Header : 52 à 60 px hauteur.
Tabs : 40 à 48 px hauteur.
Feed : colonne centrale 100 % largeur utile.
Bottom nav : 64 à 76 px + safe area.

## 5. HIERARCHIE VISUELLE

Header secondaire, tabs pour navigation, feed principal. Le contenu domine, pas l'interface.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Header : logo gauche, actions droite (recherche, notifications).
Tabs : centrées, indicateur doré sous actif.
Feed : marge 16 px, espacement 16-20 px entre cartes.

## 7. DIMENSIONS & ESPACEMENTS

Header padding : 16 px latéral.
Tabs padding : 12 px latéral.
Écart carte feed : 16 à 20 px.
Safe areas respectées.

## 8. COULEURS

Header fond noir charbon.
Tabs fond noir surface.
Indicateur actif or.
Texte blanc chaud.

## 9. TYPOGRAPHIE

Header titre : 16 à 18 px semibold.
Tabs : 13 à 14 px medium.
Contenu feed selon type.

## 10. BOUTONS

Header : recherche, notifications, profil si pas bottom nav.
Hitbox 44 px minimum.

## 11. CARTES

Les cartes feed suivent les specs détaillées dans les sections suivantes.

## 12. ICONOGRAPHIE

Icônes fines 20-22 px. Recherche, notification, paramètres si header.

## 13. COMPORTEMENT SCROLL

Header peut se réduire légèrement au scroll (8-12 px). Tabs restent visibles. Bottom nav fixe.

## 14. ANIMATIONS

Header réduction : 200-280 ms. Tabs changement : 160-220 ms. Cartes apparition : fade léger.

## 15. MICRO INTERACTIONS

Tap header logo : retour haut feed. Tap recherche : ouverture page recherche. Tap notification : centre notifications.

## 16. GESTURES MOBILE

Pull to refresh depuis header. Swipe entre tabs. Scroll vertical feed principal.

## 17. ÉTATS LOADING

Skeleton header + tabs immédiat. Feed charge par blocs.

## 18. ÉTATS ERREUR

Erreur feed : carte erreur centrale avec réessayer. Header reste fonctionnel.

## 19. ÉTATS OFFLINE

Header affiche indicateur offline discret. Tabs fonctionnelles avec cache.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile : structure décrite.
Tablet : header peut inclure plus d'actions.
Desktop : header devient top bar avec navigation latérale.

## 21. ACCESSIBILITÉ

Header navigation clavier. Tabs focusables. Structure logique pour lecteurs d'écran.

## 22. PERFORMANCE UX

Header léger, pas de blur lourd. Tabs rapides. Scroll fluide à 60fps.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Header instantané. Tabs immédiates. Feed affiche cache d'abord.

## 24. RÈGLES NON NÉGOCIABLES

Header ne doit pas dominer le feed. Tabs doivent garder leur état. Scroll ne doit pas cacher la navigation.
