# 19. FEED DESKTOP MULTI-PANEL

## 1. OBJECTIF UX

Transformer le feed en workspace premium sur desktop, sans perdre l'ADN mobile. Le desktop doit permettre exploration, lecture, écoute et débat en parallèle.

## 2. ÉMOTION RECHERCHÉE

Puissance calme, studio culturel, contrôle avancé. L'utilisateur doit sentir qu'il a une table de travail MAATFEED devant lui.

## 3. STRUCTURE VISUELLE GLOBALE

Trois à quatre zones : sidebar gauche, feed central, panneau détail/débat à droite, player sticky bas ou extrême droite.

## 4. LAYOUT EXACT

Sidebar : 240-280 px.
Feed central : 460-560 px.
Panneau détail : 520-680 px.
Panneau player/contexte : 300-360 px si écran large.
Gouttières : 16-24 px.

## 5. HIERARCHIE VISUELLE

Feed central reste point de départ. Panneau droit montre le détail de la carte sélectionnée. Player reste visible sans dominer.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Sidebar gauche fixe avec navigation. Feed central scrollable. Détail droit scrollable indépendamment. Player sticky bas ou droit.

## 7. DIMENSIONS & ESPACEMENTS

Panels padding 20-24 px. Radius panels 20-28 px. Cartes feed même style mobile mais largeur desktop contrôlée.

## 8. COULEURS

Fond global noir. Panels surfaces légèrement différentes. Bordures graphite. Accent or pour actif.

## 9. TYPOGRAPHIE

Sidebar labels : 14 px. Feed titres : 18-20 px. Détail titres : 22-28 px selon contenu.

## 10. BOUTONS

Sidebar items, CTA créer, player controls, actions détail. Desktop peut afficher plus de labels avec icônes.

## 11. CARTES

Cliquer une carte peut ouvrir détail à droite sans quitter le feed. Double clic ou bouton peut ouvrir page complète.

## 12. ICONOGRAPHIE

Sidebar : icônes + labels. Panneau droit : actions clairement groupées. Player : contrôles audio riches.

## 13. COMPORTEMENT SCROLL

Scroll indépendant par panel. La sélection de carte dans le feed peut rester surlignée. Le player ne bouge pas.

## 14. ANIMATIONS

Ouverture panneau droit : slide/fade 220-320 ms. Sélection carte : bordure or faible. Hover cartes : élévation douce.

## 15. MICRO INTERACTIONS

Hover révèle options. Raccourcis clavier possibles : lecture/pause, sauvegarder, répondre, recherche.

## 16. GESTURES MOBILE

Sur desktop tactile/tablet, garder scroll naturel. Souris : hover, clic, wheel.

## 17. ÉTATS LOADING

Chaque panel skeleton séparé. Le feed ne se vide pas si le détail charge.

## 18. ÉTATS ERREUR

Erreur panneau droit localisée. Feed utilisable. Player stable.

## 19. ÉTATS OFFLINE

Sidebar indique offline. Feed cache central. Panneau droit montre détail cache ou message local.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Desktop complet à partir d'environ 1024 px. En dessous, passer à deux panels ou mobile. Ne pas compresser quatre panels.

## 21. ACCESSIBILITÉ

Navigation clavier complète. Focus visible. Ordre logique : sidebar, feed, détail, player.

## 22. PERFORMANCE UX

Ne charger panneau droit qu'à la sélection. Limiter lecteurs actifs. Virtualiser longues listes si nécessaire.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Même desktop : charger texte/détails d'abord. Vidéos à la demande. Audio prioritaire.

## 24. RÈGLES NON NÉGOCIABLES

Desktop ne doit pas devenir un dashboard SaaS. Pas de tableaux froids dans le feed. Pas de feed étiré pleine largeur. Garder l'immersion noire/or.
