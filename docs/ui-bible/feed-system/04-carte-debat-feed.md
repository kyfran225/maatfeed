# 4. CARTE DÉBAT FEED

## 1. OBJECTIF UX

Mettre en avant les débats de manière noble, lisible et engageante dans le feed.

## 2. ÉMOTION RECHERCHÉE

Intelligence, respect, curiosité. Le débat doit sembler important mais accessible.

## 3. STRUCTURE VISUELLE GLOBALE

Carte débat avec question en vedette, auteur, stats, extrait de réponses, CTA répondre.

## 4. LAYOUT EXACT

Question : 2-3 lignes max, typographie forte.
Auteur/modérateur : avatar + nom + badge si modérateur.
Stats : nombre de réponses, participants, tendance.
Extrait : 1-2 réponses courtes.
CTA : "Répondre au débat" ou "Voir les réponses".
Hauteur totale : 180-240 px selon contenu.

## 5. HIERARCHIE VISUELLE

Question d'abord, stats ensuite, extrait puis CTA. La question doit dominer visuellement.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Question en haut, auteur juste sous question. Stats à droite ou sous auteur. Extrait sous stats. CTA en bas.

## 7. DIMENSIONS & ESPACEMENTS

Padding carte : 16 px.
Avatar : 32-36 px.
Écart question/auteur : 8 px.
Écart auteur/stats : 6 px.
Écart stats/extrait : 12 px.
Écart extrait/CTA : 16 px.

## 8. COULEURS

Surface noire élevée.
Bordure graphite.
Question : blanc chaud.
Stats : gris clair.
Extrait : gris moyen.
CTA : or ou secondaire sombre.

## 9. TYPOGRAPHIE

Question : 17-19 px semibold.
Auteur : 13-14 px medium.
Stats : 12-13 px.
Extrait : 13-14 px regular.
CTA : 14-15 px medium.

## 10. BOUTONS

CTA principal : "Répondre" (or si action principale).
CTA secondaire : "Voir tout" (secondaire sombre).
Menu options : haut droite.

## 11. CARTES

Carte débat premium, distincte des cartes média. Pas d'image sauf si essentielle au débat.

## 12. ICONOGRAPHIE

Badge modérateur, icônes stats (bulles, utilisateurs), flèche réponse, menu options.

## 13. COMPORTEMENT SCROLL

Carte débat reste lisible pendant scroll. Stats peuvent s'incrémenter après nouvelle réponse.

## 14. ANIMATIONS

CTA répond au press. Extrait peut changer au refresh mais sans mouvement brusque.

## 15. MICRO INTERACTIONS

Tap question : page détail. Tap CTA : composer réponse ou détail. Tap extrait : réponse détail.

## 16. GESTURES MOBILE

Long press : menu. Swipe sauvegarder si disponible. Pas de double tap like sur la question.

## 17. ÉTATS LOADING

Skeleton question + stats + extrait. Si réponses non chargées, afficher question et CTA d'abord.

## 18. ÉTATS ERREUR

Si réponses échouent, la carte reste avec question + CTA. Message "Réponses indisponibles pour l'instant".

## 19. ÉTATS OFFLINE

Débats déjà ouverts restent lisibles. Réponse peut être rédigée en brouillon. Envoi mis en attente.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Desktop : carte débat dans feed peut ouvrir détail dans panneau droit. Les stats peuvent être plus détaillées au hover.

## 21. ACCESSIBILITÉ

Question annoncée comme titre. Stats lisibles textuellement. CTA explicite.

## 22. PERFORMANCE UX

Chargement prioritaire de la question. Réponses et avatars après. Pas de média lourd dans la carte débat.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Le débat texte doit charger vite. Les réponses audio/vidéo peuvent être différées. Le brouillon offline est essentiel.

## 24. RÈGLES NON NÉGOCIABLES

Pas de débat noyé comme commentaire ordinaire. Pas de ton agressif visuel. Pas de réponse perdue si connexion coupe.
