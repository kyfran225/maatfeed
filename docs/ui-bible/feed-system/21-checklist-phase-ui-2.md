# 21. CHECKLIST PHASE UI 2 POUR AGENT CODEUR IA

Avant d'implémenter le Feed System MAATFEED, l'agent doit vérifier :

## ✅ Structure Feed
- [ ] Le feed mobile est une colonne premium, pas une timeline générique
- [ ] Le header est utile mais discret
- [ ] Les tabs "Pour toi / Abonnements / Tendances" gardent leur position et leur état
- [ ] Le retour depuis détail restaure exactement le scroll

## ✅ Cartes Média
- [ ] Les cartes vidéo ne lancent pas de lecture lourde agressive en réseau faible
- [ ] Les cartes audio sont visuellement fortes, avec waveform/progression
- [ ] Les cartes débat sont nobles, lisibles et orientées réponse
- [ ] Les cartes série montrent progression et épisode actuel
- [ ] Les cartes créateur/profil sont accessibles et incitatives

## ✅ Contenus Longs
- [ ] Les articles/documents ont des identités claires (type, taille, durée)
- [ ] Les contenus longs ne chargent pas de preview lourde dans le feed

## ✅ Monétisation
- [ ] Les sponsors sont clairement identifiés et élégants
- [ ] Pas de sponsor déguisé ou agressif
- [ ] La fréquence des sponsors est maîtrisée

## ✅ Actions Sociales
- [ ] Les actions sociales ont feedback immédiat
- [ ] Les actions optimistes fonctionnent offline avec synchronisation
- [ ] Les gestes mobiles sont naturels et doublés par boutons

## ✅ Audio Continu
- [ ] Le mini-player reste stable au-dessus de la bottom nav
- [ ] L'audio continue pendant la navigation
- [ ] Les vidéos hors viewport se mettent en pause

## ✅ Navigation
- [ ] La bottom nav ne cache jamais une action
- [ ] Les overlays média sont contrôlés et lisibles
- [ ] Les filtres rapides sont accessibles mais non envahissants

## ✅ Performance
- [ ] Les skeletons réservent les dimensions finales
- [ ] Les erreurs n'effacent pas le feed existant
- [ ] Le mode offline affiche cache, audios téléchargés et brouillons

## ✅ Personnalisation
- [ ] Le feed personnalisé reste varié et non monolithique
- [ ] Les labels contextuels sont discrets et utiles
- [ ] Le cold start ne bloque pas l'utilisateur

## ✅ Desktop
- [ ] Le feed desktop est multi-panel, pas étiré
- [ ] Les panels ont des scrolls indépendants
- [ ] Le design reste noir/or, culturel, premium

## ✅ Qualité Éditoriale
- [ ] Le rythme du feed évite la fatigue et la monotonie
- [ ] Les contenus sont variés (vidéo, audio, débat, série)
- [ ] Les modules éditoriaux sont rares et pertinents

## ✅ Accessibilité
- [ ] Tous les éléments sont focusables et labellisés
- [ ] Les contrastes sont suffisants
- [ ] Les gestes sont doublés par boutons
