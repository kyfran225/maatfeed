# 13. CHECKLIST AGENT CODEUR — NOTIFICATIONS, INBOX & ACTIVITY SYSTEM

## 1. OBJECTIF UX

Donner à l'agent codeur une checklist complète pour implémenter le système sans improvisation, sans bruit excessif et sans rupture avec l'identité MAATFEED.

## 2. ÉMOTION RECHERCHÉE

Précision.

L'implémentation doit produire un système fiable, calme, intelligent et actionnable.

## 3. STRUCTURE VISUELLE GLOBALE

À livrer :

- badge global
- page Notifications
- Inbox intelligente
- Centre d'activité
- filtres
- onglets
- groupements
- états lu/non-lu
- push/email preferences
- offline
- faible connexion
- responsive complet

## 4. LAYOUT EXACT

Vérifier :

- mobile une colonne
- desktop trois zones
- tablet deux zones
- header sticky modéré
- bottom nav respectée
- mini-player respecté
- safe areas

## 5. HIERARCHIE VISUELLE

Vérifier priorité :

1. sécurité
2. réponses directes
3. mentions
4. débats
5. séries
6. audios
7. créateurs
8. recommandations
9. système

## 6. POSITIONNEMENT DES ÉLÉMENTS

Vérifier :

- badge bien aligné
- filtres visibles
- actions principales accessibles
- préférences disponibles
- détails disponibles sans surcharge

## 7. DIMENSIONS & ESPACEMENTS

Vérifier :

- touch target minimum 44 px
- cartes 72 à 148 px selon type
- badges lisibles
- padding 14 à 16 px
- gaps réguliers
- pas de collage visuel

## 8. COULEURS

Vérifier :

- noir charbon
- graphite chaud
- ambre/or
- cuivre/ocre pour priorité
- non-lu subtil
- aucun rouge agressif inutile
- aucun bleu SaaS

## 9. TYPOGRAPHIE

Vérifier :

- titres courts
- descriptions 1 à 2 lignes
- métadonnées lisibles
- compteur non envahissant
- pas de texte minuscule

## 10. BOUTONS

Vérifier :

- ouvrir
- répondre
- écouter
- reprendre
- marquer lu
- archiver
- préférences
- mode léger
- réessayer

## 11. CARTES

Créer cartes pour :

- notification globale
- débat
- audio
- créateur
- série
- réponse multimédia
- sécurité
- système
- groupe
- inbox category
- timeline activity

## 12. ICONOGRAPHIE

Vérifier :

- icônes cohérentes
- cloche
- débat
- audio
- série
- créateur
- source
- sécurité
- archive
- offline

## 13. COMPORTEMENT SCROLL

Vérifier :

- scroll fluide
- groupements
- sticky contrôlé
- pas de saut
- conservation position
- pagination

## 14. ANIMATIONS

Vérifier :

- transitions sobres
- skeleton doux
- hover desktop
- focus search
- réduction motion
- passage lu/non-lu

## 15. MICRO INTERACTIONS

Vérifier :

- tap carte
- long press
- swipe lu/archive
- hover desktop
- undo archive
- feedback offline
- action en attente

## 16. GESTURES MOBILE

Vérifier :

- swipe gauche/droite
- long press
- pull-to-refresh
- swipe onglets
- alternatives visibles

## 17. ÉTATS LOADING

Vérifier :

- skeleton header
- skeleton onglets
- skeleton cartes
- skeleton timeline
- pas de spinner solitaire

## 18. ÉTATS ERREUR

Vérifier :

- erreur globale
- erreur partielle
- erreur contenu supprimé
- erreur action
- retry
- fallback cache

## 19. ÉTATS OFFLINE

Vérifier :

- notifications cache
- inbox cache
- actions en attente
- sync différée
- badge non actualisé indiqué
- contenus disponibles offline

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Tester :

- petit mobile
- grand mobile
- tablet portrait
- tablet paysage
- desktop
- desktop large
- zoom navigateur
- mini-player actif

## 21. ACCESSIBILITÉ

Vérifier :

- état lu/non-lu textuel
- focus visible
- labels
- lecteur d'écran
- navigation clavier
- réduction motion
- contrastes
- actions destructives confirmées

## 22. PERFORMANCE UX

Vérifier :

- compteur rapide
- cache-first
- pagination
- groupement
- lazy-load
- pas de média lourd
- sync différée
- actions optimistes sûres

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Vérifier :

- texte avant média
- offline utile
- mode léger
- push légères
- emails groupés
- pas de refresh agressif
- pas de blocage réseau

## 24. RÈGLES NON NÉGOCIABLES

- Ne pas créer un système bruyant
- Ne pas spammer l'utilisateur
- Ne pas mélanger inbox et activité
- Ne pas cacher les réponses directes
- Ne pas casser le mini-player audio
- Ne pas perdre les actions offline
- Ne pas afficher de badges anxiogènes
- Ne pas utiliser de design SaaS froid
- Ne pas ignorer les débats
- Ne pas ignorer l'audio
- Ne pas oublier les préférences utilisateur
