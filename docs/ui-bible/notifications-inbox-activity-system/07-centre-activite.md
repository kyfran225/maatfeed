# 7. CENTRE D'ACTIVITÉ

## 1. OBJECTIF UX

Donner à l'utilisateur une vision plus complète de son activité et des événements autour de lui : contenus publiés, réponses reçues, débats suivis, écoutes, sauvegardes, soutiens, modération.

## 2. ÉMOTION RECHERCHÉE

Mémoire vivante.

Le centre d'activité doit ressembler à un journal de bord intelligent, pas à un historique brut.

## 3. STRUCTURE VISUELLE GLOBALE

Sections :

- activité personnelle
- activité sociale
- activité créateur
- activité audio
- activité débat
- activité séries
- activité système
- historique des actions

## 4. LAYOUT EXACT

### Mobile :

- timeline verticale
- filtres horizontaux
- regroupement par jour
- cartes compactes

### Desktop :

- timeline centrale
- filtres à gauche
- statistiques rapides à droite

## 5. HIERARCHIE VISUELLE

Priorité :

1. actions récentes importantes
2. jalons personnels
3. interactions sociales
4. historiques simples
5. événements anciens

## 6. POSITIONNEMENT DES ÉLÉMENTS

Le centre d'activité doit être séparé de l'inbox.

Accès possible depuis :

- profil
- notifications
- paramètres
- tableau créateur

## 7. DIMENSIONS & ESPACEMENTS

- timeline item : 72 à 120 px
- date group : 28 px
- icône : 36 à 42 px
- ligne timeline : 1 px
- gap : 12 px
- padding : 16 px

## 8. COULEURS

### Timeline :

- ligne brun/or faible
- points ambre
- cartes graphite
- jalons or doux
- système gris chaud

## 9. TYPOGRAPHIE

- date : 12 à 13 px
- action : 14 à 16 px
- détail : 12 à 14 px
- métadonnées : 11 px

## 10. BOUTONS

Actions :

- ouvrir
- filtrer
- exporter si pertinent plus tard
- masquer
- gérer historique
- voir détails

## 11. CARTES

Carte activité :

- icône type
- action
- objet lié
- temps
- action possible

Exemples :

- "Tu as sauvegardé une série."
- "Ton débat a reçu 12 réponses."
- "Tu as terminé un audio."

## 12. ICONOGRAPHIE

- timeline
- point
- audio
- débat
- série
- sauvegarde
- publication
- soutien
- modération

## 13. COMPORTEMENT SCROLL

Timeline infinie progressive.

Chargement par périodes.

Retour position conservé.

## 14. ANIMATIONS

- apparition par jour
- ligne timeline qui se révèle doucement
- filtre transition
- jalon avec halo léger

## 15. MICRO INTERACTIONS

- tap item ouvre objet
- long press options
- filtre actif visible
- jalon partageable si pertinent

## 16. GESTURES MOBILE

- swipe filtres
- long press item
- pull-to-refresh
- scroll rapide par mois si historique long

## 17. ÉTATS LOADING

Skeleton timeline :

- ligne
- points
- cartes

## 18. ÉTATS ERREUR

Si activité indisponible :

- afficher activité locale
- message :
  "Certaines activités ne sont pas encore synchronisées."

## 19. ÉTATS OFFLINE

Offline :

- activité locale visible
- actions récentes en attente
- statut de synchronisation

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- timeline simple

### Tablet :

- timeline + filtres

### Desktop :

- timeline + statistiques + filtres

## 21. ACCESSIBILITÉ

- timeline lisible sans ligne visuelle
- actions annoncées
- dates compréhensibles
- navigation clavier

## 22. PERFORMANCE UX

- pagination temporelle
- cache
- virtualisation si long
- pas de médias lourds

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- activité textuelle
- synchronisation différée
- historique local
- pas de miniatures obligatoires

## 24. RÈGLES NON NÉGOCIABLES

- Centre d'activité ≠ inbox
- Il doit raconter le parcours
- Il ne doit pas être anxiogène
- Il doit rester filtrable
- Il doit fonctionner avec données partielles
