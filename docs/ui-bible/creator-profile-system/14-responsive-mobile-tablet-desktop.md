# 14. RESPONSIVE MOBILE, TABLET ET DESKTOP

## 1. OBJECTIF UX

Adapter le profil à chaque taille d'écran sans changer son identité.

Mobile reste la référence. Desktop enrichit sans transformer l'expérience en tableau de bord.

## 2. ÉMOTION RECHERCHÉE

### Mobile :

- proximité
- fluidité
- simplicité

### Tablet :

- confort
- lecture étendue

### Desktop :

- profondeur
- exploration
- maîtrise

## 3. STRUCTURE VISUELLE GLOBALE

### Mobile :

- une colonne
- header compactable
- tabs sticky
- feed vertical

### Tablet :

- deux colonnes possibles
- header split

### Desktop :

- trois colonnes
- identité sticky
- contenu central
- panneau contextuel

## 4. LAYOUT EXACT

### Mobile :

- largeur 100 %
- padding 16 px
- avatar 96 px
- tabs scrollables

### Tablet :

- padding 24 px
- avatar 120 px
- grille 2 colonnes pour séries

### Desktop :

- max container 1180 à 1360 px
- colonne gauche 300 px
- centre 680 px
- droite 340 px

## 5. HIERARCHIE VISUELLE

### Mobile :

- identité
- action
- onglets
- contenu

### Desktop :

- identité
- contenu
- contexte
- stats

## 6. POSITIONNEMENT DES ÉLÉMENTS

### Mobile :

- vertical

### Tablet :

- identité et actions côte à côte

### Desktop :

- identité gauche
- contenu centre
- séries/soutien droite

## 7. DIMENSIONS & ESPACEMENTS

### Mobile :

- gap 16 px

### Tablet :

- gap 20 px

### Desktop :

- gap 24 à 32 px

## 8. COULEURS

Palette identique.

Desktop peut utiliser plus de surfaces séparées, mais toujours très sombre.

## 9. TYPOGRAPHIE

### Mobile :

- texte plus compact

### Desktop :

- titres plus grands
- line-height confortable
- pas d'augmentation excessive

## 10. BOUTONS

### Mobile :

- actions réduites

### Desktop :

- labels visibles
- actions secondaires exposées

## 11. CARTES

### Mobile :

- cartes pleine largeur

### Tablet :

- grille 2 colonnes

### Desktop :

- mix feed + grille selon contenu

## 12. ICONOGRAPHIE

### Mobile :

- icône + label minimal

### Desktop :

- icône + texte plus souvent

## 13. COMPORTEMENT SCROLL

### Mobile :

- header compact + tabs sticky

### Desktop :

- colonnes sticky contrôlées

## 14. ANIMATIONS

Même langage, mais desktop peut avoir hover.

Mobile privilégie transitions tactiles.

## 15. MICRO INTERACTIONS

### Desktop :

- hover options
- tooltips courts
- focus clavier

### Mobile :

- tap
- long press
- swipe tabs

## 16. GESTURES MOBILE

### Mobile uniquement :

- swipe tabs
- pull refresh
- long press

### Tablet tactile :

- mêmes gestes, moins sensibles

## 17. ÉTATS LOADING

Skeleton adapté :

- mobile vertical
- desktop multi-colonnes

## 18. ÉTATS ERREUR

Erreur par zone.

Desktop ne doit pas afficher trop de messages simultanés.

## 19. ÉTATS OFFLINE

Offline visible partout.

Mobile prioritaire pour offline.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Règle :

- mobile = essentiel
- tablet = confort
- desktop = exploration

## 21. ACCESSIBILITÉ

Toutes les adaptations doivent rester accessibles :

- clavier desktop
- touch mobile
- focus
- labels

## 22. PERFORMANCE UX

Desktop ne doit pas charger tout.

Mobile ne doit pas sacrifier les contenus importants.

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Mobile faible connexion prioritaire :

- texte
- cache
- images légères
- pagination

## 24. RÈGLES NON NÉGOCIABLES

- Mobile reste la base
- Desktop ne devient pas SaaS
- Les mêmes contenus doivent être trouvables partout
- Les onglets doivent rester cohérents
- La performance mobile prime
