## 🎨 PRINCIPES À APPLIQUER

### Recherche Culturelle
- La recherche doit révéler le savoir africain
- Les résultats doivent valoriser la crédibilité
- Les suggestions doivent être culturellement pertinentes
- Pas de recherche purement algorithmique toxique

### Découverte Saine
- Les tendances ne doivent pas être virales toxiques
- La popularité doit être pondérée par la crédibilité
- Les recommandations doivent ouvrir des horizons
- Pas de bulles de filtres excessives

### Navigation par Connaissances
- Les contenus doivent être connectés par sens
- Les parcours d'apprentissage doivent être naturels
- La carte du savoir doit être exploratoire
- Les liens doivent être explicites et utiles

### Performance Robuste
- La recherche doit fonctionner même avec réseau faible
- Les résultats doivent apparaître rapidement
- Le cache doit être intelligent
- L'offline doit permettre les recherches de base

## 🎯 PRINCIPE CENTRAL DE LA PHASE UI 7

La découverte MAATFEED ne doit pas être une simple barre de recherche. Elle doit devenir une carte vivante du savoir africain, des débats, des voix, des séries et des chemins d'apprentissage.

Chaque recherche doit pouvoir :

- Révéler des connexions inattendues
- Proposer des parcours d'apprentissage
- Mettre en avant des voix crédibles
- Explorer la richesse culturelle
- Éviter les bulles toxiques
- Fonctionner même avec faible connexion

La recherche devient exploration, pas consommation.
