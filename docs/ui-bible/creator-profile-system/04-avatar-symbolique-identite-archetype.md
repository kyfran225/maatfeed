# 4. AVATAR SYMBOLIQUE, IDENTITÉ ET ARCHÉTYPE

## 1. OBJECTIF UX

MAATFEED doit utiliser les avatars comme marqueurs d'identité culturelle et intellectuelle, pas comme simples photos de profil génériques.

L'avatar doit représenter :

- posture intellectuelle
- centres d'intérêt
- style de participation
- préférence de contenu
- appartenance à l'univers MAATFEED

## 2. ÉMOTION RECHERCHÉE

L'avatar doit donner une impression de mystère, noblesse, spiritualité ou intelligence visuelle.

Il doit être reconnaissable, mais pas caricatural.

## 3. STRUCTURE VISUELLE GLOBALE

Système :

- avatar symbolique
- nom d'archétype
- courte signification
- centres d'intérêt associés
- influence sur recommandations
- style visuel cohérent

Exemples d'archétypes possibles :

- Scribe
- Gardien de la Mémoire
- Débatteur
- Chercheur
- Sage MAAT
- Bâtisseur Communautaire
- Explorateur Spirituel
- Analyste Historique

## 4. LAYOUT EXACT

### Sur profil :

- avatar visible dans header
- archétype sous pseudo
- tap ouvre fiche archétype
- édition depuis profil

### Dans onboarding :

- grille d'avatars
- preview profil
- signification courte

## 5. HIERARCHIE VISUELLE

Priorité :

1. symbole visuel
2. nom
3. signification
4. intérêts associés
5. personnalisation

L'avatar doit être compris même sans texte long.

## 6. POSITIONNEMENT DES ÉLÉMENTS

- avatar centré dans cercle ou médaillon
- nom archétype sous pseudo
- badge discret près avatar
- fiche détail en sheet

## 7. DIMENSIONS & ESPACEMENTS

- avatar profil mobile : 96 à 128 px
- avatar feed : 36 à 48 px
- avatar commentaire : 32 à 40 px
- avatar desktop profil : 140 à 168 px
- fiche archétype : 70 à 85 % hauteur mobile

## 8. COULEURS

- fond avatar : noir profond
- symbole : ambre, ivoire, cuivre ou sable
- halo actif : ambre faible
- archétype sélectionné : bordure or
- non sélectionné : gris chaud

## 9. TYPOGRAPHIE

- nom archétype : 12 à 14 px
- fiche titre : 22 à 26 px
- description : 14 à 16 px
- intérêts : 12 px

## 10. BOUTONS

- changer avatar
- voir signification
- choisir
- personnaliser
- réinitialiser

## 11. CARTES

Cartes :

- carte avatar
- carte archétype
- carte intérêts
- carte preview profil

## 12. ICONOGRAPHIE

Icônes abstraites :

- papyrus
- étoile
- balance
- cercle solaire
- onde
- pyramide stylisée
- plume
- constellation
- masque symbolique non humain

Éviter visages humains, portraits réalistes et avatars trop cartoon.

## 13. COMPORTEMENT SCROLL

La grille d'avatars peut scroller verticalement.

La sélection doit rester mémorisée.

## 14. ANIMATIONS

- sélection : halo ambre
- changement avatar : crossfade
- fiche archétype : montée douce
- preview : mise à jour fluide

## 15. MICRO INTERACTIONS

- tap avatar : agrandir
- long press : aperçu signification
- sélection : vibration visuelle douce
- archétype actif : mini glow

## 16. GESTURES MOBILE

- swipe entre avatars en preview
- tap choisir
- swipe down fiche
- pas de drag complexe

## 17. ÉTATS LOADING

- avatar skeleton rond
- grille progressive
- fallback symbole générique

## 18. ÉTATS ERREUR

- avatar non chargé
- sélection impossible
- image indisponible

Fallback obligatoire : symbole MAATFEED neutre.

## 19. ÉTATS OFFLINE

- avatar actuel disponible en cache
- changement gardé localement
- sync plus tard

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- grille 2 ou 3 colonnes

### Tablet :

- grille 4 colonnes

### Desktop :

- grille large + preview profil

## 21. ACCESSIBILITÉ

- description textuelle avatar
- nom d'archétype
- contraste
- sélection non basée uniquement couleur

## 22. PERFORMANCE UX

- avatars légers
- vectoriel ou images optimisées
- lazy load
- cache durable

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- charger symboles légers
- fallback local
- pas de grosses images
- sélection possible offline

## 24. RÈGLES NON NÉGOCIABLES

- Pas d'avatar générique sans âme
- Pas de portraits humains pour les personnalités IA
- Les avatars doivent être cohérents avec MAATFEED
- Chaque avatar doit avoir une signification
- L'avatar ne doit pas ralentir le profil
- L'utilisateur doit pouvoir comprendre son archétype
