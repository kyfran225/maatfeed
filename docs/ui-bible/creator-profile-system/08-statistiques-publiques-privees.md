# 8. STATISTIQUES PUBLIQUES ET PRIVÉES

## 1. OBJECTIF UX

Afficher les statistiques utiles sans transformer MAATFEED en machine à anxiété.

Il faut distinguer :

- statistiques publiques
- statistiques privées créateur
- indicateurs de qualité
- historique personnel

## 2. ÉMOTION RECHERCHÉE

Les stats doivent donner une sensation de progression, pas de pression.

## 3. STRUCTURE VISUELLE GLOBALE

### Stats publiques possibles :

- abonnés
- contenus
- séries
- débats lancés
- contributions utiles

### Stats privées :

- vues
- écoutes
- taux de complétion audio
- sauvegardes
- soutiens
- progression séries
- engagement par format

## 4. LAYOUT EXACT

### Mobile :

- stats publiques en row compacte
- stats privées dans page créateur
- graphiques très simples

### Desktop :

- stats publiques header
- analytics privées dans panneau dédié

## 5. HIERARCHIE VISUELLE

### Priorité publique :

1. contribution
2. séries
3. abonnés
4. débats

### Priorité privée :

1. performance contenu
2. fidélité audience
3. écoutes
4. revenus si activés

## 6. POSITIONNEMENT DES ÉLÉMENTS

- stats publiques sous action
- stats privées dans onglet ou dashboard créateur léger
- insights dans cartes

## 7. DIMENSIONS & ESPACEMENTS

- stat publique : largeur égale
- hauteur : 56 à 72 px
- carte insight : 100 à 160 px
- graphique mobile : 160 à 220 px hauteur

## 8. COULEURS

- chiffres : blanc cassé
- labels : gris sable
- variation positive : ambre
- alerte : ocre
- fond : surface sombre

## 9. TYPOGRAPHIE

- chiffre : 20 à 26 px
- label : 11 à 12 px
- insight : 13 à 15 px
- graphique label : 11 px

## 10. BOUTONS

- voir détails
- période
- format
- exporter plus tard si nécessaire
- comprendre

## 11. CARTES

Cartes :

- écoute totale
- contenus sauvegardés
- série la plus suivie
- débat le plus actif
- revenus créateur
- tendance

## 12. ICONOGRAPHIE

- écoute
- vue
- sauvegarde
- débat
- série
- soutien
- progression

## 13. COMPORTEMENT SCROLL

Stats publiques restent compactes.

Stats privées peuvent scroller dans page dédiée.

## 14. ANIMATIONS

- compteurs doux au chargement
- graphiques apparaissent sans exagération
- variation avec micro indicateur

## 15. MICRO INTERACTIONS

- tap stat publique : explication
- tap insight : détail
- période changée : transition douce

## 16. GESTURES MOBILE

- swipe cartes insights
- tap filtre période
- pas de graphiques complexes à manipuler

## 17. ÉTATS LOADING

- skeleton chiffres
- cartes insights
- graphiques simplifiés

## 18. ÉTATS ERREUR

- stats indisponibles
- afficher dernières stats cache
- message "non actualisé"

## 19. ÉTATS OFFLINE

- stats cache
- badge "dernière mise à jour"
- pas de recalcul inutile

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- stats compactes

### Tablet :

- grille 2 colonnes

### Desktop :

- analytics plus complet mais élégant

## 21. ACCESSIBILITÉ

- chiffres avec labels complets
- graphiques avec résumé textuel
- contraste

## 22. PERFORMANCE UX

- stats cache
- chargement différé
- pas de graphiques lourds au profil public

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- stats non prioritaires
- identité avant stats
- cache
- graphique optionnel

## 24. RÈGLES NON NÉGOCIABLES

- Ne pas rendre les stats toxiques
- Les stats privées ne doivent pas être publiques par erreur
- Les chiffres doivent avoir un sens
- Les statistiques doivent rester secondaires à la contribution
- Le profil ne doit pas devenir un dashboard froid
