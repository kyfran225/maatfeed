# 7. BADGES, CRÉDIBILITÉ ET RÉPUTATION

## 1. OBJECTIF UX

Montrer la qualité d'une contribution sans créer une course toxique aux chiffres.

MAATFEED doit valoriser :

- sources fiables
- débats constructifs
- régularité
- profondeur
- respect
- clarté
- contribution communautaire

## 2. ÉMOTION RECHERCHÉE

Les badges doivent inspirer confiance, pas supériorité.

Ils doivent sentir la reconnaissance, pas le classement brutal.

## 3. STRUCTURE VISUELLE GLOBALE

Types de badges :

- Créateur vérifié
- Débatteur constructif
- Sourceur fiable
- Série suivie
- Voix audio active
- Contributeur historique
- Modération positive
- Expert thématique, si validé

## 4. LAYOUT EXACT

### Sur profil :

- badges principaux sous nom
- badges secondaires dans section dédiée
- tap badge ouvre explication
- pas plus de 3 badges visibles dans header

## 5. HIERARCHIE VISUELLE

Priorité :

1. vérification
2. crédibilité thématique
3. qualité communautaire
4. activité

## 6. POSITIONNEMENT DES ÉLÉMENTS

- badge principal près nom
- badges secondaires sous bio
- section "Crédibilité" dans profil créateur
- détails en sheet

## 7. DIMENSIONS & ESPACEMENTS

- badge compact : 24 à 30 px hauteur
- badge carte : 64 à 88 px
- icône badge : 18 à 24 px
- gap : 8 à 12 px

## 8. COULEURS

- vérifié : or
- qualité : ambre doux
- source : sable
- modération : ocre
- inactif : gris

## 9. TYPOGRAPHIE

- badge label : 11 à 12 px
- détail badge : 13 à 15 px
- titre section : 16 à 20 px

## 10. BOUTONS

- voir badges
- comprendre
- partager badge
- demander vérification si disponible

## 11. CARTES

Carte badge :

- icône
- titre
- signification
- condition obtenue
- date ou niveau si pertinent

## 12. ICONOGRAPHIE

- sceau
- source
- balance
- micro
- livre
- étoile
- cercle communautaire

## 13. COMPORTEMENT SCROLL

Badges header restent compacts.

Section complète plus bas.

## 14. ANIMATIONS

- badge obtenu : glow discret
- tap badge : expansion sheet
- vérification : aucune animation flashy

## 15. MICRO INTERACTIONS

- tap badge : explication
- badge récent : mini label "nouveau"
- progression badge : barre douce si visible pour soi

## 16. GESTURES MOBILE

- scroll horizontal badges si nombreux
- tap détail
- swipe sheet

## 17. ÉTATS LOADING

- badges skeleton
- charger après identité

## 18. ÉTATS ERREUR

- badges indisponibles
- cacher section si non critique
- ne pas bloquer profil

## 19. ÉTATS OFFLINE

- badges cache
- statut "peut ne pas être à jour"

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- 2 à 3 badges visibles

### Desktop :

- section complète visible

### Tablet :

- badges en ligne + détails

## 21. ACCESSIBILITÉ

- badges textuels
- pas uniquement icône
- description lisible
- contraste

## 22. PERFORMANCE UX

- badges légers
- pas d'animations lourdes
- cache

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- badges texte-first
- icônes locales
- charger après profil

## 24. RÈGLES NON NÉGOCIABLES

- Les badges doivent expliquer la qualité
- Pas de gamification agressive
- Pas de classement humiliant
- Les badges doivent être compréhensibles
- La crédibilité ne doit pas être basée seulement sur popularité
