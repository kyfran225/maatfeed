# 15. CHECKLIST AGENT CODEUR - CREATOR & PROFILE SYSTEM

## 1. OBJECTIF UX

Vérifier que l'implémentation du profil MAATFEED respecte l'identité produit, le mobile-first, la faible connexion et la logique créateur.

## 2. ÉMOTION RECHERCHÉE

Le résultat doit inspirer :

- confiance
- élégance
- appartenance
- profondeur
- envie d'explorer

## 3. STRUCTURE VISUELLE GLOBALE

L'agent codeur doit vérifier :

- profil utilisateur simple
- profil créateur public
- avatar symbolique
- header
- bio
- badges
- stats
- onglets
- bibliothèque
- abonnements
- confidentialité
- monétisation
- offline
- responsive

## 4. LAYOUT EXACT

À valider :

- mobile en une colonne
- tabs sticky
- header compactable
- desktop en 3 colonnes
- contenu central
- actions toujours accessibles

## 5. HIERARCHIE VISUELLE

À valider :

- identité visible immédiatement
- action principale claire
- bio lisible
- contenus organisés
- stats secondaires
- badges explicables

## 6. POSITIONNEMENT DES ÉLÉMENTS

À valider :

- avatar dans header
- nom et rôle proches
- action principale près identité
- onglets sous header
- contenus sous tabs
- paramètres non mélangés aux contenus publics

## 7. DIMENSIONS & ESPACEMENTS

À valider :

- boutons tactiles minimum 44 px
- avatar mobile autour de 96 à 128 px
- tabs 44 à 52 px
- padding mobile 16 à 20 px
- desktop avec colonnes respirantes

## 8. COULEURS

À valider :

- noir charbon dominant
- ambre/or pour actif
- gris sable pour secondaire
- erreurs discrètes
- pas de couleurs génériques SaaS

## 9. TYPOGRAPHIE

À valider :

- nom fort
- bio lisible
- stats claires
- labels pas trop petits
- line-height confortable

## 10. BOUTONS

À valider :

- suivre
- modifier
- soutenir
- partager
- paramètres
- retry
- actions contextuelles

Chaque bouton doit avoir un état loading, actif, désactivé et erreur si nécessaire.

## 11. CARTES

À valider :

- cartes contenu
- cartes série
- cartes débat
- cartes audio
- cartes badge
- cartes sauvegarde
- cartes soutien

Toutes doivent respecter le design MAATFEED.

## 12. ICONOGRAPHIE

À valider :

- icônes cohérentes
- pas de pictogrammes génériques froids
- état actif ambre
- labels accessibles

## 13. COMPORTEMENT SCROLL

À valider :

- header compact
- tabs sticky
- position onglet restaurée
- colonnes desktop stables
- aucun saut layout

## 14. ANIMATIONS

À valider :

- transitions douces
- pas de néon agressif
- pas d'animation inutile
- respect réduction mouvement

## 15. MICRO INTERACTIONS

À valider :

- follow
- badge détail
- bio expand
- avatar preview
- sauvegarde retirer
- soutien
- onglets

## 16. GESTURES MOBILE

À valider :

- swipe tabs
- pull refresh
- long press options
- gestes non destructifs
- alternatives visibles

## 17. ÉTATS LOADING

À valider :

- skeleton header
- skeleton tabs
- skeleton cartes
- loading partiel
- pas de page blanche

## 18. ÉTATS ERREUR

À valider :

- erreur profil
- erreur onglet
- erreur stats
- erreur follow
- erreur soutien
- retry clair
- contenu conservé

## 19. ÉTATS OFFLINE

À valider :

- profil cache
- sauvegardes locales
- follow pending
- modifications pending
- contenus déjà vus
- badge offline

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

À valider :

- mobile prioritaire
- tablet confortable
- desktop exploratoire
- pas de dashboard froid
- cohérence entre tailles

## 21. ACCESSIBILITÉ

À valider :

- focus visible
- labels
- tabs accessibles
- stats textuelles
- badges expliqués
- contraste
- boutons 44 px

## 22. PERFORMANCE UX

À valider :

- identité chargée en premier
- onglets lazy
- avatars compressés
- stats cache
- pas d'autoplay média
- pagination
- re-renders limités

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

À valider :

- texte d'abord
- avatar fallback
- cache profil
- pagination
- offline
- audios avant vidéos
- pas de chargement massif

## 24. RÈGLES NON NÉGOCIABLES

- Le profil MAATFEED n'est pas un profil social générique
- L'identité culturelle doit être visible
- La contribution prime sur la popularité
- Les avatars doivent être symboliques, cohérents et légers
- Les badges doivent expliquer la qualité
- Les stats publiques doivent rester saines
- Le profil doit fonctionner en faible connexion
- Le profil créateur doit encourager le suivi et le soutien sans pression
- Le desktop ne doit pas devenir un dashboard SaaS
- Le mobile reste la vérité produit
