# 12. MONÉTISATION CRÉATEUR ET SOUTIEN

## 1. OBJECTIF UX

Permettre au créateur de recevoir du soutien ou proposer du contenu premium de manière élégante et transparente.

## 2. ÉMOTION RECHERCHÉE

Le soutien doit donner une impression de mécénat culturel moderne, pas de mendicité numérique.

## 3. STRUCTURE VISUELLE GLOBALE

Modules :

- bouton soutenir
- carte soutien
- séries premium
- contenus bonus
- statistiques privées
- historique soutien
- transparence

## 4. LAYOUT EXACT

### Sur profil public :

- bouton soutenir secondaire
- carte soutien sous bio ou panneau droit
- premium visible sur séries concernées

### Profil créateur privé :

- page monétisation
- revenus
- contenus premium
- paramètres

## 5. HIERARCHIE VISUELLE

### Priorité publique :

1. suivre
2. contenu
3. soutenir

### Priorité privée :

1. revenus
2. contenus premium
3. soutiens
4. configuration

## 6. POSITIONNEMENT DES ÉLÉMENTS

- soutien dans header ou panneau droit
- détails dans sheet
- premium sur cartes contenus
- stats privées hors profil public

## 7. DIMENSIONS & ESPACEMENTS

- bouton soutenir : 44 à 48 px
- carte soutien : 120 à 180 px
- badge premium : 24 à 30 px
- sheet soutien : 60 à 85 % hauteur

## 8. COULEURS

- soutien : or doux
- premium : ambre/or
- fond : noir surface
- montant : blanc cassé
- info : gris sable

## 9. TYPOGRAPHIE

- soutien titre : 16 à 20 px
- description : 13 à 15 px
- montant : 18 à 24 px
- condition : 11 à 12 px

## 10. BOUTONS

- soutenir
- choisir montant
- débloquer
- voir avantages
- gérer premium
- retirer premium

## 11. CARTES

Cartes :

- soutien
- série premium
- bonus
- revenus
- contributeur récent, si affichage autorisé

## 12. ICONOGRAPHIE

- étoile
- soutien
- cadenas
- série
- badge
- reçu

## 13. COMPORTEMENT SCROLL

Soutien visible mais jamais collant de façon agressive.

Sur desktop, carte soutien peut être sticky dans colonne droite.

## 14. ANIMATIONS

- ouverture soutien sheet
- sélection montant
- succès soutien
- badge premium

## 15. MICRO INTERACTIONS

- tap montant
- message créateur
- confirmation douce
- contenu débloqué avec transition

## 16. GESTURES MOBILE

- swipe sheet
- tap montant
- pas de paiement accidentel

## 17. ÉTATS LOADING

- chargement options
- paiement
- déblocage
- stats revenus

## 18. ÉTATS ERREUR

- paiement échoué
- option indisponible
- réseau
- contenu non débloqué

Message clair, pas de panique.

## 19. ÉTATS OFFLINE

- soutien désactivé
- contenus premium déjà téléchargés disponibles selon droits
- tentative gardée non payée, pas d'action automatique

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- sheet soutien

### Tablet :

- panneau soutien

### Desktop :

- carte soutien sticky

## 21. ACCESSIBILITÉ

- prix lisibles
- conditions claires
- pas de dark pattern
- actions confirmées

## 22. PERFORMANCE UX

- charger paiement uniquement à l'action
- cartes premium légères
- stats privées différées

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- paiement jamais lancé sans réseau stable
- explication légère
- pas de médias lourds dans paywall
- retry clair

## 24. RÈGLES NON NÉGOCIABLES

- La monétisation doit rester transparente
- Le soutien ne doit jamais être forcé
- Les contenus premium doivent être clairement indiqués
- Les revenus privés ne doivent pas apparaître publiquement
- Le paiement doit être sûr et compréhensible
