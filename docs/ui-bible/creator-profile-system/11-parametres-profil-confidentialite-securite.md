# 11. PARAMÈTRES PROFIL, CONFIDENTIALITÉ ET SÉCURITÉ

## 1. OBJECTIF UX

Permettre à l'utilisateur de contrôler son identité, sa visibilité, ses notifications et sa sécurité.

## 2. ÉMOTION RECHERCHÉE

Les paramètres doivent inspirer confiance et clarté.

L'utilisateur ne doit pas avoir peur de ce qui est public ou privé.

## 3. STRUCTURE VISUELLE GLOBALE

Sections :

- identité
- avatar
- bio
- confidentialité
- notifications
- contenu
- sécurité
- données
- monétisation si créateur

## 4. LAYOUT EXACT

### Mobile :

- liste de sections
- chaque section ouvre une page ou sheet
- toggles clairs
- résumé de visibilité

### Desktop :

- navigation gauche
- panneau réglage central
- aperçu profil public à droite

## 5. HIERARCHIE VISUELLE

Priorité :

1. visibilité profil
2. informations publiques
3. notifications
4. sécurité
5. données
6. avancé

## 6. POSITIONNEMENT DES ÉLÉMENTS

- statut visibilité en haut
- identité ensuite
- confidentialité avant notifications
- danger zone tout en bas

## 7. DIMENSIONS & ESPACEMENTS

- item setting : 56 à 72 px
- toggle : 44 px zone tactile
- section gap : 24 px
- danger zone : séparée clairement

## 8. COULEURS

- réglage normal : surface sombre
- actif : ambre
- confidentialité : ocre
- danger : rouge brique discret
- texte secondaire : gris sable

## 9. TYPOGRAPHIE

- section : 16 à 18 px
- item : 14 à 16 px
- description : 12 à 13 px
- danger : 13 à 14 px

## 10. BOUTONS

- enregistrer
- annuler
- modifier
- rendre privé/public
- gérer notifications
- supprimer
- télécharger données si disponible

## 11. CARTES

Cartes :

- visibilité
- notification
- sécurité
- données
- compte créateur

## 12. ICONOGRAPHIE

- verrou
- œil
- cloche
- sécurité
- avatar
- données
- alerte

## 13. COMPORTEMENT SCROLL

Sections verticales.

Bouton sauvegarde sticky seulement si changement non enregistré.

## 14. ANIMATIONS

- toggle doux
- sauvegarde confirmation
- section expansion
- alerte danger sans agressivité

## 15. MICRO INTERACTIONS

- changement visibilité : aperçu impact
- notification : test optionnel
- avatar : preview
- sauvegarde : badge

## 16. GESTURES MOBILE

- swipe back
- tap item
- pas de suppression par swipe

## 17. ÉTATS LOADING

- sauvegarde
- chargement paramètres
- avatar update
- visibilité update

## 18. ÉTATS ERREUR

- sauvegarde impossible
- réseau
- permission
- conflit

Garder valeurs précédentes visibles.

## 19. ÉTATS OFFLINE

- modifications locales
- sync plus tard
- actions sensibles désactivées si besoin

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- liste simple

### Tablet :

- split navigation

### Desktop :

- paramètres + aperçu public

## 21. ACCESSIBILITÉ

- toggles labellisés
- descriptions
- focus
- confirmation actions sensibles

## 22. PERFORMANCE UX

- sections lazy
- sauvegarde locale
- pas de page lourde

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- paramètres essentiels disponibles
- sync différée
- messages clairs
- pas de chargement infini

## 24. RÈGLES NON NÉGOCIABLES

- L'utilisateur doit savoir ce qui est public
- Les actions sensibles doivent être confirmées
- Les paramètres doivent être simples
- La confidentialité ne doit pas être cachée
- Les changements ne doivent pas disparaître sans feedback
