# 1. VISION GLOBALE DU CREATOR & PROFILE SYSTEM

## 1. OBJECTIF UX

Le Creator & Profile System doit permettre à chaque utilisateur de se présenter non seulement comme une personne, mais comme une présence culturelle dans MAATFEED.

Le profil doit répondre à plusieurs questions :

- Qui est cette personne sur MAATFEED ?
- Que crée-t-elle ?
- Quels débats anime-t-elle ?
- Quels sujets suit-elle ?
- Quelle est sa crédibilité ?
- Quel type de savoir transmet-elle ?
- Quelle est sa contribution à la communauté ?
- Est-elle simple utilisateur, créateur, expert, contributeur, modérateur ou personnalité reconnue ?

Le profil doit aussi servir d'espace de navigation personnel :

- contenus publiés
- séries créées
- débats lancés
- réponses données
- audios publiés
- sauvegardes
- abonnements
- statistiques
- monétisation
- paramètres
- confidentialité

L'objectif est de transformer le profil en temple personnel de contribution, pas en simple page "bio + posts".

## 2. ÉMOTION RECHERCHÉE

Le profil doit inspirer :

- dignité
- curiosité
- confiance
- profondeur
- appartenance
- fierté créative
- sérieux culturel
- envie de suivre

L'utilisateur qui ouvre son propre profil doit sentir :

"Voici mon espace. Voici ma trace. Voici ce que j'apporte."

L'utilisateur qui visite le profil d'un autre doit sentir :

"Cette personne a une voix, un axe, une présence."

## 3. STRUCTURE VISUELLE GLOBALE

Le système de profil repose sur 8 blocs :

### Header identité
Avatar symbolique, nom, pseudo, rôle, badge, bouton suivre ou modifier.

### Empreinte culturelle
Bio, centres d'intérêt, archétype, sujets dominants, ton de contribution.

### Navigation profil
Onglets : Publications, Audios, Débats, Séries, Réponses, Sauvegardes selon contexte.

### Crédibilité et réputation
Badges, qualité des contributions, sources, participation constructive.

### Bibliothèque personnelle
contenus sauvegardés, continue listening, séries suivies, historique utile.

### Créateur et monétisation
soutien, premium, séries payantes, statistiques privées.

### Paramètres et confidentialité
visibilité, sécurité, notifications, données.

### Responsive et offline
profil lisible même avec faible connexion.

## 4. LAYOUT EXACT

### Sur mobile :

- header profil en haut
- avatar centré ou légèrement aligné à gauche selon contexte
- bloc identité compact
- bio repliable
- statistiques horizontales
- onglets sticky sous le header
- contenu en feed vertical
- bouton action principal visible
- navigation fluide vers création, édition ou abonnement

### Sur desktop :

- colonne gauche : identité, bio, badges, liens
- colonne centrale : contenus
- colonne droite : séries, statistiques, recommandations, créateur
- header large, mais non envahissant
- onglets visibles en haut de la colonne centrale

### Sur tablette :

- header large
- identité à gauche
- statistiques et actions à droite
- contenu en grille ou feed selon onglet

## 5. HIERARCHIE VISUELLE

Priorité visuelle :

1. avatar/identité
2. nom et rôle
3. action principale
4. bio courte
5. statistiques essentielles
6. onglets
7. contenus
8. badges secondaires
9. paramètres

Le profil doit donner une information claire dès les 3 premières secondes.

## 6. POSITIONNEMENT DES ÉLÉMENTS

### Mobile :

- bouton retour haut gauche
- menu haut droite
- avatar dans la zone haute
- nom sous avatar ou à droite
- rôle/badge sous nom
- bouton suivre/modifier sous l'identité
- stats sous action
- bio sous stats
- onglets sticky ensuite

### Desktop :

- avatar dans colonne gauche
- identité fixe ou semi-sticky
- contenus au centre
- bloc créateur à droite

## 7. DIMENSIONS & ESPACEMENTS

### Mobile :

- header hauteur : 220 à 320 px selon richesse
- avatar : 82 à 112 px
- avatar créateur vérifié : 112 à 128 px
- bouton principal : 44 à 52 px hauteur
- stats : 3 à 4 colonnes, hauteur 54 à 72 px
- onglets : 44 à 52 px
- padding horizontal : 16 à 20 px

### Desktop :

- colonne identité : 280 à 340 px
- colonne contenu : 620 à 760 px
- colonne droite : 300 à 380 px
- avatar : 128 à 168 px
- gap colonnes : 24 px

## 8. COULEURS

Palette :

- fond principal : noir charbon profond
- surfaces : noir graphite
- surfaces hautes : noir chaud
- accent principal : ambre/or
- texte principal : blanc cassé
- texte secondaire : gris sable
- badges crédibilité : or discret
- badges communautaires : ocre doux
- alertes confidentialité : brun rouge discret
- statistiques : gris chaud avec accent ambre

Le profil doit rester premium, jamais flashy.

## 9. TYPOGRAPHIE

### Nom :

- mobile : 22 à 28 px
- desktop : 28 à 36 px
- weight semi-bold ou bold élégant

### Pseudo :

- 13 à 15 px
- gris sable

### Bio :

- 14 à 16 px
- line-height 1.5 à 1.65

### Stats :

- chiffres : 18 à 22 px
- labels : 11 à 12 px

### Onglets :

- 13 à 14 px
- actif en ambre

## 10. BOUTONS

Boutons principaux selon contexte :

- Suivre
- Modifier le profil
- Soutenir
- Message, uniquement si autorisé par les règles produit
- Voir séries
- Créer
- Paramètres

Boutons secondaires :

- partager profil
- signaler
- copier lien
- gérer confidentialité
- activer profil créateur

Le bouton principal doit toujours être clair. Un profil ne doit pas afficher 6 actions de même poids.

## 11. CARTES

Cartes utilisées :

- carte identité
- carte bio
- carte badge
- carte statistique
- carte contenu
- carte série
- carte débat lancé
- carte audio
- carte sauvegarde
- carte soutien créateur
- carte confidentialité

Toutes les cartes doivent respirer, avec radius généreux, bordures fines et matière sombre.

## 12. ICONOGRAPHIE

Icônes nécessaires :

- profil
- créateur
- badge
- débat
- micro
- série
- sauvegarde
- source
- soutien
- confidentialité
- paramètres
- lien
- partage

Style :

- icônes fines
- arrondies
- dorées uniquement pour actif, vérifié ou important
- gris sable pour secondaire

## 13. COMPORTEMENT SCROLL

### Mobile :

- header se compacte au scroll
- avatar peut réduire légèrement
- onglets deviennent sticky
- bouton principal peut devenir une mini action sticky
- le contenu garde le contexte de l'onglet actif

### Desktop :

- colonne gauche peut rester sticky
- colonne centrale scrolle
- colonne droite sticky partiellement

## 14. ANIMATIONS

Animations principales :

- ouverture profil : fade + montée douce
- header compact : transition fluide
- changement onglet : glissement horizontal léger
- badge hover/tap : micro glow
- follow : transformation bouton avec confirmation douce
- édition profil : ouverture sheet ou modal

Durées :

- micro : 120 à 180 ms
- changement onglet : 220 à 300 ms
- ouverture profil : 260 à 360 ms

## 15. MICRO INTERACTIONS

Exemples :

- tap badge : explication courte
- tap stat : ouvre détail
- follow : bouton devient "Suivi" avec petite vibration visuelle
- avatar : ouvre aperçu symbolique
- bio longue : "voir plus"
- contenu épinglé : halo discret
- profil privé : verrou doux

## 16. GESTURES MOBILE

Gestures :

- swipe entre onglets
- pull-to-refresh du profil
- long press sur contenu pour options
- swipe down pour fermer un profil ouvert en modal
- tap avatar pour agrandir
- swipe contenu sauvegardé pour retirer

Gestures à éviter :

- suppression accidentelle
- unfollow par swipe
- changement d'onglet trop sensible

## 17. ÉTATS LOADING

Le profil doit charger par couches :

1. identité
2. stats
3. bio
4. onglets
5. contenus
6. badges
7. séries

Skeleton :

- avatar rond
- nom
- stats
- tabs
- cartes contenu

Ne jamais afficher une page vide si au moins l'identité est disponible.

## 18. ÉTATS ERREUR

Erreurs possibles :

- profil introuvable
- profil privé
- réseau instable
- contenus non chargés
- stats indisponibles
- avatar indisponible

L'UI doit :

- garder le header si possible
- afficher un message court
- proposer réessayer
- ne pas casser toute la page pour un onglet indisponible

## 19. ÉTATS OFFLINE

Offline :

- afficher profil en cache
- badge "données récentes non synchronisées"
- contenus déjà vus disponibles
- sauvegardes locales visibles
- édition possible en brouillon
- follow/soutien mis en attente si nécessaire

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- profil vertical, fluide, onglets sticky

### Tablet :

- header riche, contenu en 2 colonnes possible

### Desktop :

- profil en 3 colonnes premium
- identité sticky
- contenus centraux
- panneaux contextuels

## 21. ACCESSIBILITÉ

Obligatoire :

- avatar avec description
- boutons 44 px minimum
- focus visible
- tabs accessibles
- stats compréhensibles par texte
- badges explicables
- contraste élevé
- pas d'information uniquement par couleur

## 22. PERFORMANCE UX

Règles :

- charger identité en priorité
- lazy load contenus
- stats en cache
- avatars compressés
- onglets chargés à la demande
- éviter recalculs lourds au scroll
- images basse qualité avant haute qualité

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Priorités :

- identité d'abord
- texte avant médias
- avatar symbolique léger
- stats simplifiées
- contenus paginés
- mode léger
- cache profil
- pas de vidéo autoplay dans profil

## 24. RÈGLES NON NÉGOCIABLES

- Le profil ne doit jamais ressembler à un profil social générique
- L'identité culturelle doit être visible
- Les avatars doivent rester cohérents avec l'univers MAATFEED
- Les onglets doivent être simples
- Le profil doit rester lisible en faible connexion
- Les statistiques publiques ne doivent pas créer une compétition toxique
- La crédibilité doit être qualitative, pas seulement quantitative
- Le profil créateur doit mettre en avant la contribution, pas seulement la popularité
