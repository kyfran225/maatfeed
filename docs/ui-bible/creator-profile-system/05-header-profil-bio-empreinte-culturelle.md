# 5. HEADER PROFIL, BIO ET EMPREINTE CULTURELLE

## 1. OBJECTIF UX

Le header doit condenser l'identité MAATFEED d'un profil : nom, rôle, intention, spécialité, crédibilité et action principale.

Il doit permettre au visiteur de comprendre immédiatement la présence culturelle du profil.

## 2. ÉMOTION RECHERCHÉE

Le header doit ressembler à une entrée de maison intellectuelle : sobre, accueillante, profonde.

## 3. STRUCTURE VISUELLE GLOBALE

Header :

- fond visuel sombre
- avatar
- nom
- pseudo
- rôle
- archétype
- bio courte
- badges
- actions
- stats essentielles

Empreinte culturelle :

- sujets dominants
- ton
- formats préférés
- contribution principale

## 4. LAYOUT EXACT

### Mobile :

- fond hero en haut
- avatar chevauchant légèrement la surface
- nom et pseudo centrés ou alignés gauche
- bio sous nom
- chips sujets
- actions
- stats

### Desktop :

- hero horizontal
- avatar à gauche
- bio au centre
- actions à droite

## 5. HIERARCHIE VISUELLE

Priorité :

1. nom
2. rôle/spécialité
3. bio
4. action
5. stats
6. sujets

## 6. POSITIONNEMENT DES ÉLÉMENTS

- avatar haut ou centre
- nom juste sous avatar
- badge vérification près nom
- bio sous rôle
- chips sous bio
- actions sous chips
- stats en bas du header

## 7. DIMENSIONS & ESPACEMENTS

- hero mobile : 240 à 340 px
- bio max : 3 lignes collapsed
- chips : 28 à 34 px
- action row : 44 à 52 px
- stats row : 60 à 72 px

## 8. COULEURS

- hero : gradient noir vers brun profond
- chips : ambre faible
- badge : or discret
- bio : gris clair
- stats : surface sombre

## 9. TYPOGRAPHIE

- nom : 24 à 32 px
- rôle : 13 à 15 px
- bio : 14 à 16 px
- chips : 11 à 12 px
- stat : 18 à 22 px

## 10. BOUTONS

- suivre/modifier
- soutenir
- partager
- plus
- voir bio complète

## 11. CARTES

La bio complète peut devenir une carte détaillée :

- à propos
- domaines
- formats
- sources
- liens

## 12. ICONOGRAPHIE

- badge
- lien
- sujet
- rôle
- localisation large si volontaire
- calendrier ancienneté

Ne jamais forcer des données personnelles sensibles.

## 13. COMPORTEMENT SCROLL

Header compact :

- avatar réduit
- nom reste visible
- onglets passent sticky
- action principale devient icône/capsule

## 14. ANIMATIONS

- compactage fluide
- bio expansion
- chips apparition
- action follow

## 15. MICRO INTERACTIONS

- tap bio : lire plus
- tap sujet : feed filtré
- tap badge : explication
- tap rôle : définition

## 16. GESTURES MOBILE

- swipe up naturel
- tap chips
- swipe down si profil en modal
- pas de gestures critiques sur header

## 17. ÉTATS LOADING

- skeleton hero
- avatar
- nom
- bio
- chips

## 18. ÉTATS ERREUR

- bio indisponible
- badges indisponibles
- stats indisponibles

Le header doit rester utilisable.

## 19. ÉTATS OFFLINE

- header cache
- bio cache
- stats marquées comme non actualisées

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- vertical

### Tablet :

- avatar + bio en deux zones

### Desktop :

- hero horizontal riche

## 21. ACCESSIBILITÉ

- bio lisible
- boutons nommés
- chips accessibles
- contraste
- focus

## 22. PERFORMANCE UX

- hero léger
- pas de vidéo dans header
- avatar optimisé
- chips texte-first

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- header charge sans médias lourds
- fond gradient local
- avatar fallback
- bio visible rapidement

## 24. RÈGLES NON NÉGOCIABLES

- Le header doit expliquer qui est le profil
- La bio ne doit pas être cachée trop profondément
- Les sujets doivent être visibles
- Les actions doivent être claires
- Le header ne doit pas devenir une bannière vide décorative
