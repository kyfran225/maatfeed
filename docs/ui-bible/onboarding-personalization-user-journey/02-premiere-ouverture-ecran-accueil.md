# 2. PREMIÈRE OUVERTURE ET ÉCRAN D'ACCUEIL

## 1. OBJECTIF UX

Créer une première impression forte, claire et mémorable. L'utilisateur doit comprendre immédiatement que MAATFEED est une plateforme différente : culturelle, intelligente, sociale, audio-first, debate-first et premium.

## 2. ÉMOTION RECHERCHÉE

L'émotion recherchée est l'éveil.

L'utilisateur doit ressentir qu'il ouvre une porte vers un espace de savoir africain vivant, pas une application sociale de plus.

## 3. STRUCTURE VISUELLE GLOBALE

L'écran comprend :

- fond noir profond
- symbole MAATFEED
- titre
- phrase de valeur
- 2 à 3 bénéfices courts
- bouton commencer
- option connexion/compte si nécessaire
- option passer si exploration invitée autorisée

## 4. LAYOUT EXACT

### Mobile :

- logo/symbole en haut-centre ou légèrement au-dessus du centre
- titre au centre
- phrase courte sous titre
- bénéfices en chips ou lignes courtes
- bouton principal en bas
- bouton secondaire sous le principal

### Desktop :

- grand visuel symbolique à gauche
- texte et actions à droite
- background avec motif culturel subtil

## 5. HIERARCHIE VISUELLE

1. symbole MAATFEED
2. promesse
3. bénéfices
4. action

La phrase principale doit être mémorisable.

Exemple d'esprit :

"Explore le savoir africain, écoute les voix, rejoins les débats."

## 6. POSITIONNEMENT DES ÉLÉMENTS

Le bouton "Commencer" doit être accessible sans scroll.

Les bénéfices ne doivent pas devenir une liste longue.

La connexion doit rester visible mais secondaire.

## 7. DIMENSIONS & ESPACEMENTS

- symbole : 72 à 110 px mobile
- titre : 28 à 34 px
- sous-texte : 15 à 17 px
- bouton : 54 px
- espace titre/sous-texte : 12 px
- espace sous-texte/bénéfices : 22 px
- marge basse : safe area + 24 px

## 8. COULEURS

- fond : noir charbon
- symbole : or/ambre
- titre : blanc chaud
- sous-texte : beige grisé
- bouton : ambre/or profond
- bouton secondaire : transparent avec bordure brun/or

## 9. TYPOGRAPHIE

### Titre :

- fort
- élégant
- pas trop long

### Sous-texte :

- clair
- humain
- maximum 2 lignes

### Bénéfices :

- 12 à 14 px
- format court

## 10. BOUTONS

Boutons :

- "Commencer"
- "J'ai déjà un compte"
- "Explorer d'abord" si mode invité disponible

Le bouton principal doit être visuellement dominant, mais pas criard.

## 11. CARTES

Pas de grandes cartes multiples sur le premier écran.
Éventuellement 3 micro-cartes bénéfices :

- Débats
- Audios
- Séries

Ces cartes doivent rester très légères.

## 12. ICONOGRAPHIE

Symboles :

- onde audio
- cercle débat
- papyrus
- boussole

Pas d'illustration humaine obligatoire.

## 13. COMPORTEMENT SCROLL

Pas de scroll nécessaire sur petit mobile, sauf contrainte extrême.

Le contenu doit s'adapter verticalement.

## 14. ANIMATIONS

- logo apparition douce
- léger halo
- bénéfices apparaissent en décalé
- bouton arrive en dernier
- durée totale courte

## 15. MICRO INTERACTIONS

- tap bouton : légère contraction
- tap bénéfice : peut ouvrir mini-explication
- appui long logo : aucune fonction cachée essentielle

## 16. GESTURES MOBILE

- swipe gauche possible pour écran suivant
- tap principal recommandé
- retour système quitte ou revient selon état

## 17. ÉTATS LOADING

Si l'app charge :

- afficher symbole
- message court
- pas de longue attente sans feedback

## 18. ÉTATS ERREUR

Si première ouverture échoue :

- proposer mode léger
- proposer réessayer
- garder accès à une page minimale

## 19. ÉTATS OFFLINE

Si offline dès ouverture :

- afficher écran d'accueil
- proposer mode offline limité
- permettre choix d'intérêts localement

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- plein écran vertical

### Tablet :

- symbole plus grand
- texte centré

### Desktop :

- split layout immersif

## 21. ACCESSIBILITÉ

- titre lisible
- boutons nommés
- contraste
- focus
- motion réduite

## 22. PERFORMANCE UX

- écran disponible instantanément
- assets locaux
- pas de vidéo
- pas de police lourde bloquante

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- première ouverture rapide
- pas de dépendance réseau forte
- possibilité commencer léger
- pas d'animation lourde

## 24. RÈGLES NON NÉGOCIABLES

- Première impression premium
- Message clair
- Pas de surcharge
- Pas de formulaire immédiat agressif
- Pas de médias lourds
- Accès au mode faible connexion
