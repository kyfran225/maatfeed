# 8. ONBOARDING FAIBLE CONNEXION ET MODE LÉGER

## 1. OBJECTIF UX

Adapter l'entrée dans MAATFEED aux réalités de connexion instable, data limitée et appareils modestes.

## 2. ÉMOTION RECHERCHÉE

Soulagement.

L'utilisateur doit sentir que l'application comprend sa réalité, sans le punir.

## 3. STRUCTURE VISUELLE GLOBALE

Le mode léger peut être proposé :

- pendant onboarding
- si réseau lent détecté
- dans préférences formats
- dans état erreur
- depuis paramètres

L'écran explique simplement :

- moins d'images
- pas d'autoplay
- audio optimisé
- contenus sauvegardables
- chargement plus rapide

## 4. LAYOUT EXACT

### Mobile :

- carte mode léger dans l'onboarding
- toggle
- résumé bénéfices
- bouton activer

### Desktop :

- option dans panneau préférences

## 5. HIERARCHIE VISUELLE

1. bénéfice
2. impact
3. contrôle
4. action

Ne pas présenter le mode léger comme une version inférieure.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Le mode léger doit être visible avant le premier feed, mais pas obligatoire.

## 7. DIMENSIONS & ESPACEMENTS

### Carte mode léger :

- hauteur : 130 à 190 px
- padding : 16 px
- radius : 24 px

### Toggle :

- ligne 56 px

## 8. COULEURS

### Mode léger :

- fond graphite
- accent ambre
- icône éclair doux
- badge "recommandé si connexion lente"

## 9. TYPOGRAPHIE

- titre : 16 à 18 px
- description : 13 à 14 px
- bénéfices : 12 à 13 px

## 10. BOUTONS

Boutons :

- Activer mode léger
- Garder expérience complète
- Modifier plus tard

## 11. CARTES

### Carte bénéfices :

- "Images réduites"
- "Audio optimisé"
- "Pas d'autoplay"
- "Chargement plus rapide"

## 12. ICONOGRAPHIE

- éclair
- data
- audio
- image compressée
- nuage
- téléchargement

## 13. COMPORTEMENT SCROLL

Écran court, pas de longues explications.

## 14. ANIMATIONS

- toggle fluide
- icône éclair douce
- pas d'effet technique

## 15. MICRO INTERACTIONS

- tap activer : confirmation
- tap détail : montre effets
- changement immédiat sur aperçu feed

## 16. GESTURES MOBILE

- tap
- long press détail
- pas de gesture complexe

## 17. ÉTATS LOADING

Aucun loading réseau nécessaire pour activer localement.

## 18. ÉTATS ERREUR

Si sauvegarde échoue :

- activer localement
- sync plus tard

## 19. ÉTATS OFFLINE

Mode léger activable offline.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- carte simple

### Tablet/Desktop :

- option dans préférences

## 21. ACCESSIBILITÉ

- toggle nommé
- effets expliqués
- état actif clair

## 22. PERFORMANCE UX

- impact immédiat
- réduire médias
- désactiver autoplay
- prioriser texte

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Cœur de cette section :

- data limitée respectée
- réseau instable prévu
- appareils modestes
- offline partiel
- reprise sans perte

## 24. RÈGLES NON NÉGOCIABLES

- Mode léger valorisé, pas dégradant
- Activable dès onboarding
- Pas d'autoplay par défaut si faible connexion
- Préférences modifiables
- Offline compatible
