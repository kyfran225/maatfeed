# 13. CHECKLIST AGENT CODEUR - ONBOARDING, PERSONALIZATION & USER JOURNEY SYSTEM

## 1. OBJECTIF UX

Donner à l'agent codeur une checklist complète pour implémenter l'onboarding MAATFEED sans le transformer en formulaire générique.

## 2. ÉMOTION RECHERCHÉE

Maîtrise, accueil, fluidité.

Le résultat doit donner une première expérience premium, simple, culturelle et personnalisante.

## 3. STRUCTURE VISUELLE GLOBALE

À livrer :

- première ouverture
- choix intérêts
- choix avatar symbolique
- choix archétype
- préférences formats
- mode faible connexion
- premier feed personnalisé
- onboarding créateur
- onboarding débat
- onboarding IA
- reprise après interruption
- états loading/erreur/offline

## 4. LAYOUT EXACT

Vérifier :

- mobile plein écran
- boutons accessibles
- progression discrète
- desktop split layout
- tablet adaptatif
- pas de scroll long initial
- safe areas respectées

## 5. HIERARCHIE VISUELLE

Vérifier :

- message clair
- action principale évidente
- passer disponible
- choix lisibles
- personnalisation progressive
- contenu réel vite accessible

## 6. POSITIONNEMENT DES ÉLÉMENTS

Vérifier :

- titre haut/centre
- choix au centre
- boutons en bas
- progression visible
- mode léger accessible
- reprise visible

## 7. DIMENSIONS & ESPACEMENTS

Vérifier :

- bouton 52 à 56 px
- touch target 44 px
- padding 20 px mobile
- cartes 88 à 150 px selon type
- radius 22 à 28 px
- gaps réguliers

## 8. COULEURS

Vérifier :

- noir charbon
- graphite chaud
- ambre/or
- beige
- aucun bleu SaaS
- aucun blanc massif
- sélection visible

## 9. TYPOGRAPHIE

Vérifier :

- titres courts
- descriptions 1 à 2 lignes
- pas de jargon
- lisible petit écran
- hiérarchie nette

## 10. BOUTONS

Vérifier :

- Commencer
- Continuer
- Passer
- Choisir plus tard
- Activer mode léger
- Voir mon feed
- Reprendre

## 11. CARTES

Créer cartes pour :

- intérêts
- avatars
- archétypes
- formats
- mode léger
- onboarding créateur
- onboarding débat
- onboarding IA
- reprise

## 12. ICONOGRAPHIE

Vérifier :

- symboles culturels
- non humains si avatar symbolique
- onde audio
- débat
- papyrus
- boussole
- plume
- constellation
- pas d'icônes enfantines

## 13. COMPORTEMENT SCROLL

Vérifier :

- peu de scroll
- bouton bas sticky si besoin
- pas de contenu caché par safe area
- keyboard aware
- retour système propre

## 14. ANIMATIONS

Vérifier :

- transitions douces
- sélection halo
- progression calme
- réduction motion
- aucune animation lourde

## 15. MICRO INTERACTIONS

Vérifier :

- tap sélection
- multi-sélection
- compteur
- preview avatar
- preview archétype
- feedback sauvegarde
- reprise

## 16. GESTURES MOBILE

Vérifier :

- swipe écran intro
- swipe avatars
- long press détail
- swipe down sheets
- alternatives visibles

## 17. ÉTATS LOADING

Vérifier :

- skeleton onboarding
- skeleton feed
- chargement personnalisation
- pas de spinner solitaire
- contenu local d'abord

## 18. ÉTATS ERREUR

Vérifier :

- sauvegarde échouée
- réseau instable
- feed personnalisé indisponible
- avatar indisponible
- réessayer
- continuer sans blocage

## 19. ÉTATS OFFLINE

Vérifier :

- choix locaux
- avatars locaux
- thèmes locaux
- onboarding débat local
- onboarding IA local
- feed cache
- synchronisation différée

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Tester :

- petit mobile
- grand mobile
- tablet portrait
- tablet paysage
- desktop
- desktop large
- zoom
- clavier ouvert
- faible réseau

## 21. ACCESSIBILITÉ

Vérifier :

- labels
- focus visible
- contraste
- état sélectionné annoncé
- progression annoncée
- boutons 44 px minimum
- réduction motion
- lecteur d'écran

## 22. PERFORMANCE UX

Vérifier :

- assets locaux
- chargement rapide
- pas de vidéo obligatoire
- pas d'images lourdes
- sauvegarde locale
- feed initial cache
- lazy-load

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Vérifier :

- mode léger proposé
- pas d'autoplay
- data limitée
- offline possible
- reprise après interruption
- synchronisation plus tard
- audio optimisé

## 24. RÈGLES NON NÉGOCIABLES

- Ne pas faire un formulaire
- Ne pas fatiguer dès l'entrée
- Ne pas bloquer l'utilisateur
- Ne pas perdre les choix
- Ne pas imposer l'IA
- Ne pas imposer un avatar
- Ne pas ignorer le faible réseau
- Ne pas afficher un feed vide
- Ne pas casser l'identité MAATFEED
- Ne pas transformer l'onboarding en tunnel commercial
- L'utilisateur doit entrer vite dans le contenu
