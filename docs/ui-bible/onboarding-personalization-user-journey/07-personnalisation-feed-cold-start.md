# 7. PERSONNALISATION DU FEED ET COLD START

## 1. OBJECTIF UX

Créer un premier feed intéressant même quand l'utilisateur est nouveau et que l'application ne connaît presque rien de lui.

Le cold start doit être élégant, pas vide.

## 2. ÉMOTION RECHERCHÉE

Découverte immédiate.

L'utilisateur doit sentir que MAATFEED a déjà quelque chose de précieux à lui montrer.

## 3. STRUCTURE VISUELLE GLOBALE

Premier feed basé sur :

- intérêts choisis
- archétype
- formats préférés
- tendances de qualité
- contenus éditoriaux
- séries recommandées
- débats actifs
- audios populaires
- sources fiables

## 4. LAYOUT EXACT

Après onboarding :

- transition vers feed
- carte de bienvenue discrète
- sections personnalisées
- action "ajuster mes choix"
- premiers contenus préchargés

### Mobile :

- feed vertical

### Desktop :

- feed + panneaux découverte

## 5. HIERARCHIE VISUELLE

Premier écran feed :

1. contenu fort
2. raison de recommandation
3. action
4. possibilité ajuster

Ne pas afficher seulement une page "Bienvenue".

## 6. POSITIONNEMENT DES ÉLÉMENTS

Carte bienvenue en haut mais compacte.

Contenu réel visible immédiatement.

## 7. DIMENSIONS & ESPACEMENTS

### Carte bienvenue :

- hauteur : 90 à 140 px
- radius : 24 px
- padding : 16 px

Cartes contenu suivent règles Feed System.

## 8. COULEURS

### Bienvenue :

- fond noir/brun
- accent or
- pas de bannière criarde

### Recommandation :

- badge discret "Pour toi"

## 9. TYPOGRAPHIE

### Bienvenue :

- titre : 16 à 18 px
- texte : 13 à 14 px
- action : 13 px

## 10. BOUTONS

Actions :

- Ajuster
- Voir pourquoi
- Masquer
- Commencer une série
- Écouter maintenant
- Rejoindre débat

## 11. CARTES

Premier feed doit mélanger :

- 1 contenu fort
- 1 audio
- 1 débat
- 1 série
- 1 créateur
- 1 source ou document

Éviter monotone.

## 12. ICONOGRAPHIE

- badge pour toi
- boussole
- audio
- débat
- série
- source

## 13. COMPORTEMENT SCROLL

Le feed doit être prêt à scroller.

La personnalisation ne doit pas imposer une modal.

## 14. ANIMATIONS

- transition onboarding vers feed
- cartes apparaissent progressivement
- badge "Pour toi" léger

## 15. MICRO INTERACTIONS

- tap "pourquoi"
- feedback moins comme ça
- sauvegarder
- suivre thème
- écouter

## 16. GESTURES MOBILE

- scroll feed
- long press contenu
- swipe actions selon Feed System

## 17. ÉTATS LOADING

Si feed personnalisé charge :

- afficher contenu éditorial par défaut
- skeletons
- message court

## 18. ÉTATS ERREUR

Si personnalisation échoue :

- feed général de qualité
- bouton réessayer personnalisation
- ne jamais bloquer

## 19. ÉTATS OFFLINE

Offline :

- feed de démarrage cache
- thèmes locaux
- contenus sauvegardés si retour utilisateur
- synchronisation plus tard

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- feed vertical

### Tablet :

- feed + side suggestions

### Desktop :

- feed central + discovery panel

## 21. ACCESSIBILITÉ

- recommandations expliquées
- boutons accessibles
- feed navigable
- pas de dépendance image

## 22. PERFORMANCE UX

- premier contenu rapide
- préchargement limité
- images lazy
- pas d'autoplay lourd
- cache cold start

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- feed léger
- texte/audio prioritaire
- vidéos différées
- images compressées
- mode data respecté

## 24. RÈGLES NON NÉGOCIABLES

- Pas de feed vide
- Pas de blocage si personnalisation échoue
- Toujours expliquer un minimum
- Mélanger formats
- Respecter préférences
- Préserver performance
