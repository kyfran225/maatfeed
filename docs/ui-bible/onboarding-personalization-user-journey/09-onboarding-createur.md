# 9. ONBOARDING CRÉATEUR

## 1. OBJECTIF UX

Permettre aux utilisateurs qui veulent créer de comprendre rapidement comment publier, structurer leurs contenus, créer des séries, participer aux débats et éventuellement monétiser plus tard.

## 2. ÉMOTION RECHERCHÉE

Capacité.

Le créateur doit sentir : "Je peux commencer simplement, puis grandir."

## 3. STRUCTURE VISUELLE GLOBALE

Onboarding créateur peut être déclenché :

- après choix archétype Créateur
- au premier tap sur créer
- depuis profil
- depuis une série
- depuis un débat

Étapes :

- choisir intention
- choisir format principal
- expliquer brouillons
- expliquer séries
- expliquer IA de création
- expliquer règles communauté
- commencer un premier brouillon

## 4. LAYOUT EXACT

### Mobile :

- sheet ou mini-flow
- 3 étapes maximum avant accès composer
- bouton créer immédiatement

### Desktop :

- workspace créateur avec panneau d'aide

## 5. HIERARCHIE VISUELLE

1. commencer
2. choisir format
3. comprendre règles
4. améliorer plus tard

Ne pas forcer configuration complète.

## 6. POSITIONNEMENT DES ÉLÉMENTS

L'aide créateur doit apparaître près du bouton création.

Pas de grand onboarding imposé à tous les utilisateurs.

## 7. DIMENSIONS & ESPACEMENTS

### Sheet créateur :

- hauteur 60 à 80 %
- cartes format : 88 à 130 px
- bouton principal 54 px

## 8. COULEURS

### Création :

- accent ambre
- plume/papyrus
- fond graphite
- carte active or doux

## 9. TYPOGRAPHIE

- titre : 20 à 24 px
- description : 13 à 15 px
- format : 14 à 16 px

## 10. BOUTONS

Boutons :

- Créer maintenant
- Choisir format
- Commencer un brouillon
- Voir règles
- Plus tard

## 11. CARTES

### Formats :

- Post court
- Audio
- Vidéo
- Débat
- Série
- Source/document

## 12. ICONOGRAPHIE

- plume
- onde
- vidéo
- débat
- série
- source
- IA

## 13. COMPORTEMENT SCROLL

Flow court.

Les détails longs vont dans aide ou documentation interne.

## 14. ANIMATIONS

- ouverture sheet
- format sélectionné s'illumine
- transition vers composer

## 15. MICRO INTERACTIONS

- tap format
- aperçu court
- bouton créer
- aide IA proposée mais non imposée

## 16. GESTURES MOBILE

- swipe down fermer
- tap format
- long press détail

## 17. ÉTATS LOADING

Si composer charge :

- skeleton du composer
- conserver format choisi

## 18. ÉTATS ERREUR

Si création indisponible :

- sauvegarder intention
- proposer réessayer
- brouillon local

## 19. ÉTATS OFFLINE

### Création offline :

- brouillons locaux
- upload plus tard
- audio/video selon stockage local
- message clair

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- flow court

### Tablet/Desktop :

- assistant latéral

## 21. ACCESSIBILITÉ

- formats nommés
- règles accessibles
- focus
- pas de bouton caché

## 22. PERFORMANCE UX

- composer lazy-load
- brouillon immédiat
- pas d'upload forcé
- IA à la demande

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- brouillons offline
- publication différée
- médias compressés
- audio léger
- pas de perte

## 24. RÈGLES NON NÉGOCIABLES

- Créateur peut commencer vite
- Pas de configuration lourde
- Brouillon préservé
- IA facultative
- Règles claires
- Offline supporté
