# 6. PRÉFÉRENCES AUDIO, VIDÉO, DÉBAT ET LECTURE

## 1. OBJECTIF UX

Adapter MAATFEED aux habitudes réelles de consommation : certains veulent écouter, d'autres lire, regarder, débattre ou sauvegarder pour plus tard.

## 2. ÉMOTION RECHERCHÉE

Confort.

L'utilisateur doit sentir que l'application respecte son rythme, sa connexion, son temps et son attention.

## 3. STRUCTURE VISUELLE GLOBALE

Écran :

- titre
- choix de formats préférés
- préférence autoplay
- préférence audio
- préférence débat
- mode data
- résumé

Formats :

- audio
- vidéo
- texte
- débats
- séries
- documents
- réponses courtes
- contenus longs

## 4. LAYOUT EXACT

### Mobile :

- cartes format en grille 2 colonnes
- toggles simples
- bouton continuer

### Desktop :

- cartes formats + panneau préférences détaillées

## 5. HIERARCHIE VISUELLE

1. formats préférés
2. réseau/data
3. notifications liées
4. réglages avancés plus tard

Ne pas demander trop de détails au départ.

## 6. POSITIONNEMENT DES ÉLÉMENTS

Formats en haut.

Mode data juste après, car critique pour Afrique.

Réglages avancés dans paramètres plus tard.

## 7. DIMENSIONS & ESPACEMENTS

### Carte format :

- 96 à 130 px
- radius : 22 px
- padding : 14 px

### Toggle ligne :

- hauteur : 56 à 64 px

## 8. COULEURS

### Format actif :

- ambre/or

### Audio actif :

- cuivre/or avec onde

### Low data actif :

- ocre doux ou ambre sombre

## 9. TYPOGRAPHIE

- titre format : 14 à 16 px
- description : 12 à 13 px
- toggle label : 14 à 15 px

## 10. BOUTONS

Boutons :

- Continuer
- Configurer plus tard
- Activer mode léger
- Désactiver autoplay

## 11. CARTES

### Carte audio :

- onde
- "Écouter en priorité"

### Carte débat :

- cercle de voix
- "Voir les discussions actives"

### Carte vidéo :

- icône lecture
- "Regarder quand la connexion le permet"

## 12. ICONOGRAPHIE

- onde
- play
- livre
- débat
- série
- source
- data
- téléchargement

## 13. COMPORTEMENT SCROLL

Écran court.

Les options avancées doivent être repliées.

## 14. ANIMATIONS

- sélection format douce
- toggle fluide
- aperçu feed mini change légèrement

## 15. MICRO INTERACTIONS

- tap format
- toggle autoplay
- choix low data affiche explication courte
- confirmation légère

## 16. GESTURES MOBILE

- tap
- scroll court
- long press option pour détail

## 17. ÉTATS LOADING

Préférences locales, pas de loading lourd.

## 18. ÉTATS ERREUR

Si sauvegarde échoue :

- garder local
- synchroniser plus tard
- message discret

## 19. ÉTATS OFFLINE

Tout doit fonctionner offline.

Préférences synchronisées plus tard.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- simple

### Tablet :

- deux colonnes

### Desktop :

- plus détaillé mais toujours clair

## 21. ACCESSIBILITÉ

- toggles accessibles
- état activé annoncé
- labels clairs
- pas de couleur seule

## 22. PERFORMANCE UX

- préférences locales
- pas de médias dans l'écran
- impact immédiat sur feed

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- low data proposé
- autoplay désactivable
- audio basse qualité
- images compressées
- vidéos non prioritaires si choisi

## 24. RÈGLES NON NÉGOCIABLES

- Ne jamais forcer autoplay
- Mode faible connexion visible
- Audio traité comme format majeur
- L'utilisateur peut changer plus tard
- Préférences appliquées au feed
