# 4. SOUTIEN CRÉATEUR

## 1. OBJECTIF UX

Permettre aux utilisateurs de soutenir volontairement les créateurs qu'ils apprécient, sans que cela devienne une pression sociale ou une mécanique agressive.

Le soutien doit être un geste de reconnaissance, pas un péage.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit ressentir :

- gratitude
- proximité
- contrôle
- fierté
- simplicité

Le créateur doit ressentir que son travail peut être valorisé.

## 3. STRUCTURE VISUELLE GLOBALE

Le soutien créateur peut apparaître :

- sur profil créateur
- sous un contenu fort
- à la fin d'une série
- après un audio terminé
- dans une page soutien dédiée
- dans notifications créateur si pertinent

Éléments :

- message du créateur
- options de soutien
- montant
- fréquence si prévue
- transparence
- bouton soutenir
- confirmation

## 4. LAYOUT EXACT

### Mobile :

- carte soutien compacte sur profil
- sheet de soutien
- options montant en chips
- champ montant libre si pertinent
- bouton principal bas

### Desktop :

- panneau soutien sur profil
- options visibles
- historique ou badges de soutien si prévus

## 5. HIERARCHIE VISUELLE

1. créateur
2. raison du soutien
3. options
4. transparence
5. paiement
6. confirmation

Ne pas afficher d'abord un montant sans expliquer le geste.

## 6. POSITIONNEMENT DES ÉLÉMENTS

### Sur profil :

- sous bio ou après sections principales
- pas avant l'identité du créateur

### Sous contenu :

- après consommation ou près d'une valeur forte
- pas avant l'aperçu

## 7. DIMENSIONS & ESPACEMENTS

### Carte soutien :

- mobile : 130 à 190 px
- sheet : 65 à 85 % hauteur
- chips montant : 42 à 48 px
- CTA : 52 à 56 px
- avatar créateur : 48 à 64 px

## 8. COULEURS

### Soutien :

- cuivre/or chaleureux
- fond brun noir
- bouton ambre
- confirmation or doux
- aucune couleur de don caritatif trop criarde

## 9. TYPOGRAPHIE

- titre : 18 à 24 px
- message créateur : 13 à 15 px
- montant : 16 à 20 px
- transparence : 11 à 13 px

## 10. BOUTONS

Actions :

- Soutenir
- Choisir montant
- Soutenir une fois
- Soutien mensuel si prévu
- Annuler
- Voir détails
- Gérer soutien

## 11. CARTES

### Carte profil soutien :

- avatar/sceau créateur
- phrase courte
- montant suggéré
- bouton

### Carte confirmation :

- merci
- montant
- créateur
- accès ou badge si prévu
- bouton continuer

## 12. ICONOGRAPHIE

- main stylisée
- cœur abstrait très sobre
- sceau créateur
- pièce/or
- reçu
- bouclier paiement

Éviter les cœurs rose/rouge enfantins.

## 13. COMPORTEMENT SCROLL

Le sheet soutien doit garder le CTA visible.
Les détails de frais peuvent être repliés.

## 14. ANIMATIONS

- sélection montant avec halo
- confirmation douce
- badge soutien apparaît si prévu
- aucune animation de pression sociale

## 15. MICRO INTERACTIONS

- tap montant
- montant personnalisé
- voir transparence
- paiement
- confirmation
- partage non forcé

## 16. GESTURES MOBILE

- swipe down fermer sheet
- tap montant
- long press non nécessaire
- éviter gestures qui changent montant accidentellement

## 17. ÉTATS LOADING

- préparation paiement
- vérification
- confirmation
- synchronisation soutien

Ne jamais effacer l'état si paiement revient en attente.

## 18. ÉTATS ERREUR

Erreurs :

- paiement échoué
- paiement annulé
- réseau instable
- créateur indisponible
- montant invalide

Réponses :

- réessayer
- modifier montant
- revenir au profil
- support si paiement débité

## 19. ÉTATS OFFLINE

### Offline :

- soutien impossible
- intention peut être sauvegardée
- message clair
- pas de faux paiement

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- sheet

### Tablet :

- modal large

### Desktop :

- panneau profil + modal paiement

## 21. ACCESSIBILITÉ

- montant annoncé
- bouton paiement clair
- transparence accessible
- confirmation lisible
- pas de pression visuelle

## 22. PERFORMANCE UX

- sheet léger
- prix/montants locaux
- paiement à la demande
- confirmation robuste

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- paiement résilient
- statut en attente
- pas de double paiement
- support clair
- montant modifiable

## 24. RÈGLES NON NÉGOCIABLES

- Soutien volontaire
- Pas de culpabilisation
- Pas de pression publique
- Montant clair
- Paiement sécurisé
- Confirmation fiable
- Créateur identifié
- Frais ou conditions transparents
