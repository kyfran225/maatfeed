# 13. CHECKLIST AGENT CODEUR - MONETIZATION, PREMIUM & SUPPORT SYSTEM

## 1. OBJECTIF UX

Donner à l'agent codeur une checklist complète pour implémenter la monétisation MAATFEED sans trahir l'identité premium, culturelle et respectueuse de la plateforme.

## 2. ÉMOTION RECHERCHÉE

Exécution propre.
Le résultat doit être fiable, clair, élégant, éthique et adapté aux usages mobiles africains.

## 3. STRUCTURE VISUELLE GLOBALE

À livrer :

- contenus premium
- séries premium
- soutien créateur
- sponsor natif
- audio sponsorisé
- paywall
- preview gratuite
- pricing
- paiement
- états paiement
- historique accès
- erreurs
- offline
- faible connexion
- accessibilité

## 4. LAYOUT EXACT

Vérifier :

- mobile-first
- paywall en sheet
- CTA visible
- prix clair
- preview avant paiement
- desktop pricing propre
- historique accès lisible
- mini-player audio respecté

## 5. HIERARCHIE VISUELLE

Vérifier :

- valeur avant prix
- aperçu avant paywall
- contenu gratuit respecté
- sponsorisé visible
- soutien volontaire
- paiement clair
- statut accès clair

## 6. POSITIONNEMENT DES ÉLÉMENTS

Vérifier :

- badge premium visible
- label sponsorisé visible
- prix près CTA
- conditions près CTA
- support dans erreurs
- accès actifs en haut historique

## 7. DIMENSIONS & ESPACEMENTS

Vérifier :

- CTA 52 à 56 px
- badges 22 à 28 px
- cartes premium respirantes
- sheet 65 à 90 %
- touch target 44 px
- padding 16 à 24 px

## 8. COULEURS

Vérifier :

- noir charbon
- graphite chaud
- or/ambre premium
- cuivre soutien
- ocre erreur
- pas de rouge agressif
- pas de vert e-commerce criard
- pas de bleu SaaS

## 9. TYPOGRAPHIE

Vérifier :

- prix lisible
- conditions lisibles
- descriptions courtes
- labels clairs
- pas de microtexte critique

## 10. BOUTONS

Créer et vérifier :

- Débloquer
- Écouter extrait
- Lire aperçu
- Soutenir
- Payer
- Réessayer
- Vérifier paiement
- Restaurer accès
- Continuer gratuitement
- Plus tard
- Contacter support

## 11. CARTES

Créer cartes pour :

- contenu premium
- série premium
- épisode premium
- soutien créateur
- sponsor natif
- audio sponsorisé
- offre pricing
- paiement en attente
- paiement réussi
- paiement échoué
- accès actif
- reçu

## 12. ICONOGRAPHIE

Vérifier :

- sceau premium
- clé
- casque
- série
- soutien
- sponsorisé
- reçu
- bouclier
- synchronisation
- offline

## 13. COMPORTEMENT SCROLL

Vérifier :

- pas d'interruption brutale feed
- CTA sticky dans paywall si nécessaire
- détails repliables
- pas de scroll horizontal pricing mobile
- position préservée après paiement

## 14. ANIMATIONS

Vérifier :

- ouverture sheet douce
- déverrouillage sobre
- succès paiement calme
- erreur stable
- réduction motion
- pas d'animations manipulatrices

## 15. MICRO INTERACTIONS

Vérifier :

- tap badge premium
- tap sponsorisé
- tap extrait
- sélectionner offre
- soutien montant
- paiement
- restore
- support
- feedback confirmation

## 16. GESTURES MOBILE

Vérifier :

- swipe down sheet
- pas de paiement par swipe
- fermeture protégée pendant paiement
- long press sauvegarder
- gestures alternatives visibles

## 17. ÉTATS LOADING

Vérifier :

- chargement prix
- vérification accès
- préparation paiement
- paiement en attente
- déblocage accès
- skeletons
- pas de spinner muet

## 18. ÉTATS ERREUR

Vérifier :

- paiement échoué
- paiement annulé
- réseau interrompu
- statut inconnu
- accès non synchronisé
- contenu indisponible
- sponsor non chargé
- retry/support

## 19. ÉTATS OFFLINE

Vérifier :

- paiement désactivé offline
- contenus débloqués téléchargés accessibles
- accès cache
- statut en attente conservé
- vérification au retour réseau
- support accessible quand possible

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Tester :

- petit mobile
- grand mobile
- tablet portrait
- tablet paysage
- desktop
- desktop large
- zoom navigateur
- mini-player actif
- faible réseau

## 21. ACCESSIBILITÉ

Vérifier :

- prix annoncé
- conditions lisibles
- sponsorisé textuel
- premium textuel
- focus visible
- navigation clavier
- erreurs annoncées
- paiement accessible
- pas de couleur seule

## 22. PERFORMANCE UX

Vérifier :

- previews légères
- pas d'autoplay
- paiement à la demande
- état local transaction
- éviter double paiement
- lazy-load
- cache historique
- vérification fiable

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Vérifier :

- réseau instable prévu
- paiement en attente
- retry manuel
- pas de double paiement
- médias compressés
- audio basse qualité
- contenu débloqué offline si téléchargé
- messages simples

## 24. RÈGLES NON NÉGOCIABLES

- Pas de dark pattern
- Pas de prix caché
- Pas de sponsor déguisé
- Pas de paywall sans preview
- Pas de culpabilisation
- Pas de paiement accidentel
- Pas de double paiement
- Pas de perte d'accès payé
- Pas de monétisation qui casse le feed
- Pas d'expérience premium criarde
- Respect de l'utilisateur gratuit
- Respect des créateurs
- Respect du faible réseau
- Respect total de l'identité MAATFEED
