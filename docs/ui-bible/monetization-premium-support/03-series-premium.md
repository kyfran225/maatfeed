# 3. SÉRIES PREMIUM

## 1. OBJECTIF UX

Permettre aux créateurs ou à MAATFEED de proposer des séries structurées avec épisodes gratuits et premium, tout en donnant à l'utilisateur une vision claire de la progression, de la valeur et des conditions d'accès.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit ressentir qu'il entre dans un parcours construit, presque une petite académie mobile, pas dans une playlist payante confuse.

## 3. STRUCTURE VISUELLE GLOBALE

Une série premium comprend :

- couverture
- titre
- créateur
- description
- progression
- épisodes gratuits
- épisodes premium
- durée totale
- niveau
- prix ou accès
- bouton commencer/continuer/débloquer

## 4. LAYOUT EXACT

### Page série mobile :

- hero compact
- badge premium si série payante
- progression
- liste épisodes
- bloc accès
- CTA sticky si non débloqué

### Page série desktop :

- hero à gauche
- détails et accès à droite
- épisodes en liste centrale
- recommandations en bas

## 5. HIERARCHIE VISUELLE

1. promesse de la série
2. progression ou structure
3. épisodes gratuits
4. accès premium
5. épisodes premium
6. créateur et crédibilité

## 6. POSITIONNEMENT DES ÉLÉMENTS

Les épisodes gratuits doivent apparaître avant le bloc premium pour montrer la valeur.
Les épisodes verrouillés affichent un aperçu, pas seulement un cadenas.

## 7. DIMENSIONS & ESPACEMENTS

### Mobile :

- hero série : 180 à 260 px
- carte épisode : 84 à 130 px
- bloc premium : 140 à 220 px
- CTA sticky : 56 px
- gap épisodes : 10 px

### Desktop :

- hero : 360 à 480 px large
- épisode : 96 à 140 px
- panneau accès : 320 à 380 px

## 8. COULEURS

### Série premium :

- fond profond
- accent or
- progression ambre
- épisode gratuit : graphite
- épisode premium : graphite + bordure or subtile
- épisode débloqué : badge accessible

## 9. TYPOGRAPHIE

- titre série : 24 à 32 px mobile selon espace
- description : 14 à 16 px
- épisode : 14 à 16 px
- durée : 12 px
- prix : 20 à 28 px

## 10. BOUTONS

Actions :

- Commencer gratuitement
- Continuer
- Débloquer la série
- Écouter l'extrait
- Voir le programme
- Télécharger épisodes
- Soutenir le créateur

## 11. CARTES

### Carte épisode :

- numéro
- titre
- durée
- statut gratuit/premium/débloqué
- progression
- action écouter/regarder/lire

### Carte série premium :

- bénéfices
- nombre épisodes
- accès
- CTA

## 12. ICONOGRAPHIE

- chapitres
- progression
- cadenas discret
- casque audio
- vidéo
- document
- sceau premium

## 13. COMPORTEMENT SCROLL

La liste épisodes doit être claire.
Le CTA premium peut rester sticky si l'utilisateur n'a pas accès.
Si l'utilisateur a accès, remplacer CTA par "Continuer".

## 14. ANIMATIONS

- progression qui se remplit
- épisode débloqué halo léger
- transition épisode gratuit vers premium sans rupture
- ouverture programme douce

## 15. MICRO INTERACTIONS

- tap épisode verrouillé : preview/paywall
- tap progression : détail
- tap télécharger : état
- accès débloqué : épisodes deviennent actifs

## 16. GESTURES MOBILE

- swipe épisodes si carousel horizontal utilisé
- long press épisode pour sauvegarder
- swipe down paywall
- tap CTA

## 17. ÉTATS LOADING

- skeleton hero
- skeleton épisodes
- vérification accès
- chargement progression

Afficher les épisodes déjà connus même si accès charge.

## 18. ÉTATS ERREUR

Si série partiellement indisponible :

- afficher épisodes disponibles
- message par section
- réessayer

Si paiement validé mais série non débloquée :

- état "Synchronisation de ton accès"
- bouton restaurer accès

## 19. ÉTATS OFFLINE

### Offline :

- épisodes téléchargés accessibles
- épisodes premium non téléchargés grisés
- progression locale conservée
- synchronisation plus tard

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- vertical
- CTA sticky

### Tablet :

- hero + épisodes en deux zones

### Desktop :

- layout riche avec panneau accès

## 21. ACCESSIBILITÉ

- statut épisode textuel
- progression annoncée
- bouton épisode clair
- prix et accès lisibles
- focus sur épisode actif

## 22. PERFORMANCE UX

- charger liste épisodes rapidement
- médias à la demande
- couverture compressée
- progression cache
- pas d'autoplay

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- audio basse qualité
- téléchargement pour plus tard
- texte descriptif avant média
- reprise progression
- paywall léger

## 24. RÈGLES NON NÉGOCIABLES

- Série structurée, pas playlist confuse
- Épisodes gratuits visibles
- Épisodes premium expliqués
- Progression préservée
- Accès clair
- Offline pour contenus téléchargés
- Aucun piège
