# 2. CONTENUS PREMIUM

## 1. OBJECTIF UX

Présenter certains contenus comme premium lorsqu'ils apportent une profondeur réelle : analyse longue, audio travaillé, documentaire, série structurée, source commentée, débat enrichi, masterclass culturelle.

Le premium doit signaler une valeur ajoutée, pas une punition.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit ressentir :

- envie d'approfondir
- respect pour le travail du créateur
- clarté sur ce qui est inclus
- possibilité de rester en gratuit sans honte

## 3. STRUCTURE VISUELLE GLOBALE

Un contenu premium doit comporter :

- titre
- type
- créateur
- badge premium
- aperçu gratuit
- bénéfices
- prix ou accès requis
- bouton débloquer
- alternative gratuite si disponible

## 4. LAYOUT EXACT

### Dans le feed :

- carte premium intégrée
- preview visible
- badge en haut
- CTA en bas

### Dans la page détail :

- haut de page avec aperçu
- bloc "Ce que tu débloques"
- bouton action
- informations accès
- contenus liés gratuits

## 5. HIERARCHIE VISUELLE

1. titre et valeur
2. aperçu
3. contenu débloqué
4. prix
5. action
6. conditions

Le cadenas ne doit pas être l'élément principal. La valeur doit l'être.

## 6. POSITIONNEMENT DES ÉLÉMENTS

### Badge premium :

- haut gauche ou proche du type
- jamais caché

### CTA :

- bas de carte
- sticky en détail mobile si page longue

### Preview :

- avant le paywall

## 7. DIMENSIONS & ESPACEMENTS

### Carte feed :

- hauteur 180 à 280 px
- badge 24 à 28 px
- CTA 44 à 52 px
- padding 16 px

### Détail :

- hero 220 à 360 px mobile selon média
- bloc accès 120 à 200 px

## 8. COULEURS

### Premium :

- fond noir/brun
- bordure or faible
- badge ambre
- CTA or profond
- preview avec overlay sombre

Ne jamais utiliser un cadenas rouge ou alarme.

## 9. TYPOGRAPHIE

- titre : 17 à 22 px mobile
- description : 13 à 15 px
- prix : 18 à 24 px
- bénéfices : 13 px
- conditions : 11 à 12 px

## 10. BOUTONS

Actions :

- Débloquer ce contenu
- Écouter l'extrait
- Lire l'aperçu
- Sauvegarder pour plus tard
- Voir contenus gratuits similaires
- Offrir ou soutenir si prévu plus tard

## 11. CARTES

Carte premium doit afficher :

- type de contenu
- valeur
- durée ou profondeur
- extrait
- accès
- CTA

Exemple d'esprit :
"Analyse audio complète - 42 min - disponible avec accès premium."

## 12. ICONOGRAPHIE

- sceau premium
- clé
- casque
- papyrus
- livre
- chapitre
- source

## 13. COMPORTEMENT SCROLL

Le paywall ne doit pas apparaître avant l'aperçu.
Sur long contenu, laisser lire une partie gratuite, puis bloc premium.

## 14. ANIMATIONS

- reveal premium doux
- déverrouillage avec halo
- passage preview vers contenu complet sans saut

## 15. MICRO INTERACTIONS

- tap badge : "Contenu premium"
- tap extrait : preview
- tap bénéfice : détail
- déblocage : accès immédiat
- sauvegarde : feedback

## 16. GESTURES MOBILE

- long press sauvegarder
- swipe fermer sheet
- tap CTA
- scroll preview

## 17. ÉTATS LOADING

- vérification accès
- chargement preview
- chargement prix
- déblocage

Toujours conserver le contenu preview visible.

## 18. ÉTATS ERREUR

Si contenu indisponible :

- afficher preview si possible
- message clair
- proposer contenus similaires

Si accès payé non reconnu :

- proposer restaurer ou resynchroniser

## 19. ÉTATS OFFLINE

### Premium offline :

- disponible si téléchargé ou déjà cache autorisé
- non disponible sinon
- état clair

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- carte intégrée + sheet

### Tablet :

- carte large + détails

### Desktop :

- hero + panneau accès

## 21. ACCESSIBILITÉ

- premium annoncé
- prix lisible
- CTA clair
- preview clairement séparée
- pas d'information couleur seule

## 22. PERFORMANCE UX

- preview légère
- média complet après accès
- lazy-load
- éviter double chargement

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- preview texte ou audio basse qualité
- pas de vidéo lourde auto
- téléchargement premium possible si prévu
- reprise fiable

## 24. RÈGLES NON NÉGOCIABLES

- Premium = valeur réelle
- Aperçu obligatoire
- Prix clair
- Pas de blocage brutal
- Accès débloqué immédiatement après paiement réussi
- Alternative gratuite si possible
- Respect de l'utilisateur gratuit
