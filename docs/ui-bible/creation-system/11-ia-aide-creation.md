# 11. IA D'AIDE À LA CRÉATION

## 1. OBJECTIF UX

L'IA doit aider le créateur à améliorer son contenu sans voler sa voix.
Elle peut proposer :

- titres
- résumés
- tags
- reformulations
- sources à ajouter
- structure de débat
- transcription
- chapitrage
- avertissements de clarté
- suggestions de ton

## 2. ÉMOTION RECHERCHÉE

L'IA doit être ressentie comme un conseiller discret, pas comme un professeur arrogant.
Émotion :

- accompagnement
- confiance
- clarté
- stimulation
- contrôle

## 3. STRUCTURE VISUELLE GLOBALE

IA sous forme :

- bouton contextuel
- panneau latéral desktop
- bottom sheet mobile
- cartes suggestions
- actions appliquer/ignorer/modifier

## 4. LAYOUT EXACT

### Mobile :
- bouton IA ambre discret
- sheet "Améliorer cette création"
- suggestions en cartes
- appliquer une par une

### Desktop :
- panneau droit avec suggestions continues
- preview impact possible

## 5. HIERARCHIE VISUELLE

Priorité :

1. suggestion utile
2. raison courte
3. appliquer
4. ignorer
5. régénérer

## 6. POSITIONNEMENT DES ÉLÉMENTS

- bouton IA dans toolbar
- suggestions proches du champ concerné
- panneau IA jamais au-dessus du contenu principal

## 7. DIMENSIONS & ESPACEMENTS

- bouton IA : 40 à 44 px
- carte suggestion : 88 à 160 px
- sheet IA : 50 à 80 % hauteur
- panneau desktop : 320 à 380 px

## 8. COULEURS

- IA : ambre/or subtil
- suggestion : surface sombre
- appliquer : ambre
- ignorer : gris sable
- alerte : ocre

## 9. TYPOGRAPHIE

- suggestion titre : 14 à 16 px
- explication : 12 à 14 px
- bouton : 13 px

## 10. BOUTONS

- améliorer
- résumer
- proposer titre
- proposer tags
- clarifier débat
- générer transcription
- appliquer
- ignorer
- régénérer

## 11. CARTES

Carte suggestion :

- type
- suggestion
- pourquoi
- actions

Ne jamais remplacer automatiquement sans consentement clair.

## 12. ICONOGRAPHIE

- étincelle IA
- plume
- tag
- résumé
- source
- transcription

## 13. COMPORTEMENT SCROLL

Panneau IA scrollable indépendamment.
Sur mobile, sheet IA ne doit pas faire perdre la position du composer.

## 14. ANIMATIONS

- suggestion apparaît en fade
- appliquer : insertion douce
- régénérer : skeleton
- ignorer : collapse

## 15. MICRO INTERACTIONS

- hover/tap "voir différence"
- appliquer partiellement
- copier suggestion
- feedback "utile / pas utile"

## 16. GESTURES MOBILE

- swipe suggestion : ignorer
- tap appliquer
- long press : copier
- swipe down sheet

## 17. ÉTATS LOADING

- génération
- transcription
- analyse clarté
- suggestions tags

Loading doit être poétique mais sobre : petites lignes ambre qui respirent.

## 18. ÉTATS ERREUR

- IA indisponible
- réseau
- contenu trop court
- limite atteinte

Toujours laisser création normale possible.

## 19. ÉTATS OFFLINE

Offline :

- suggestions IA cloud indisponibles
- suggestions locales simples si disponibles
- demande IA mise en attente optionnelle
- composer continue

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :
- sheet IA

### Tablet :
- panneau temporaire

### Desktop :
- panneau permanent optionnel

## 21. ACCESSIBILITÉ

- suggestions lisibles
- actions labellisées
- pas d'insertion automatique
- focus

## 22. PERFORMANCE UX

- IA à la demande
- pas de génération permanente
- cache suggestions
- limiter requêtes

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- IA non bloquante
- texte local conservé
- suggestions différées
- priorité création manuelle

## 24. RÈGLES NON NÉGOCIABLES

- L'IA ne remplace jamais la voix du créateur
- Aucune suggestion ne s'applique sans action claire
- L'IA ne doit pas bloquer la publication
- L'IA doit rester contextuelle
- Les suggestions doivent être sobres et utiles
