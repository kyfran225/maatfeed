# 7. CRÉATION DE SÉRIE

## 1. OBJECTIF UX

Permettre aux créateurs de construire des parcours de contenu.
Une série peut regrouper :

- épisodes audio
- vidéos
- posts
- débats
- documents
- leçons
- analyses

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit sentir qu'il bâtit une bibliothèque vivante.
Émotion :

- ambition
- ordre
- continuité
- fierté
- progression

## 3. STRUCTURE VISUELLE GLOBALE

Création série :

- titre
- description
- couverture
- format dominant
- épisodes
- ordre
- publication progressive
- monétisation éventuelle
- audience
- preview

## 4. LAYOUT EXACT

### Mobile :
- étape infos série
- étape couverture
- étape épisodes
- étape preview

### Desktop :
- colonne épisodes
- composer épisode
- preview série

## 5. HIERARCHIE VISUELLE

Priorité :

1. titre série
2. promesse éditoriale
3. épisodes
4. couverture
5. publication

## 6. POSITIONNEMENT DES ÉLÉMENTS

- titre haut
- couverture sous titre
- description
- liste épisodes
- bouton ajouter épisode sticky
- preview finale

## 7. DIMENSIONS & ESPACEMENTS

- couverture mobile : ratio 16:9 ou 1:1 selon usage
- carte épisode : 76 à 100 px
- bouton ajouter : 48 px
- description : 120 à 180 px

## 8. COULEURS

- série : or discret
- épisode actif : ambre faible
- brouillon : ocre
- publié : blanc/gris
- premium : or plus net

## 9. TYPOGRAPHIE

- titre série : 24 à 30 px
- épisode : 14 à 16 px
- description : 14 à 15 px
- meta : 12 px

## 10. BOUTONS

- ajouter épisode
- importer contenu existant
- réordonner
- publier série
- publier épisode
- sauvegarder
- preview

## 11. CARTES

Cartes :

- épisode
- couverture
- progression
- monétisation
- checklist série

Chaque épisode indique :

- type
- durée
- statut
- ordre

## 12. ICONOGRAPHIE

- pile
- épisode
- audio
- vidéo
- texte
- débat
- verrou premium
- drag handle

## 13. COMPORTEMENT SCROLL

Liste épisodes scrollable.
Bouton ajouter reste accessible.
Desktop : épisodes sticky à gauche.

## 14. ANIMATIONS

- ajout épisode : insertion
- réordonner : déplacement fluide
- publication épisode : badge
- preview : transition page série

## 15. MICRO INTERACTIONS

- drag épisode
- épisode incomplet : pastille
- couverture manquante : suggestion IA
- titre long : avertissement doux

## 16. GESTURES MOBILE

- drag réordonner
- swipe épisode : options
- long press : menu
- tap épisode : éditer

## 17. ÉTATS LOADING

- génération couverture
- upload épisode
- preview série
- publication

## 18. ÉTATS ERREUR

- épisode incomplet
- upload échoué
- ordre conflit
- couverture trop lourde

## 19. ÉTATS OFFLINE

- série en brouillon local
- épisodes locaux
- publication différée
- réorganisation offline

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :
- étapes

### Tablet :
- épisodes + détails

### Desktop :
- workspace série complet

## 21. ACCESSIBILITÉ

- réordonner accessible sans drag
- labels
- statut épisode textuel
- focus

## 22. PERFORMANCE UX

- épisodes lazy
- couverture compressée
- autosave
- preview optimisée

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- série texte/audio prioritaire
- vidéo différée
- épisodes sauvegardés localement
- upload reprenable

## 24. RÈGLES NON NÉGOCIABLES

- Une série doit pouvoir rester en brouillon
- L'ordre des épisodes doit être clair
- Le créateur doit voir ce qui est publié ou non
- La série ne doit pas devenir un tableau SaaS
- La promesse éditoriale doit être mise en avant
