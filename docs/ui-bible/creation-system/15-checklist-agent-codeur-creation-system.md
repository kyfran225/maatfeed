# 15. CHECKLIST AGENT CODEUR — CREATION SYSTEM

## Vision générale

L'agent codeur doit implémenter un Creation System transversal, mobile-first, local-first et fidèle à MAATFEED.
La création doit couvrir :

- post
- audio
- vidéo
- débat
- série
- réponse multimédia
- document
- citation
- sources
- brouillons
- preview
- publication
- IA
- offline
- faible connexion
- desktop workspace

## Entrée création

À valider :

- bouton création accessible depuis la navigation principale
- ouverture instantanée
- choix format clair
- audio et débat valorisés
- brouillons récents visibles
- offline autorisé

## Composer texte/post

À valider :

- champ agréable
- titre optionnel
- citation
- source
- tags
- preview fidèle
- autosave
- publication sans perte

## Studio audio

À valider :

- micro central
- timer
- waveform
- pause/reprise
- preview
- transcription
- upload différé
- fichier local conservé
- publication possible après preview

## Studio vidéo

À valider :

- preview verticale
- import
- capture
- compression
- captions
- couverture
- upload reprenable
- brouillon local

## Création débat

À valider :

- question centrale
- contexte
- sources
- tags
- positions optionnelles
- preview débat
- IA de clarification
- publication structurée

## Création série

À valider :

- titre
- description
- couverture
- épisodes
- ordre
- statuts
- brouillon
- publication progressive

## Réponse multimédia

À valider :

- contexte parent visible
- choix format
- réponse texte/audio/vidéo/image/document
- preview
- retour au thread
- highlight après publication

## Sources et médias

À valider :

- ajout source simple
- carte source
- upload progress
- compression
- retry
- suppression claire
- offline queue

## Brouillons

À valider :

- autosave
- statut visible
- reprise
- suppression avec confirmation
- brouillons locaux
- brouillons cloud si disponible

## Preview

À valider :

- rendu réel feed/débat/série
- responsive
- accès modification
- pas de preview générique

## Publication

À valider :

- validation minimale
- publication avec loading localisé
- succès clair
- partage
- voir publication
- publication différée offline

## IA

À valider :

- suggestions non intrusives
- appliquer/ignorer
- pas de remplacement automatique
- IA non bloquante
- IA contextuelle

## Faible connexion

À valider :

- création possible offline
- médias locaux
- uploads reprenables
- compression
- publication différée
- statut clair

## Accessibilité

À valider :

- boutons 44 px minimum
- labels
- focus
- clavier desktop
- alternatives aux gestures
- messages erreur textuels
- transcription audio/vidéo

## Performance

À valider :

- composer rapide
- autosave léger
- IA lazy
- preview optimisée
- upload chunké visuellement
- pas de blocage global

## Règles finales

Le Creation System de MAATFEED doit donner à chaque utilisateur l'impression qu'il peut transformer une idée en contenu culturel publiable, même avec peu de réseau, peu de temps, et sans compétence technique.

La création n'est pas une simple boîte de publication.
C'est un atelier de transmission.
