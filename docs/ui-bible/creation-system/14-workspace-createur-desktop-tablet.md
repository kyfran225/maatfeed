# 14. WORKSPACE CRÉATEUR DESKTOP ET TABLET

## 1. OBJECTIF UX

Offrir aux créateurs avancés un espace de production plus riche sur grand écran, sans tomber dans un dashboard froid.

## 2. ÉMOTION RECHERCHÉE

Sensation :

- atelier éditorial
- contrôle
- profondeur
- calme
- professionnalisme culturel

## 3. STRUCTURE VISUELLE GLOBALE

### Desktop :
- navigation création à gauche
- composer au centre
- aperçu à droite
- IA/sources/checklist dans panneau droit
- brouillons accessibles

### Tablet :
- composer + preview ou composer + IA selon orientation

## 4. LAYOUT EXACT

### Desktop 3 colonnes :
- gauche : 260 px
- centre : 640 à 760 px
- droite : 360 px
- header global : 64 à 72 px

## 5. HIERARCHIE VISUELLE

Priorité :

1. contenu
2. preview
3. publication
4. IA
5. brouillons

## 6. POSITIONNEMENT DES ÉLÉMENTS

- types création gauche
- composer centre
- preview droite haut
- checklist droite bas
- bouton publier sticky

## 7. DIMENSIONS & ESPACEMENTS

- gap : 24 px
- composer max : 760 px
- preview card : 320 à 380 px
- panneau : 100 % hauteur disponible

## 8. COULEURS

- fond large : noir profond
- colonnes : surfaces subtiles
- séparateurs : ambre très faible
- focus : ambre

## 9. TYPOGRAPHIE

- nav : 13 à 15 px
- composer : 16 à 18 px
- preview : selon rendu feed
- panneau : 12 à 14 px

## 10. BOUTONS

- nouveau
- brouillons
- preview
- publier
- IA
- sources
- programmation
- quitter

## 11. CARTES

- brouillon
- suggestion IA
- source
- preview
- checklist

## 12. ICONOGRAPHIE

Même système que mobile, plus labels visibles.

## 13. COMPORTEMENT SCROLL

Colonnes indépendantes mais non confuses.
Composer scroll principal.
Preview sticky.

## 14. ANIMATIONS

- transitions panneaux
- preview live douce
- drag upload
- publication

## 15. MICRO INTERACTIONS

- hover actions
- drag-and-drop
- raccourcis clavier
- autosave visible

## 16. GESTURES MOBILE

Tablet tactile :

- drag média
- swipe panneau
- tap large

## 17. ÉTATS LOADING

- preview
- IA
- upload
- autosave

## 18. ÉTATS ERREUR

- panneaux affichent erreur locale
- composer reste intact
- retry

## 19. ÉTATS OFFLINE

- workspace reste utilisable
- brouillons locaux
- publication attente

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Mobile reste référence.
Desktop enrichit, mais ne redéfinit pas le produit.

## 21. ACCESSIBILITÉ

- navigation clavier
- raccourcis indiqués
- focus
- labels
- contrastes

## 22. PERFORMANCE UX

- preview optimisée
- panneaux lazy
- autosave
- pas de rendu lourd simultané

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Même desktop :

- local-first
- upload différé
- compression
- IA non bloquante

## 24. RÈGLES NON NÉGOCIABLES

- Desktop ne doit pas devenir un dashboard SaaS
- Le composer reste central
- Preview fidèle
- IA secondaire
- Brouillons toujours accessibles
