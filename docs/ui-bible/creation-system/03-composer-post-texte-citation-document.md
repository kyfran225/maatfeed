# 3. COMPOSER POST, TEXTE, CITATION ET DOCUMENT

## 1. OBJECTIF UX

Permettre de créer des contenus textuels riches, culturels et sourcés sans complexité.
Ce composer couvre :

- post simple
- réflexion courte
- citation commentée
- document
- extrait historique
- note culturelle
- ressource pédagogique

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit sentir qu'il écrit dans un espace sérieux, propre, noble.
Pas une boîte de statut générique. Plutôt une table d'écriture numérique.

## 3. STRUCTURE VISUELLE GLOBALE

Structure :

- titre optionnel
- champ principal
- ajout média
- ajout citation
- ajout source
- tags
- audience
- aperçu
- IA d'aide

## 4. LAYOUT EXACT

### Mobile :
- header avec fermer, aperçu, publier
- grand champ texte
- toolbar basse
- options avancées repliées
- preview en sheet

### Desktop :
- champ central
- preview droite
- sources et tags droite
- brouillons gauche

## 5. HIERARCHIE VISUELLE

Priorité :

1. champ texte
2. titre
3. sources
4. tags
5. aperçu
6. publication

## 6. POSITIONNEMENT DES ÉLÉMENTS

- titre au-dessus du corps
- corps au centre
- toolbar sous le champ ou bas fixed
- sources sous le corps
- tags après sources
- aperçu accessible haut droite

## 7. DIMENSIONS & ESPACEMENTS

- champ titre : 48 à 56 px hauteur
- corps minimum mobile : 220 px
- padding : 16 à 20 px
- line-height texte : 1.55 à 1.7
- carte source : 64 à 90 px
- tags : hauteur 32 à 36 px

## 8. COULEURS

- champ fond transparent ou surface très sombre
- placeholder gris sable
- curseur ambre
- source validée bordure ambre
- erreur source rouge discret

## 9. TYPOGRAPHIE

- titre : 22 à 28 px
- corps : 16 à 18 px
- citation : 17 à 20 px, style éditorial
- source : 12 à 14 px
- tags : 12 px

## 10. BOUTONS

- ajouter source
- ajouter image
- ajouter citation
- IA améliorer
- aperçu
- publier
- sauvegarder brouillon

## 11. CARTES

Cartes :

- source
- citation
- image
- document
- suggestion IA
- checklist qualité

Carte citation :

- guillemet discret
- fond sombre
- liseré ambre gauche
- auteur/source visible

## 12. ICONOGRAPHIE

- plume
- guillemets
- lien
- document
- image
- IA
- œil preview

## 13. COMPORTEMENT SCROLL

Le champ texte doit grandir jusqu'à une limite puis scroller.
Toolbar reste accessible.
Le clavier mobile ne doit jamais cacher le curseur.

## 14. ANIMATIONS

- ajout source : slide-in
- citation : expansion douce
- preview : fade
- suggestion IA : apparition latérale/sheet

## 15. MICRO INTERACTIONS

- sélection texte : menu citation/source
- compteur qualité
- source ajoutée : coche
- tag suggéré : pill qui apparaît
- sauvegarde auto : "Brouillon sauvegardé"

## 16. GESTURES MOBILE

- long press texte : options
- swipe source : supprimer
- drag média : réordonner
- swipe down preview : fermer

## 17. ÉTATS LOADING

- sauvegarde auto
- analyse IA
- preview
- upload document

Loading localisé, jamais plein écran.

## 18. ÉTATS ERREUR

- champ vide
- source invalide
- document trop lourd
- réseau
- contenu non publiable

Toujours conserver le texte.

## 19. ÉTATS OFFLINE

- texte sauvegardé localement
- sources gardées
- publication en attente
- documents uploadés plus tard
- preview locale disponible

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :
- édition plein écran

### Tablet :
- édition + preview alternée

### Desktop :
- édition et preview simultanées

## 21. ACCESSIBILITÉ

- champs labellisés
- focus visible
- taille texte confortable
- support clavier
- erreurs textuelles

## 22. PERFORMANCE UX

- autosave léger
- preview différée
- documents lazy
- IA seulement sur demande ou suggestion douce

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- texte prioritaire
- publication différée
- documents compressés
- sources enregistrées même offline
- pas de perte contenu

## 24. RÈGLES NON NÉGOCIABLES

- Le texte ne doit jamais être perdu
- La source doit être clairement visible si ajoutée
- Le composer ne doit pas ressembler à un CMS lourd
- La citation doit avoir un rendu éditorial premium
- L'aperçu doit montrer le rendu réel dans le feed
