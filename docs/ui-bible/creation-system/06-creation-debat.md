# 6. CRÉATION DE DÉBAT

## 1. OBJECTIF UX

Permettre de lancer un débat structuré, clair, sourcé et engageant.
Le débat MAATFEED ne doit pas être un simple post avec commentaires. Il doit être une scène organisée.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit sentir qu'il ouvre un cercle de discussion sérieux.
Émotion :

- gravité
- curiosité
- responsabilité
- stimulation
- respect

## 3. STRUCTURE VISUELLE GLOBALE

Création débat :

- question centrale
- contexte
- positions possibles
- sources
- tags
- règles du débat
- média optionnel
- IA de clarification
- aperçu page débat
- publication

## 4. LAYOUT EXACT

### Mobile :
- étape 1 : question
- étape 2 : contexte
- étape 3 : sources/tags
- étape 4 : aperçu
- publication

### Desktop :
- composer central
- aperçu débat à droite
- IA et sources à gauche/droite

## 5. HIERARCHIE VISUELLE

Priorité :

1. question du débat
2. contexte
3. sources
4. catégories
5. règles
6. publication

## 6. POSITIONNEMENT DES ÉLÉMENTS

- question en haut
- champ contexte sous question
- sources sous contexte
- positions optionnelles après sources
- preview avant publication

## 7. DIMENSIONS & ESPACEMENTS

- champ question : 80 à 120 px
- contexte : 180 à 260 px
- source card : 72 à 96 px
- step indicator : 32 à 40 px hauteur
- bouton publier : 44 à 52 px

## 8. COULEURS

- débat : accent ambre profond
- question : blanc cassé
- contexte : gris clair
- source : bordure ambre faible
- règle : surface sombre

## 9. TYPOGRAPHIE

- question : 22 à 28 px
- contexte : 15 à 17 px
- source : 12 à 14 px
- labels : 11 à 12 px

## 10. BOUTONS

- ajouter source
- proposer reformulation IA
- ajouter position
- aperçu
- publier débat
- sauvegarder brouillon

## 11. CARTES

Cartes :

- source
- position
- règle
- suggestion IA
- aperçu débat

Carte position :

- titre court
- description
- couleur neutre
- pas de polarisation agressive

## 12. ICONOGRAPHIE

- débat
- balance
- source
- IA
- règle
- question

## 13. COMPORTEMENT SCROLL

Flow par étapes mobile.
Sur desktop, scroll central avec aperçu sticky.

## 14. ANIMATIONS

- progression étapes
- reformulation IA en douceur
- source ajoutée
- preview débat qui se compose progressivement

## 15. MICRO INTERACTIONS

- question trop vague : suggestion douce
- source manquante : rappel
- débat sensible : ton recommandé
- tag proposé : chip ambre

## 16. GESTURES MOBILE

- swipe étape suivante/précédente
- long press source : options
- swipe source : retirer

## 17. ÉTATS LOADING

- IA analyse question
- preview débat
- validation sources
- publication

## 18. ÉTATS ERREUR

- question vide
- débat doublon
- source invalide
- réseau
- modération

Toujours conserver brouillon.

## 19. ÉTATS OFFLINE

- débat sauvegardé localement
- sources gardées
- publication différée
- validation sources plus tard

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :
- étapes simples

### Tablet :
- question + aperçu

### Desktop :
- workspace débat complet

## 21. ACCESSIBILITÉ

- champs clairs
- structure par étapes
- erreurs textuelles
- clavier

## 22. PERFORMANCE UX

- IA non bloquante
- sources lazy
- preview légère
- autosave

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- débat texte-first
- sources en attente
- publication différée
- pas de média obligatoire
- brouillon local

## 24. RÈGLES NON NÉGOCIABLES

- Un débat doit avoir une question claire
- Le contexte doit être encouragé
- Les sources doivent être faciles à ajouter
- L'IA peut clarifier, pas imposer une opinion
- La création débat doit rester digne et structurée
