# 12. MONÉTISATION CRÉATEUR DANS LA CRÉATION

## 1. OBJECTIF UX

Permettre aux créateurs d'activer une monétisation élégante sans transformer MAATFEED en plateforme agressive.
Options possibles :

- contenu premium
- série premium
- soutien créateur
- sponsor natif
- contenu bonus
- accès anticipé

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit sentir :

- valeur
- transparence
- dignité
- maîtrise

Le créateur ne doit pas sentir qu'il mendie. Il propose une valeur culturelle.

## 3. STRUCTURE VISUELLE GLOBALE

Dans le composer :

- section monétisation repliée
- options simples
- preview badge premium
- règles de visibilité
- estimation claire

## 4. LAYOUT EXACT

### Mobile :
- section "Valeur & accès" sous options avancées
- cartes premium/soutien/sponsor
- preview

### Desktop :
- panneau droit sous publication

## 5. HIERARCHIE VISUELLE

Priorité :

1. gratuit ou premium
2. valeur proposée
3. accès
4. preview
5. conditions

## 6. POSITIONNEMENT DES ÉLÉMENTS

- monétisation après contenu, jamais avant
- badge premium dans preview
- explication sous option

## 7. DIMENSIONS & ESPACEMENTS

- carte option : 72 à 100 px
- toggle : 44 px
- badge premium : 24 à 30 px

## 8. COULEURS

- premium : or
- soutien : ambre doux
- sponsor : gris sable
- gratuit : surface sombre

## 9. TYPOGRAPHIE

- option : 14 à 16 px
- description : 12 à 13 px
- condition : 11 à 12 px

## 10. BOUTONS

- activer premium
- ajouter bonus
- définir accès
- preview paywall
- désactiver

## 11. CARTES

Cartes :

- premium
- soutien
- sponsor
- preview utilisateur

## 12. ICONOGRAPHIE

- étoile
- cadenas
- main/soutien
- partenaire
- badge

## 13. COMPORTEMENT SCROLL

Section repliée par défaut pour éviter surcharge.
Dépliée seulement si créateur intéressé ou éligible.

## 14. ANIMATIONS

- activation toggle
- badge premium apparaît dans preview
- cartes se déplient doucement

## 15. MICRO INTERACTIONS

- preview accès gratuit/premium
- message transparence
- alerte si contenu incomplet

## 16. GESTURES MOBILE

- tap cartes
- swipe options non nécessaire
- sheet détails

## 17. ÉTATS LOADING

- vérification éligibilité
- sauvegarde option
- preview paywall

## 18. ÉTATS ERREUR

- non éligible
- option indisponible
- réseau
- contenu incomplet

## 19. ÉTATS OFFLINE

- option gardée en brouillon
- validation plus tard
- publication premium attend réseau

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :
- section simple

### Desktop :
- panneau détaillé

## 21. ACCESSIBILITÉ

- transparence
- labels
- pas de dark pattern
- conditions lisibles

## 22. PERFORMANCE UX

- section lazy
- pas de calcul lourd
- preview simple

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- pas de paywall lourd
- aperçu léger
- explication claire
- validation différée

## 24. RÈGLES NON NÉGOCIABLES

- Monétisation transparente
- Pas de confusion gratuit/premium
- Pas de sponsor caché
- Pas de pression excessive
- La valeur éditoriale reste prioritaire
