# 5. VIDEO CREATION STUDIO

## 1. OBJECTIF UX

Permettre la création ou l'import de vidéos courtes et propres, adaptées au feed MAATFEED sans imiter TikTok.
La vidéo doit servir le savoir, le débat, la culture, l'explication, pas seulement le divertissement.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit sentir :

- contrôle
- clarté
- modernité
- légèreté
- sérieux éditorial

Le studio vidéo doit être efficace, pas bruyant.

## 3. STRUCTURE VISUELLE GLOBALE

Le studio vidéo contient :

- caméra/import
- preview verticale
- durée
- couverture
- titre
- description
- tags
- transcription/captions
- source
- audio associé
- publication

## 4. LAYOUT EXACT

### Mobile :
- preview verticale 9:16
- contrôles bas
- options à droite mais limitées
- titre/description après capture
- preview finale avant publication

### Desktop :
- upload/preview central
- métadonnées droite
- timeline simple bas

## 5. HIERARCHIE VISUELLE

Priorité :

1. preview vidéo
2. bouton record/import
3. durée
4. titre
5. captions
6. publication

## 6. POSITIONNEMENT DES ÉLÉMENTS

- preview au centre
- record en bas centre
- importer en bas gauche
- galerie/couverture en bas droite
- options après capture dans sheet

## 7. DIMENSIONS & ESPACEMENTS

### Mobile :
- preview : ratio 9:16
- largeur : 100 % moins marges
- radius preview : 24 à 30 px
- record : 72 à 88 px
- boutons secondaires : 44 px
- safe area bas respectée

## 8. COULEURS

- fond : noir profond
- record : ambre ou blanc cassé selon contexte
- bordure preview : ambre très faible
- captions : blanc sur overlay sombre
- erreurs : rouge discret

## 9. TYPOGRAPHIE

- timer : 14 à 16 px
- titre vidéo : 18 à 24 px
- captions : 14 à 16 px
- options : 12 à 14 px

## 10. BOUTONS

- enregistrer
- arrêter
- importer
- retourner caméra si disponible
- couper
- choisir couverture
- captions
- publier
- sauvegarder brouillon

## 11. CARTES

Après capture :

- carte preview
- carte couverture
- carte captions
- carte source
- carte qualité

## 12. ICONOGRAPHIE

- caméra
- upload
- sous-titres
- couverture
- ciseaux
- source
- IA

## 13. COMPORTEMENT SCROLL

### Pendant capture :
- pas de scroll

### Après capture :
- preview sticky
- métadonnées scrollables

## 14. ANIMATIONS

- ouverture caméra
- record pulse
- fin capture vers preview
- upload progression
- captions apparition

## 15. MICRO INTERACTIONS

- choix couverture : cadre ambre
- captions générées : badge
- compression : progression
- erreur format : message immédiat

## 16. GESTURES MOBILE

- tap record
- long press record pour capture rapide
- swipe preview pour revoir
- pinch interdit si non nécessaire
- drag couverture dans timeline simple

## 17. ÉTATS LOADING

- accès caméra
- import
- compression
- génération captions
- upload
- preview

## 18. ÉTATS ERREUR

- caméra refusée
- format trop lourd
- upload échoué
- compression impossible
- captions indisponibles

Toujours proposer sauvegarde locale.

## 19. ÉTATS OFFLINE

Offline :

- import/capture autorisé
- publication différée
- preview locale
- compression locale
- upload plus tard

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :
- capture verticale

### Tablet :
- preview + métadonnées

### Desktop :
- upload avancé
- preview verticale centrée
- panneau détails

## 21. ACCESSIBILITÉ

- captions fortement encouragées
- contrôles labellisés
- alternative texte
- focus desktop

## 22. PERFORMANCE UX

- compression vidéo
- upload reprenable
- thumbnail générée
- preview légère
- éviter lecture auto lourde

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- avertir sur taille
- proposer audio à la place si réseau faible
- upload différé
- qualité adaptative
- captions différées

## 24. RÈGLES NON NÉGOCIABLES

- Pas de clone TikTok
- La vidéo doit servir le contenu
- Captions faciles à ajouter
- Upload reprenable
- Brouillon sauvegardé
- Aucun média capturé ne doit être perdu
