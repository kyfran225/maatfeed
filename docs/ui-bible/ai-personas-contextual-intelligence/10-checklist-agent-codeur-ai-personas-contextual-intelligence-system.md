# 10. CHECKLIST AGENT CODEUR - AI PERSONAS & CONTEXTUAL INTELLIGENCE SYSTEM

## 1. OBJECTIF UX

Donner à l'agent codeur une checklist complète pour implémenter le système IA MAATFEED avec cohérence, transparence, sobriété et respect de l'identité produit.

## 2. ÉMOTION RECHERCHÉE

Exécution maîtrisée.

Le résultat final doit donner une IA utile, belle, claire, discrète et fiable.

## 3. STRUCTURE VISUELLE GLOBALE

À livrer :

- avatars IA non humains
- cartes persona
- panneau IA mobile
- panneau IA desktop
- IA débat
- IA création
- IA recherche
- IA recommandations
- badges IA
- transparence
- limites
- feedback
- signalement
- états loading
- états erreur
- états offline
- préférences IA

## 4. LAYOUT EXACT

Vérifier :

- mobile bottom sheet
- desktop panneau droit
- tablet panneau repliable
- contenu humain prioritaire
- IA jamais centrale par défaut
- bouton fermer visible
- actions contextuelles limitées

## 5. HIERARCHIE VISUELLE

Vérifier :

- contenu humain avant IA
- persona visible
- badge IA visible
- limites accessibles
- actions utiles
- recommandations expliquées

## 6. POSITIONNEMENT DES ÉLÉMENTS

Vérifier :

- IA débat proche des outils débat
- IA création dans composer
- IA recherche sous suggestions
- IA recommandation dans carte "Pourquoi"
- badges toujours près du contenu IA

## 7. DIMENSIONS & ESPACEMENTS

Vérifier :

- avatar standard 36 à 56 px
- cartes IA 96 à 220 px
- sheet 55 à 90 % hauteur
- panneau desktop 320 à 420 px
- touch target 44 px
- padding 16 à 24 px

## 8. COULEURS

Vérifier :

- noir charbon
- graphite chaud
- ambre/or
- cuivre/ocre
- pas de violet chatbot
- pas de bleu SaaS
- pas de couleurs criardes

## 9. TYPOGRAPHIE

Vérifier :

- réponses courtes
- paragraphes lisibles
- labels IA clairs
- disclaimers lisibles
- pas de murs de texte

## 10. BOUTONS

Vérifier :

- Résumer
- Expliquer
- Comparer
- Reformuler
- Ajouter nuance
- Proposer sources
- Insérer
- Masquer
- Signaler
- Voir limites
- Réessayer
- Continuer sans IA

## 11. CARTES

Créer cartes pour :

- persona
- résumé
- suggestion
- sources
- modération
- recommandation expliquée
- création
- erreur IA
- offline IA

## 12. ICONOGRAPHIE

Vérifier :

- avatars non humains
- symboles sobres
- badge IA
- balance
- papyrus
- constellation
- bouclier
- onde
- plume

## 13. COMPORTEMENT SCROLL

Vérifier :

- panneau IA scroll indépendant
- position contenu conservée
- lien IA vers réponse avec highlight
- pas de saut brutal

## 14. ANIMATIONS

Vérifier :

- transitions sobres
- skeleton doux
- hover desktop
- focus search
- réduction motion
- passage lu/non-lu

## 15. MICRO INTERACTIONS

Vérifier :

- tap carte
- long press
- swipe lu/archive
- hover desktop
- undo archive
- feedback offline
- action en attente

## 16. GESTURES MOBILE

Vérifier :

- swipe gauche/droite
- long press
- pull-to-refresh
- swipe onglets
- alternatives visibles

## 17. ÉTATS LOADING

Vérifier :

- skeleton header
- skeleton onglets
- skeleton cartes
- skeleton timeline
- pas de spinner solitaire

## 18. ÉTATS ERREUR

Vérifier :

- erreur globale
- erreur partielle
- erreur contenu supprimé
- erreur action
- retry
- fallback cache

## 19. ÉTATS OFFLINE

Vérifier :

- notifications cache
- inbox cache
- actions en attente
- sync différée
- badge non actualisé indiqué
- contenus disponibles offline

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

Tester :

- petit mobile
- grand mobile
- tablet portrait
- tablet paysage
- desktop
- desktop large
- zoom navigateur
- mini-player actif

## 21. ACCESSIBILITÉ

Vérifier :

- état lu/non-lu textuel
- focus visible
- labels
- lecteur d'écran
- navigation clavier
- réduction motion
- contrastes
- actions destructives confirmées

## 22. PERFORMANCE UX

Vérifier :

- compteur rapide
- cache-first
- pagination
- groupement
- lazy-load
- pas de média lourd
- sync différée
- actions optimistes sûres

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

Vérifier :

- texte avant média
- offline utile
- mode léger
- push légères
- emails groupés
- pas de refresh agressif
- pas de blocage réseau

## 24. RÈGLES NON NÉGOCIABLES

- Aucun avatar humain
- Aucun portrait humain
- IA toujours identifiée
- IA jamais déguisée en utilisateur
- IA jamais dominante
- IA jamais publication automatique
- IA toujours contrôlable
- IA toujours signalable
- IA utilisable mais non indispensable
- Respect des religions et traditions
- Respect de la nuance
- Respect du faible réseau
- Respect de l'identité MAATFEED
