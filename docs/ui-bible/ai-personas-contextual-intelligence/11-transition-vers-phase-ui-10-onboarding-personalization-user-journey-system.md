## 🎨 PRINCIPES À APPLIQUER

### Onboarding Culturel et Respectueux
- L'onboarding doit être une initiation culturelle, pas un formulaire froid
- Les avatars symboliques doivent être présentés comme des choix identitaires
- L'archétype doit être présenté comme une boussole, pas une case
- Les centres d'intérêt doivent refléter la richesse du savoir africain

### Personnalisation Progressive
- L'utilisateur ne doit pas être surchargé de choix initiaux
- La personnalisation doit s'affiner avec l'usage
- Les préférences doivent pouvoir évoluer
- L'IA doit apprendre sans envahir

### Parcours sans Friction
- L'accès doit être possible sans inscription immédiate
- L'inscription doit être minimale et respectueuse
- L'onboarding doit être skippable pour les utilisateurs pressés
- La découverte doit être naturelle et guidée

### Performance et Faible Connexion
- L'onboarding doit fonctionner même avec connexion instable
- Les choix doivent être sauvegardés localement
- Le mode léger doit être disponible dès le début
- Les médias doivent être optionnels

## 🎯 PRINCIPE CENTRAL DE LA PHASE UI 10

L'onboarding MAATFEED ne doit pas être un formulaire d'inscription déguisé. Il doit être une initiation légère, culturelle, progressive et personnalisante, capable de comprendre l'utilisateur sans le fatiguer dès la première ouverture.

Chaque étape doit pouvoir :

- Accueillir avec respect culturel
- Proposer un avatar symbolique et non humain
- Guider vers un archétype sans enfermer
- Personnaliser progressivement sans surcharger
- Fonctionner même avec faible connexion
- Évoluer avec l'utilisateur dans le temps

L'onboarding devient un rite d'initiation, pas une barrière.
