# 4. IA DANS LES DÉBATS

## 1. OBJECTIF UX

Aider l'utilisateur à comprendre, structurer et enrichir les débats sans réduire la liberté d'expression ni remplacer les participants.

L'IA dans les débats doit :

- résumer
- clarifier
- identifier les points d'accord
- identifier les désaccords
- proposer des questions
- signaler le manque de sources
- reformuler avec nuance
- calmer les tensions
- aider à répondre

## 2. ÉMOTION RECHERCHÉE

Le débat doit devenir plus lisible, plus profond, plus respirable.

L'utilisateur doit sentir que l'IA apporte de l'oxygène dans une pièce pleine d'idées.

## 3. STRUCTURE VISUELLE GLOBALE

Dans une page débat, l'IA peut apparaître sous forme de :

- bouton "Résumer"
- carte "Points clés"
- panneau "Analyse du débat"
- suggestion de réponse
- alerte de nuance
- aide aux sources
- intervention d'Animateur Communautaire
- éclairage Expert Kemet ou religieux selon sujet

## 4. LAYOUT EXACT

### Mobile :

- bouton IA sous le header débat ou dans menu
- bottom sheet IA
- sections courtes :
  - résumé
  - points d'accord
  - points de désaccord
  - questions ouvertes
  - sources manquantes
  - aide à répondre

### Desktop :

- panneau droit "Intelligence contextuelle"
- résumé sticky
- boutons d'action
- comparaison d'arguments possible

## 5. HIERARCHIE VISUELLE

Le thread humain reste central.

L'IA vient après :

1. sujet du débat
2. réponses humaines
3. contexte
4. actions humaines
5. assistance IA

## 6. POSITIONNEMENT DES ÉLÉMENTS

L'IA ne doit pas poster automatiquement dans le thread.

Les interventions IA visibles dans le thread doivent être clairement marquées et justifiées.

Préférer un panneau d'aide plutôt qu'un faux participant permanent.

## 7. DIMENSIONS & ESPACEMENTS

### Carte résumé :

- mobile : 140 à 220 px
- desktop : 180 à 280 px
- padding : 16 à 20 px
- sections internes : gap 12 px

### Chip IA débat :

- hauteur 34 à 40 px
- texte court
- icône constellation

## 8. COULEURS

### Débat IA :

- fond graphite
- bordure ambre
- badge IA or doux
- avertissement ocre si contenu sensible
- sources en papyrus/beige

## 9. TYPOGRAPHIE

### Résumé :

- titre : 16 à 18 px
- contenu : 14 à 15 px
- points : courts
- disclaimer : 11 à 12 px

## 10. BOUTONS

Actions :

- Résumer le débat
- Voir les points d'accord
- Voir les désaccords
- Aider à répondre
- Ajouter de la nuance
- Proposer des sources
- Changer de persona
- Masquer l'analyse IA

## 11. CARTES

### Carte "Points clés" :

- 3 à 5 points maximum
- pas de long essai
- possibilité "Voir plus"

### Carte "Sources manquantes" :

- indique les affirmations qui méritent source
- ne condamne pas l'utilisateur
- propose un ton neutre

### Carte "Réponse suggérée" :

- brouillon modifiable
- jamais publication automatique

## 12. ICONOGRAPHIE

- balance pour nuance
- cercle débat
- papyrus pour source
- étoile IA
- bouclier pour modération
- plume pour reformulation

## 13. COMPORTEMENT SCROLL

Le panneau IA doit garder sa position.

Quand l'IA référence une réponse, cliquer doit scroller vers cette réponse avec highlight temporaire.

Ne jamais perdre la position initiale sans retour possible.

## 14. ANIMATIONS

- highlight réponse référencée
- ouverture panneau IA
- génération résumé par blocs
- accordéons pour points d'accord/désaccord
- disparition douce des suggestions ignorées

## 15. MICRO INTERACTIONS

- tap point clé : montre réponses liées
- tap source manquante : propose formulation
- tap reformuler : ouvre composer
- utile/pas utile sur résumé
- signaler analyse IA

## 16. GESTURES MOBILE

- swipe down fermer IA
- swipe entre sections IA
- long press sur suggestion
- tap réponse liée

## 17. ÉTATS LOADING

### Loading résumé :

- "Lecture du débat…"
- skeleton par sections
- possibilité d'annuler
- thread reste utilisable

## 18. ÉTATS ERREUR

Si le débat est trop long :

- résumé partiel
- bouton "analyser seulement les réponses récentes"

Si IA indisponible :

- proposer tri manuel
- continuer débat sans IA

## 19. ÉTATS OFFLINE

Offline :

- résumés déjà générés accessibles
- nouvelles analyses indisponibles
- brouillons IA sauvegardés si déjà créés
- message discret

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- bottom sheet

### Tablet :

- panneau latéral

### Desktop :

- workspace débat + IA

## 21. ACCESSIBILITÉ

- IA annoncée
- liens vers réponses clairs
- focus vers réponse liée
- contenu IA lisible
- réduction motion
- pas de couleurs seules

## 22. PERFORMANCE UX

- génération à la demande
- résumé cache
- limiter contexte
- analyse progressive
- pas de recalcul automatique à chaque réponse

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- résumé court
- analyse par lots
- texte uniquement
- pas de médias
- cache
- pas de génération répétée

## 24. RÈGLES NON NÉGOCIABLES

- L'IA ne poste jamais automatiquement
- L'IA ne remplace pas les participants
- L'IA doit être marquée
- Résumés toujours prudents
- Les sujets sensibles doivent être nuancés
- L'utilisateur garde le contrôle
- Aucune vérité finale autoritaire
