# 2. AVATARS IA NON HUMAINS ET IDENTITÉ SYMBOLIQUE

## 1. OBJECTIF UX

Créer une famille visuelle d'avatars IA immédiatement reconnaissables, cohérents, premium et non humains.

Chaque persona IA doit être identifiable sans visage humain, grâce à une forme, un symbole, une couleur d'accent, une texture et une présence visuelle propres.

## 2. ÉMOTION RECHERCHÉE

L'utilisateur doit ressentir :

- mystère maîtrisé
- intelligence
- respect
- profondeur culturelle
- sérénité
- autorité calme

Les avatars doivent donner une présence, pas une personnalité caricaturale.

## 3. STRUCTURE VISUELLE GLOBALE

Chaque avatar IA est composé de :

- symbole principal
- cercle ou sceau de fond
- motif subtil
- halo léger
- couleur d'accent
- micro-animation éventuelle
- nom de persona
- rôle court

Format commun :

- avatar rond ou sceau arrondi
- fond sombre uniforme
- symbole central lumineux
- bordure or/brun
- aucune peau
- aucun visage
- aucun regard humain

## 4. LAYOUT EXACT

### Dans une carte :

- avatar à gauche
- nom persona à droite
- rôle sous le nom
- badge IA proche du nom
- action ou statut en bas

### Dans un panneau IA :

- avatar en haut
- nom
- spécialité
- limites
- actions

### Dans une réponse :

- petit avatar 32 à 36 px
- nom persona
- label IA
- contenu

## 5. HIERARCHIE VISUELLE

Hiérarchie :

1. symbole
2. nom persona
3. spécialité
4. badge IA
5. action

Le symbole doit aider la reconnaissance, mais le texte doit toujours confirmer.

## 6. POSITIONNEMENT DES ÉLÉMENTS

### Avatar :

- gauche sur mobile
- haut ou gauche sur desktop selon carte
- jamais placé comme décoration de fond uniquement
- jamais utilisé sans label dans contexte sensible

## 7. DIMENSIONS & ESPACEMENTS

### Tailles :

- très petit : 24 px pour badge inline
- standard : 36 à 44 px
- carte : 52 à 64 px
- profil persona : 88 à 120 px

### Bordure :

- 1 px
- halo externe très léger
- padding interne visuel suffisant autour du symbole

## 8. COULEURS

### Palette commune :

- fond noir profond
- bordure or vieilli
- symbole ambre/or
- ombres brunes
- accents spécifiques par persona

### Accents possibles :

- Sage MAAT : or équilibré
- Expert Kemet : sable/papyrus
- Animateur Communautaire : cuivre chaud
- Théologien Catholique : ivoire/or ancien
- Érudit Musulman : vert très sombre + or, avec prudence esthétique
- Érudit Juif : bleu nuit très sombre + or discret

Aucune couleur ne doit devenir un cliché visuel agressif.

## 9. TYPOGRAPHIE

### Nom persona :

- 14 à 16 px
- semi-bold
- lisible

### Rôle :

- 12 à 13 px
- ton calme

### Badge IA :

- 10 à 12 px
- texte : "IA" ou "Persona IA"

## 10. BOUTONS

Actions :

- voir rôle
- choisir cette aide
- masquer
- changer de persona
- voir limites
- signaler

Les boutons doivent rester secondaires par rapport au contenu.

## 11. CARTES

Carte persona :

- avatar
- nom
- spécialité
- meilleure utilisation
- limites
- bouton "Utiliser ici"

Exemple :

"Expert Kemet - Analyse historique, civilisation kémétique, contexte des sources."

## 12. ICONOGRAPHIE

Symboles recommandés :

- Sage MAAT : balance abstraite, plume stylisée, cercle d'équilibre
- Expert Kemet : obélisque abstrait, papyrus, grille archéologique
- Animateur Communautaire : cercle de voix, foyer symbolique, anneaux connectés
- Théologien Catholique : vitrail abstrait, livre lumineux, croix géométrique très sobre
- Érudit Musulman : arabesque abstraite, étoile géométrique, livre ouvert symbolique
- Érudit Juif : étoile géométrique stylisée, rouleau symbolique, lampe abstraite

Les symboles religieux doivent être respectueux, sobres et non polémiques.

## 13. COMPORTEMENT SCROLL

Dans une liste de personas, avatars fixes dans chaque carte.

Sur mobile, la sélection peut être horizontale.

Sur desktop, grille ou colonne.

## 14. ANIMATIONS

Chaque avatar peut avoir une micro-animation très subtile :

- halo qui respire
- légère rotation d'un anneau
- scintillement discret d'un point
- onde très lente

Jamais d'animation cartoon.

## 15. MICRO INTERACTIONS

- tap avatar : affiche description
- hover desktop : révèle spécialité
- sélection : bordure ambre plus nette
- changement persona : transition douce

## 16. GESTURES MOBILE

- swipe horizontal entre personas
- long press pour voir détails
- tap pour sélectionner
- swipe down pour fermer sélection

## 17. ÉTATS LOADING

Si avatar non chargé :

- symbole placeholder abstrait
- nom toujours affiché
- ne jamais afficher silhouette humaine par défaut

## 18. ÉTATS ERREUR

Si avatar indisponible :

- utiliser sceau générique IA MAATFEED
- message invisible ou discret
- ne pas casser la carte

## 19. ÉTATS OFFLINE

Avatars doivent être disponibles offline via assets légers.

Aucun avatar IA ne doit dépendre d'un chargement distant lourd.

## 20. RESPONSIVE MOBILE/TABLET/DESKTOP

### Mobile :

- avatars 36 à 52 px
- labels courts

### Tablet :

- cartes plus riches

### Desktop :

- grille personas
- previews complètes

## 21. ACCESSIBILITÉ

Chaque avatar doit avoir :

- nom textuel
- rôle textuel
- description alternative
- état sélectionné annoncé
- contraste suffisant

## 22. PERFORMANCE UX

- assets vectoriels ou images très légères
- cache local
- pas d'animations coûteuses
- pas d'effets 3D lourds
- pas de génération dynamique à chaque affichage

## 23. COMPORTEMENT FAIBLE CONNEXION AFRIQUE

- avatars locaux
- pas d'images lourdes
- pas de vidéo animée
- fallback texte complet
- rendu rapide sur téléphones modestes

## 24. RÈGLES NON NÉGOCIABLES

- Aucun visage humain
- Aucun portrait humain
- Aucun avatar réaliste
- Aucun style cartoon enfantin
- Symboles respectueux
- IA toujours identifiée
- Cohérence visuelle entre toutes les personas
- Avatars légers et disponibles offline
